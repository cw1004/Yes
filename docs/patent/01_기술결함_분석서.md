# 기술 결함 분석서 — 초안 명세서에 대한 독립 검증

> 대상: 「예측 불확실도에 기반하여 회로 재구성의 실행 여부를 결정하는 전기차 및
> 산업용 인버터의 단계적 복원 안전 시스템 및 그 방법」 초안
> 방법: 물리적 유도 + 수치 검증(`sim/check_numerics.py`) + 시뮬레이션 실증(`sim/run_embodiment.py`)

## 판정 등급

| 등급 | 정의 | 건수 |
|---|---|---|
| **C (치명)** | 기재대로 실시하면 발명이 동작하지 않거나, 실시 불가능하거나, 새로운 위험을 만든다 | **13** |
| **M (중대)** | 수치·논리가 성립하지 않아 심사·무효심판에서 직접 공격받는다 | 19 |
| m (경미) | 표현·정합성 문제 | 8 |

가장 중요한 결론부터 적는다.

> **초안의 핵심 특징인 불확실도 게이팅은, 기재된 수치대로는 단 한 번도 발동하지 않는다.**
> `U_epis`는 [0,1] 확률의 분산이므로 Bhatia–Davis 부등식에 의해 `Var ≤ p(1−p)`이다.
> 게이트가 평가되는 지점인 `P_fail ≥ T2 = 0.70`에서 상한은 `0.70 × 0.30 = 0.21`이며,
> M=5 이산 헤드의 실제 최대는 **0.135**이다. 임계 `U_max = 0.25`는 이 상한을 넘는다.
> 60,000 표본 시뮬레이션에서 관측된 최대 분산은 **0.0488**, 게이트 발동은 **0건**이었다.
>
> 즉 청구항 1의 "불확실도가 임계 이상이면 재구성을 금지한다"는 한정이,
> 명세서가 제시한 산출식과 수치로는 **공집합**을 지시한다. 이는 실시가능요건
> (특허법 제42조 제3항) 및 뒷받침요건(제4항) 위반으로 직결된다.

## A. 진단부 (200) — 불확실도 산출

### A-1 [C] 게이팅 임계 `U_max = 0.25`가 수학적으로 도달 불가능

| 항목 | 값 |
|---|---|
| Popoviciu 전역 상한 | `Var ≤ 1/4 = 0.25` (등호는 p̄=0.5, 헤드가 0과 1로 정확히 양분될 때만) |
| Bhatia–Davis 조건부 상한 @ P_fail=0.70 | `p(1−p) = 0.21` |
| M=5 이산 헤드 실제 최대 @ p̄=0.70 | **0.135** (헤드 3개=1.000, 2개=0.250) |
| 60,000 표본 실측 최대 (P_fail≥0.70) | **0.0488** |
| 초안 게이트 발동 횟수 | **0 / 2,481** |

**정정**: 인식적 불확실도를 **상호정보량(mutual information)** 으로 정의한다.

```
U_epis = I = H[ (1/M)Σ p_m ] − (1/M) Σ H[p_m]      단위 nat, 범위 [0, ln2 = 0.6931]
```

시뮬레이션에서 결정된 `U_max = 1.14 × 10⁻³ nat` (ID 오게이팅률 5 %의 설계점).
보조 지표로 확률 공간 표준편차 `σ_epis = sqrt(Var)`를 병기한다(상한 0.458 @ p=0.7).

### A-2 [C] `U = sqrt(U_alea + U_epis)`의 차원 불일치

초안의 `σ²_m`은 헤드가 출력하는 **로짓 공간** 관측 잡음 분산이고,
`U_epis`는 **확률 공간** 분산이다. 서로 다른 공간의 분산은 더할 수 없다.

**정정 1 (주)**: 엔트로피 분해. 세 항이 모두 nat 단위이고 가법적이며,
Jensen 부등식에 의해 `U_epis ≥ 0`이 보장된다.

```
U_total = H[p̄]                    (전체)
U_alea  = (1/M) Σ H[p_m]          (우연적)
U_epis  = U_total − U_alea        (인식적, 상호정보량)
```

**정정 2 (대안)**: 로짓 잡음을 probit 근사로 확률 공간에 정합적으로 사영한다.

```
p_m = sigmoid( μ_m / sqrt(1 + π·σ²_m/8) )
```

본 구현은 정정 2로 헤드 출력을 산출하고 정정 1로 분해한다(`sim/inverter_uq/`).

### A-3 [C] OOD 판정 (ii) 엔트로피 기준이 전이 임계 T2와 자기모순

`H(p) > 0.60 nat ⟺ p ∈ (0.2876, 0.7124)`이고 `T2 = 0.70`이 이 구간 **내부**에 있다.
따라서 `P_fail ∈ [0.70, 0.7124)`에서는 OOD_2가 항상 참이 되어 S3 진입이 영구 차단되고,
실효 전이 임계가 설계자가 의도하지 않은 **0.7124로 이동**한다.

### A-4 [C] OOD 판정 (ii)는 정보량이 0

이진 출력에서 `H(p̄)`는 `p̄`만의 단조 결정론적 함수다. 따라서 `OOD_2`는
"P_fail이 중간 대역에 있음"과 논리적으로 **동치**이며, P_fail 외의 정보를 전혀 담지 않는다.
분포외 입력의 증거가 될 수 없다.

**정정**: 서로 독립인 세 계열의 지표를 논리합한다.

| 지표 | 근거 | 시뮬레이션 AUROC (센서이상 / 게이트열화 / 800 V) |
|---|---|---|
| 입력공간 마할라노비스 (클래스 조건부, Ledoit–Wolf 축소) | 학습 분포와의 거리 | 1.000 / 1.000 / 0.950 |
| 입력공간 PCA 재구성 잔차 | 학습 다양체 이탈 | 1.000 / 1.000 / 0.507 |
| 잠재공간 마할라노비스 · 잔차 | 비선형 결합 이탈 | 0.890 / 0.992 / 0.922 |
| 앙상블 상호정보량 | 모델 불일치 | 0.603 / 0.770 / 0.628 |

### A-5 [C] 공유 백본이 인식적 불확실도를 구조적으로 과소평가

분포외성은 대개 백본 표현에서 발생하는데 백본이 공유되면 헤드 간 불일치로 포착되지 않는다.
**실측 확인**: 상호정보량 단독 AUROC는 저온 시동 시나리오에서 **0.200**으로,
0.5를 크게 밑돈다. 즉 미학습 입력에서 앙상블이 **오히려 더 확신한다**.
초안이 앙상블 분산만으로 게이팅하려 한 설계는 이 지점에서 무너진다.

**정정**: (i) 백본에 **스펙트럴 정규화**(최대 특이값 ≤ 3.0)를 적용해 거리 보존
성질을 부여하고, (ii) 마지막 2개 층을 헤드별로 분리하며, (iii) 기하학적 OOD 지표를
**필수 병용**한다.

### A-6 [M] 마할라노비스 세부 규정 누락

- 단일 가우시안 → **클래스 조건부** 가우시안의 최소 거리
- `Σ⁻¹` 특이화 → **Ledoit–Wolf 축소** 필수(구현 축소계수 λ = 1.7 × 10⁻³)
- **INT8 양자화 후 특징 분포가 변하므로 `μ_train, Σ_train, D_th`는 반드시 배포 대상
  양자화 모델로 재산출**해야 한다. 미기재 시 실차에서 OOD 판정이 붕괴한다.

### A-7 [C] 분할 컨포멀 예측의 오용

이진 분류에서 컨포멀 예측은 **집합** `{∅, {0}, {1}, {0,1}}`을 산출하지 **구간**을 주지 않는다.
"해당 구간 폭이 U_max를 초과하면"이라는 기재는 성립하지 않는다.

**정정**: **Venn–Abers 예측자(IVAP)** 를 사용한다. 이진 확률의 구간 `[p₀, p₁]`을 주며
자동 캘리브레이션이 보장된다. 실측 구간 폭은 중앙값 0.0312, 95 백분위 0.0400.
추가로 교환가능성이 분포이동에서 깨지므로 **Mondrian 조건부** 적용을 명시해야 한다.

### A-8 [M] 캘리브레이션과 임계치 결정의 순서 미정의

온도 스케일링은 단조변환이므로 AUC는 불변이지만 **임계치의 절대값과 U_epis는 바뀐다**
(로짓을 T로 나누면 헤드 간 확률 분산이 축소된다). 따라서 `T1, T2, U_max`는
**반드시 온도 스케일링 후**에 결정해야 한다. 초안은 순서를 규정하지 않았다.

### A-9 [M] ECE 빈 전략 미규정

등간격 빈은 고확신 구간에 표본이 편중되어 ECE를 과소평가한다.
**정정**: 등질량(quantile) 빈을 기본으로 하고 등간격을 병기.
실측 — 등질량 0.0021 / 등간격 0.0029 (온도 T = 1.2032, 기준 ≤ 0.05 충족).

## B. 복원 정책부 (300) — 상태 전이

### B-1 [C] 게이팅 무한 체류 — 발명이 만들어낸 새로운 위험

`U_epis ≥ U_max`가 지속되면 `P_fail = 0.99`여도 **영구히 S2에 체류**한다.
실제로 소자가 열폭주 중이라면 디레이팅만으로는 막지 못한다.
즉 게이팅 자체가 새로운 위험원이 되며, 초안에는 탈출 경로가 없다.

**정정 (안전상 필수)**:

```
게이트가 t_hold(= 30 s) 이상 지속되고 P_fail ≥ T2 가 유지되면
  -> S4(안전 정지)로 강제 상승한다.
감시부의 결정론적 물리 트립(T_j > T_lim 등)은 게이트 상태와 무관하게 항상 우선한다.
```

### B-2 [C] `FP ≤ 0.1 %`의 단위 미정의

진단 100 Hz에서 표본당 FPR = 10⁻³은 **0.1 건/s = 8,640 건/일**이다. 무의미하다.

**정정**: 목표를 **오재구성률 ≤ 10 FIT(건/10⁹h)** 로 정의하고,
자기상관으로 측정한 탈상관시간 `τ_dec`로부터 유효 독립시행수 `n_eff = 1/τ_dec`를 구해
표본당 임계로 환산한다. 진단 오차는 시간상관되므로 독립 가정은 금지한다.

```
요구 표본당 FPR = ( 목표FIT / (n_eff · 3600 · 10⁹) )^(1/N_conf)
              = ( 10 / (4.0 · 3600 · 10⁹) )^(1/3) = 8.855 × 10⁻⁵
```

이 수준은 6만 표본으로 직접 분해할 수 없으므로 음성 점수 꼬리에 **일반화 파레토
분포(GPD) 첨두초과 적합**을 하여 외삽한다 (u = 0.422, ξ = 0.1104, β = 0.7858).
결과: **T2 = 0.995031**.

### B-3 [M] U_max 결정 절차의 편면성

"오분류 표본 U_epis 분포의 5 백분위"만으로는 **정분류 표본의 오게이팅률이 전혀 통제되지
않는다.** 극단적으로 U_max를 크게 잡으면 100 % 게이팅되지만 재구성은 영원히 불가능해진다.

**정정 — 이중 제약**:

```
U_max = max { u :  P(gate | 차단대상, P_fail ≥ T2) 를 최대화 }
        s.t.  P(gate | 정당 재구성, P_fail ≥ T2) ≤ β = 0.05
조건부 집합을 {P_fail ≥ T2}로 한정한다 (게이트가 실제로 평가되는 지점).
두 제약을 동시에 만족하는 u가 없으면 -> 불확실도 분리능 부족 -> 모델 재학습.
```

### B-4 [M] 히스테리시스 `T2' = 0.62`의 자기모순

S3는 비가역이라고 정의해 놓고 S3로부터의 하향 전이 임계를 두었다. 적용 대상이 없다.
**정정**: T2'는 "S3 진입 대기 중인 S2⁺ 상태에서의 복귀 임계"로 재정의하거나 삭제.

### B-5 [M] `dP_fail/dt` 추정기 미정의

100 Hz 확률 신호의 수치미분은 SNR이 0에 가깝다. 0.15/s 임계는 잡음만으로 상시 초과한다.
**정정**: 창 `W_d = 2.0 s`의 최소자승 기울기(또는 Savitzky–Golay 1차 도함수)를 쓰고,
기울기의 표준오차 SE를 함께 산출하여 `slope > 0.15/s AND slope > 3·SE`를 요구한다.

### B-6 [m] `T_j > 125 °C` 절대 임계의 부적절성

SiC(정격 175~200 °C)에는 과도하게 보수적이고 소자별로 의미가 다르다.
**정정**: 절대 온도가 아닌 **정격 대비 마진** `ΔT = T_j,max − T_j < 25 K`로 기재하고
소자별 표를 둔다.

## C. 재구성 제어부 (400) — 고장 모드 판별과 시퀀스

### C-1 [C] B4 출력 상한 "58 %, 근거 √3/3"은 근거 오류

`√3/3 = 0.5774`는 **B6 SVPWM의 변조 이득**이지 B4 강압비가 아니다.

정확한 유도 — 고장상 c를 분압 커패시터 중점 O에 접속하면 `v_cO = 0`.
부동 중성점 부하에서는 선간전압만 유효하므로 `v_ac = v_aO`, `v_bc = v_bO`.
평형 3상에서 선간 진폭은 `√3·V_m`이므로:

```
√3 · V_m ≤ V_dc/2      ->   V_m ≤ V_dc/(2√3) = 0.2887 · V_dc
B6 SVPWM 기준 (V_m = V_dc/√3 = 0.5774·V_dc)  ->  비율 = 정확히 50.0 %
B6 SPWM  기준 (V_m = V_dc/2   = 0.5000·V_dc)  ->  비율 = 57.7 %
```

즉 **58 %는 SPWM 기준일 때만 성립**한다. 양산 인버터는 SVPWM/3차 고조파 주입을 쓰므로
**50 %를 채택**하고 기준 변조 방식을 명시해야 한다.

### C-2 [C] B4 모드의 지배적 제약(중점 커패시터)이 통째로 누락

고장상 전류가 분압 커패시터를 통해 환류하므로 **기본파 주파수의 중점 전압 변동**이 발생한다.

```
Δv_pk = I_m / (2π·f_e·C_eq) ,   C_eq = 2C
```

`V_dc = 400 V, C = 1500 µF × 2, 허용 불평형 5 % (20 V)` 기준 실시 가능 영역:

| 전류 | f_min | 커패시터 RMS 전류 |
|---|---|---|
| 1.00 pu (400 A) | 1061 Hz | 283 A |
| 0.50 pu (200 A) | 531 Hz | 141 A |
| 0.20 pu (80 A) | 212 Hz | 57 A |
| 0.10 pu (40 A) | 106 Hz | 28 A |

**B4 모드는 저속(저주파) 영역에서 실시 불가능하다.** 초안은 전압 제약 하나만,
그것도 틀린 값으로 기재했다. 세 제약을 모두 기재해야 실시가능요건을 충족한다.

### C-3 [C] B4 전환에 필요한 하드웨어 전제 미기재

초안은 "리던던트 레그 미보유 시 B4"라고 하여 추가 하드웨어가 불필요한 것처럼 읽힌다.
그러나 B4는 (a) 분압 커패시터와 중점 인출, (b) 고장상을 중점에 접속하는 양방향 도통 소자,
(c) 고장 레그를 확실히 분리하는 직렬 차단 소자가 **모두** 필요하다.
표준 2레벨 인버터에는 셋 다 없다.

### C-4 [C] SCR/TRIAC으로 상 절체 불가

TRIAC/SCR은 자기소호가 불가능하다. 전동기 상전류는 양방향·연속이므로 임의 시점에 차단할 수 없다.

**정정**: 절체 소자는 역직렬 IGBT/MOSFET(양방향 차단) 또는 기계식 컨택터로 한다.
SCR/TRIAC을 쓴다면 **투입 전용**(고장상 → 중점 접속)으로 한정하고
해당 상 전류의 **영교차에 동기하여 점호**한다.

### C-5 [C] 단락 검출을 DC 링크 전류로 하는 것은 대역폭상 불가능

```
di/dt = V_dc / L_loop = 400 V / 30 nH = 13,333 A/µs
2.5 × 정격(1,000 A) 도달 시간 = 75 ns
```

통상 DC 링크 전류 센서(대역 50~200 kHz, 상승시간 2~7 µs)로는 관측할 수 없다.

**정정**: 1차 검출은 **DESAT + 게이트 전압 플래토 이상 + 켈빈 소스 기생 인덕턴스
di/dt 감지**(또는 로고스키 코일)로 하고, DC 링크 전류·전압 강하는 **사후 확인 지표**로
격하한다. DESAT은 블랭킹(1~3 µs) 동안 맹목이며 오프 상태 단락은 다음 턴온의 첫 펄스에서
검출된다는 점도 기재해야 한다.

### C-6 [C] 직렬 차단 소자의 위치 미정의 — 시퀀스가 성립하지 않음

DC 링크에 SSCB/퓨즈를 두면 개방 시 인버터 전체가 정지하므로 이후 B4 운전이 불가능하다.
즉 초안의 "격리 확인 후 개방고장 시퀀스 ③ 이하 적용"이 **논리적으로 성립하지 않는다.**

**정정 — 세 실시예를 구분**:

| 실시예 | 배치 | 결과 | 대가 |
|---|---|---|---|
| (a) 레그 직렬형 | 각 레그 DC측 | 해당 레그만 분리, 잔여 2레그로 B4 가능 | 상시 도통 손실 |
| (b) 상 출력 직렬형 | 각 상 AC 출력에 양방향 SSCB | 고장상 분리 후 중점 접속 | 상시 도통 손실 |
| (c) 미보유형 | 분리 수단 없음 | **단락 시 재구성 불가 → ASC/FW → S4** | 없음 |

또한 **격리 확인 방법**을 정의해야 한다: 분리 소자 양단 전압 측정, 또는 저듀티 시험 펄스
인가 후 상전류 부재를 3 주기 확인.

### C-7 [C] ASC 시 어느 암을 단락할지 미정의

초안은 "하암 3상 단락"으로 고정했다. 그러나 **상암 소자가 단락 고장이면 하암 ASC는
관통을 유발한다.**

**정정**: **고장 소자가 속한 암과 동일한 암으로 ASC에 진입**한다.
(하암 단락 → 나머지 두 하암 턴온, 상암 전체 오프. 상암 단락 → 그 반대.)

### C-8 [C] 개방고장 판정 기준 15 %가 가장 흔한 고장을 놓침

| 고장 유형 | 상전류 RMS | Park 벡터 궤적 | 초안 기준(<15 %) |
|---|---|---|---|
| **단일 스위치 개방** (상암만 등) | 약 70 % (1/√2) | **반원** | **검출 불가** |
| 상 개방 (레그 전체·결선 단선) | ≈ 0 % | **직선** | 검출 가능 |

초안은 두 모드를 혼동하여 "결손된 반원형"이라 쓰면서 RMS 기준은 상 개방용을 적용했다.
결과적으로 **가장 흔한 단일 스위치 개방을 놓친다.**

**정정 — 정규화 평균 전류 Park 벡터법 (Cardoso/Mendes)**:

```
d_k = <i_k>_T / ( (1/T)∫|i_s| dt ) ,  k ∈ {a,b,c}
  정상          : |d_k| ≈ 0
  단일 스위치 개방: 해당 상 |d_k| > d_th(≈0.30), 부호로 상암/하암 판별
  상 개방        : 두 d_k가 반대 부호로 동시 증가, 해당 상 전류 ≈ 0
  Park 각 α = atan2(<i_β>, <i_α>) 로 6개 소자 중 위치 특정
저부하에서 d_k가 불안정하므로 |i_s| > 0.10 pu 에서만 판정을 유효로 한다.
```

### C-9 [M] 데드타임 연장의 인과 부재

개방고장 자체는 데드타임과 무관하다. 초안은 근거 없이 `Δt = 0.5~1.5 µs`를 기재했다.

**정정 — 게이트 저항 절환에 연결하면 인과가 성립한다**:
`R_g1(2.2 Ω) → R_g2(10 Ω)` 절환은 di/dt를 억제하지만 `t_d(off)`와 `t_f`를 증가시키므로,
관통 방지를 위해 데드타임을 **반드시** 그만큼 연장해야 한다.

```
Δt_d ≥ [ t_d(off)|R_g2 − t_d(off)|R_g1 ] + 소자·온도 산포 + 안전마진   (실측으로 결정)
```

### C-10 [M] 게이트 저항 증대의 열적 대가 미기재

R_g 증대는 스위칭 손실을 증가시켜 접합 온도를 올린다. 즉 보호하려는 대상을 악화시킨다.
**정정**: 고 R_g 운전의 허용 지속시간을 `ΔP_sw`와 `R_th`로부터 산정하여 한정한다.
또한 느린 턴오프는 DESAT 응답을 지연시키므로 L0 계층과의 정합을 확인해야 한다.

### C-11 [m] "연속 3 전기각 주기"의 저속 발산

5 Hz에서 3 주기 = 600 ms. 시간 상한을 병기해야 한다.

## D. 계층적 시간 예산부 (500)

### D-1 [M] 진단 주기와 지연의 미분리
예산 표는 지연만 규정한다. **정정**: `T_diag = 10 ms`(주기), 지연 상한 10 ms(1주기 파이프라인),
지터 ≤ 1 ms를 각각 명시한다.

### D-2 [C] 락스텝 코어는 처리량 이득이 없다

락스텝 듀얼코어는 동일 명령을 두 코어가 실행하고 비교하므로 **처리량은 1코어분**이다.
"락스텝 멀티코어에서 5 ms 예산을 만족"이라는 기재는 성립하지 않는다.

**정정**: 락스텝 코어쌍(감시부·정책부, ASIL D)과 **비락스텝 성능 코어**(AI 추론)를
분리한 구성으로 기재한다. 이는 실제 차량용 MCU의 표준 구성이며 ASIL 분해와도 정합한다.

### D-3 [M] LSTM은 WCET 산정이 곤란

순차 의존으로 SIMD 병렬화가 불리하고 실행시간 예측이 어렵다.
**정정**: **인과적 팽창 합성곱(TCN)** 또는 depthwise-separable 1D-CNN으로 대체·병기한다.
고정 수용영역이므로 **결정론적 WCET 산정이 가능**하며, 이는 기능안전 주장을 강화한다.

### D-4 [M] 연산량 예산의 정합성 부족

`5 MMAC / 5 ms = 1.0 GMAC/s` 요구.

| 구성 | 가용 | 추론시간 | 판정 |
|---|---|---|---|
| 300 MHz, INT8 4 MAC/cy, η=0.5 | 0.60 GMAC/s | 8.33 ms | 미달 |
| 400 MHz, INT8 4 MAC/cy, η=0.5 | 0.80 GMAC/s | 6.25 ms | 미달 |
| 600 MHz, 8 MAC/cy(DSP), η=0.6 | 2.88 GMAC/s | 1.74 ms | 충족 |

**정정**: 산정식 `T_inf = MAC / (f_clk · MAC_per_cycle · η)`를 명세서에 기재하고
예산을 `MAC ≤ 2 M/추론`으로 하향한다. 메모리 예산표(파라미터, Σ⁻¹, 특징 버퍼)도 추가한다.
참고로 본 실시예 구현의 파라미터 수는 3,410개(INT8 3.3 kB)이다.

### D-5 [C] 시간 예산 초과 시 재구성 무효화 규정 누락

가장 중요한 규정이 빠졌다. **시한을 초과한 상태에서 비가역 조치를 실행해서는 안 된다.**
**정정**: "어느 구간이든 시간 예산을 초과하면 해당 주기의 재구성 명령은 무효로 하고
직전 보수적 상태를 유지한다"를 명시한다.

## E. 안전 감시부 (600) — 가장 큰 구조적 공백

### E-1 [C] ASIL 분해 조합이 ISO 26262-9에 존재하지 않음

초안: "ASIL B(D) + ASIL D(D) = ASIL D".
ASIL D의 **유효한 분해는 D(D)+QM(D), C(D)+A(D), B(D)+B(D) 뿐**이다.
D(D) 단독으로 이미 D를 충족하므로 B(D)를 더하는 것은 분해가 아니다.

**정정**: 의도(AI는 낮게, 감시부는 높게)에 정확히 부합하는 유효 조합은
**QM(D) + D(D)** — 이른바 Doer/Checker 구조다.

- 진단부(200, AI) = **QM(D)**
- 안전 감시부(600) = **ASIL D(D)**
- 추가 필수 요건: 충분한 독립성(별도 코어·MPU 파티션·별도 전원·클럭·기준전압·신호경로)과
  **종속고장분석(DFA, ISO 26262-9 Clause 5)** 수행을 기재해야 한다.
- 감시부가 단순 워치독이면 MCU 고장모드를 충분히 덮지 못해 분해가 성립하지 않는다.
  따라서 감시부는 **독립 연산과 독립 센싱 경로**를 갖는 것으로 한정해야 한다.

### E-2 [C] **감시부가 재구성 명령을 전혀 통제하지 않는다 — 최대 결함**

초안의 감시부는 토크 지령만 `min()`으로 제한한다. 그러나 본 발명에서 진짜 위험한
비가역 조치는 **회로 재구성**(게이트 영구 차단, 바이패스 도통)이며,
이는 토크 포락선으로 전혀 막히지 않는다.

> 결과적으로 **QM(D)로 강등한 AI가 ASIL D급 위험 조치를 단독으로 트리거**할 수 있고,
> ASIL 분해 논거 전체가 무너진다.

**정정 (본 개정의 최대 기여)**: 감시부가 **재구성 허가 신호(RP)** 를 독립·결정론적으로
산출하고, 재구성 게이트 명령은 `정책부 요구 AND 감시부 RP`의 **하드웨어 AND**를
통과해야만 실행되게 한다. RP는 학습 모델을 일절 쓰지 않는다.

RP는 위반 시의 귀착 상태가 다르므로 두 부분으로 분해한다.

```
RP_data (입력 신뢰성)  = (V_dc ∈ 정격 검증 범위) AND (|i_a+i_b+i_c| ≤ ε)
                         AND (개방 서명의 결정론적 확인) AND (시간예산 미초과)
    위반 -> 재구성 보류, S2 체류
RP_env  (실행 포락선)  = (T_j ≤ T_j,max) AND (ω ≤ ω_lim) AND (분리 확인 완료|개방고장)
    위반 -> S4 안전 정지
```

**시뮬레이션이 이 구조의 필요성을 실증한다**:

| 시나리오 | 재구성 후보 | AI 게이트 | ¬RP_data | 통합 차단 |
|---|---|---|---|---|
| ID (정상 분포) | 251 | 5.6 % | 0.0 % | — (가용성 유지) |
| 전류센서 게인이상 | 23 | 100.0 % | 91.3 % | **100 %** |
| 게이트드라이버 열화 | 1,247 | 100.0 % | 0.6 % | **100 %** |
| **800 V 전압클래스** | 3 | **0.0 %** | **100.0 %** | **100 %** |

800 V 근접 OOD는 **AI 측 지표로 전혀 차단되지 않으나** 감시부의 결정론적 전압범위
검사가 100 % 차단한다. 학습 기반 게이팅만으로는 불충분하다는 직접 증거다.

### E-3 [C] `min()` 연산이 회생 구간에서 무력

`T_final = min(T_cmd, T_lim)`은 `T_cmd < 0`(회생)일 때 항상 T_cmd를 통과시킨다.
`min(−250, 200) = −250`. 회생측 포락선이 전혀 적용되지 않는다.

**정정**: `T_final = clamp(T_cmd, −T_lim,regen, +T_lim,drive)` — 부호별 독립 포락선.

### E-4 [M] 3상 전류합 검사의 임계값과 적용 조건 미규정

명세서 스스로 오프셋 드리프트 ±2 %를 도메인 랜덤화에 포함했다.
정격 400 A 기준 채널당 8 A, 3채널 RSS의 3σ = **41.6 A (정격의 10.4 %)**.
임계는 이보다 커야 오검출이 없다.
또한 이 검사는 **3선식 절연 중성점**에서만 유효하며 개방권선·이중 인버터 구성에서는
무효임을 명시해야 한다.

## F. 디지털 트윈 및 자가보정 (700)

### F-1 [C] Sim-to-real 격차 검증 절차 부재

합성 데이터만으로 학습하면 **실차 데이터가 전부 OOD로 판정**될 수 있다
(마할라노비스가 학습 분포를 기준으로 하기 때문). 그러면 게이트가 상시 발동하여
재구성 기능 자체가 죽는다.

**정정**: 실차 정상주행 데이터로 특징 분포 정렬을 검증(MMD 또는 Wasserstein 거리 < 임계)한
후에 배포하고, `μ_train, Σ_train`은 **실차 정상 데이터를 포함**하여 산출한다.

### F-2 [M] 800 V 전압 클래스 미반영
`250~450 V`만 기재되어 400 V급 전용이다. 800 V급(500~900 V) 병기 필요.

### F-3 [M] 단조 보수화 래칫에 의한 가용성 붕괴
안전 방향으로만 이동하는 유한집합 탐색은 차량 생애 동안 **단조 감소**하여
결국 최대 디레이팅에 고착된다.
**정정**: 일시 성분(주행 사이클 단위 리셋)과 영구 성분(래칫)을 분리하고,
완화는 OTA 경로로만 수행한다.

### F-4 [m] 센서 랜덤화 항목 부족
게인 오차, 대역 제한, **위상 지연**을 추가해야 한다. 전류 센서 위상 지연은
Park 벡터 진단에 직접 영향을 준다.

## 요약 — 반드시 고쳐야 할 우선순위

1. **A-1 / A-2** 불확실도 정의를 상호정보량으로 교체 (없으면 발명이 동작하지 않음)
2. **E-2** 감시부의 재구성 허가 신호 도입 (없으면 ASIL 논거가 무너짐)
3. **B-1** 게이팅 유계 체류 및 S4 상승 (없으면 발명이 위험을 만듦)
4. **C-5 ~ C-8** 고장 모드 판별·격리·ASC 암 선택 정정 (없으면 실시하면 사고)
5. **C-1 ~ C-3** B4 모드 3중 제약과 하드웨어 전제 (없으면 실시 불가)
6. **E-1** ASIL 분해를 QM(D)+D(D)로 (없으면 기능안전 주장이 허위)
7. **G-8** 출원서류와 실무 문서 분리
