# 경기장 변화 시스템 v1.0

구현 위치: `07_MVP_Code/src/engine.js` (`STAGES`, `stageFor`, `arenaParams`)

진행도와 난이도를 함께 사용하여 시각/물리 환경을 단계적으로 변경한다.

## 스테이지 결정
```
Stage = progressBand(통과한 골문 수) + floor(difficulty / 25)     (최대 WORLD FINAL)
```
| 통과 골문 수 | 기본 단계 |
|---|---|
| 0~4 | DAY |
| 5~9 | SUNSET |
| 10~19 | NIGHT |
| 20~29 | RAIN |
| 30~49 | WIND |
| 50~79 | STORM |
| 80+ | WORLD FINAL |

> 기준을 "점수"가 아니라 "통과한 골문 수"로 잡은 이유: 점수는 콤보·퍼펙트 보너스 때문에
> 골문 하나당 20점 이상 오른다. 점수 기준으로 두면 6골문 만에 WORLD FINAL 에 도달해
> 연출 단계가 몇 초 만에 끝나버린다.

난이도는 단계를 **가속**한다. 난이도 50이면 시작부터 두 단계 위(NIGHT)에서 출발한다.

## 환경 효과
| 스테이지 | rain | wind | movement 계수 |
|---|---|---|---|
| DAY | 0 | 0 | 0.60 |
| SUNSET | 0 | 0 | 0.75 |
| NIGHT | 0 | 0 | 0.90 |
| RAIN | 1.0 | 0.2 | 1.00 |
| WIND | 0.3 | 1.0 | 1.10 |
| STORM | 1.0 | 1.0 | 1.25 |
| WORLD FINAL | 0.6 | 0.8 | 1.35 |

- RAIN: 빗줄기 연출 + 골문 이동폭 소폭 증가
- WIND: 공에 수평 가속(돌풍)이 붙는다
- STORM: 비 + 바람 + 이동폭 최대
- WORLD FINAL: 최고 난이도 연출

**안전장치**: 환경 효과는 스테이지별 가중치(0~1.35)로만 적용되고, 최종 물리값은
`arenaParams()` 에서 다시 clamp 된다. 모든 효과가 한 번에 최대치로 겹치지 않는다.

## 골문 배치 규칙 (플레이 가능성 보장)
다음 골문의 높이는 **직전 골문에서 실제로 도달 가능한 범위** 안에서만 생성된다.
```
travel = 골문 간격 / speed          다음 골문까지 걸리는 시간
climb  = |flap| * travel * 0.55     그 시간에 올라갈 수 있는 높이
다음 골문 mid ∈ [이전 mid - climb, 이전 mid + climb * 1.6]
```
하강이 상승보다 쉬우므로 아래쪽 여유를 1.6배로 둔다.
이 제약이 없으면 물리적으로 통과 불가능한 배치가 생긴다(실제로 초기 빌드에서 발생했다).
