세 개의 화면을 한 앱에서 다룹니다. 상단에서 전환합니다.

| 화면 | 주소 | 데이터 | 특징 |
| --- | --- | --- | --- |

## 🧠 AI 추천 종목 3선 (`/ai.html`)

“월가와 전세계 정보망을 분석해 3종목을 골라 달라”는 요구를 이렇게 구현했습니다.

### 동작 방식

```
1) 자체 지표 스크리닝     유니버스(미국 27종목 / 한국 12종목)를 신호 엔진으로 전수 계산
                          → 추세·모멘텀·거래량·변동성 상위 10개를 후보로 추림
2) Claude 웹 검색 조사    Claude Opus 5 가 서버측 웹 검색 도구로 직접 조사
                          Reuters·Bloomberg·CNBC·WSJ 등의 최신 뉴스, 실적·가이던스,
                          애널리스트 목표주가, 금리·환율·유가, 아시아·유럽 동향
3) 3종목 제출             strict 스키마 도구로만 결과를 받음
                          (종목·논지·촉매·리스크·신뢰도·기간·출처 URL)
```

**AI가 지어내지 못하게 막은 장치**

- 종목은 **반드시 후보 목록 안에서** 고르게 합니다. 존재하지 않는 티커를 만들 수 없습니다.
  그래도 목록 밖 심볼이 오면 화면에 `후보 목록 밖 · 지표 미검증` 경고가 붙습니다.
- 화면의 **가격·RSI·거래량 배율·진입/손절/목표는 전부 우리 엔진이 계산한 값**입니다.
  AI가 쓴 숫자를 그대로 보여주지 않습니다.
- 뉴스 근거는 **웹 검색으로 확인한 것만** 쓰고, 종목마다 출처 URL을 남기게 했습니다.
- AI가 고른 종목의 기술적 점수가 매도 신호(-20 이하)면 `⚠ 지표는 매도 신호` 배지를 띄웁니다.
- 수익을 단정하는 표현을 금지하고, 종목마다 **리스크를 반드시 함께** 적게 했습니다.

### 설정

```bash
npm install                        # @anthropic-ai/sdk (AI 기능에만 필요)
export ANTHROPIC_API_KEY=sk-ant-...
node server/server.js
```

키가 없어도 화면은 동작합니다. 이때는 AI 분석을 건너뛰고 **기술적 지표 상위 3종목**만
보여주며, 화면과 결과 모두에 `지표 전용 (AI 키 없음)`이라고 표시됩니다.

| 환경변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | — | 없으면 지표 전용 모드 |
| `AI_CACHE_TTL_MS` | `600000` | 같은 조건 재요청 시 캐시 유지 시간(10분) |
| `AI_LOG_DIR` | `logs/` | 추천 이력 저장 위치 |

한 번 실행에 웹 검색이 여러 번 돌아 **30~90초** 걸리고, Opus 5 기준 대략 **$0.1~0.4**가
듭니다. 화면 상단에 토큰 사용량과 예상 비용이 그대로 표시되고,
`logs/ai-recommendations-YYYY-MM-DD.jsonl` 에 이력이 남습니다.

### 화면

- **시장 상황** — 오늘 장 전반에 대한 요약 (검색으로 확인한 내용만)
- **추천 카드 3개** — 논지, 상승 촉매, 리스크, 신뢰도(높음/중간/낮음), 유효 기간,
  우리 엔진이 계산한 지표 스냅샷과 진입·손절·목표, 그리고 출처 링크
- **스캔한 후보 종목** — AI가 무엇을 보고 골랐는지 전체 후보와 점수를 함께 공개

> ⚠️ AI가 최신 뉴스를 읽어도 **미래를 알 수는 없습니다.** 이 결과는 참고 자료이며
> 투자 권유가 아닙니다. 특히 뉴스는 이미 가격에 반영되어 있는 경우가 많습니다.

## ⚡ 한국 초단타 (`/kr.html`)

### 먼저 알아야 할 제약 — 초봉은 만들어 쓰는 것입니다

**KIS OpenAPI가 제공하는 최소 봉 단위는 1분봉입니다.** 10·20·30초봉은 API에 없습니다.
그래서 이 앱은 실시간 체결 틱(WebSocket `H0STCNT0`)을 받아 **직접 초봉으로 집계**합니다.

- 초봉은 **접속한 순간부터** 쌓입니다. 과거 초봉은 소급해서 만들 수 없습니다.
- 1분·3분·5분봉은 REST 분봉으로 과거를 채운 뒤(시딩) 실시간 틱으로 이어붙입니다.
- 지표가 제 값을 내려면 30봉이 필요합니다. 10초봉이면 접속 후 **약 5분**이 지나야 신호가 나옵니다.
  (그동안 화면에 `지표 워밍업 14/30봉` 처럼 진행 상황이 표시됩니다.)

장 시작과 동시에 쓰려면 **08:50쯤 미리 띄워두세요.**

### 설정

```bash
export KIS_APP_KEY=발급받은_앱키
export KIS_APP_SECRET=발급받은_앱시크릿
export KIS_ACCOUNT=12345678-01        # 종합계좌번호-상품코드
export KIS_PAPER=1                    # 1=모의투자(기본), 0=실전
export KIS_HTS_ID=your_hts_id         # (선택) 체결통보 수신용
node server/server.js
```

키가 없으면 자동으로 **데모 모드**로 뜹니다. 가짜 체결틱·호가가 흐르므로 화면과 자동매매 로직을
그대로 확인할 수 있습니다. 상단 배지에 `데모 / 모의투자 / 실전` 중 무엇으로 붙었는지 항상 표시됩니다.

> 자격증명은 환경변수로만 받습니다. 저장소나 코드에 넣지 마세요.
> 접근토큰은 `.kis-token.json`에 캐시됩니다(gitignore 처리, 발급이 분당 1회로 제한되기 때문).

### 화면

- **차트** — 10초/20초/30초/1분/3분/5분봉 + 이동평균선·볼린저밴드·VWAP·자동 추세선·지지/저항, 거래량·RSI·MACD
  봉마다 **매수/매도 체결량과 체결 건수**를 따로 보여줍니다(초단타 수급 판단의 핵심).
- **호가창** — 10단계 잔량 바, 총잔량 불균형(%), 클릭하면 주문 가격에 입력됩니다.
- **체결 테이프** — 최근 체결 22건을 매수/매도 색으로 구분.
- **신호** — 아래 표의 판정을 가중 합산한 -100~+100 점수와 근거.
- **초단타 플랜** — 전부 **호가(틱) 단위**로 계산합니다.
  손절은 ATR을 호가로 환산, 목표는 *수수료+거래세를 덮고도 손익비 1.5가 되는* 호가수로 역산합니다.
  `본전 호가`는 왕복비용을 덮는 데 필요한 최소 호가수입니다 — 이보다 작은 목표는 애초에 손해입니다.
- **수동 주문** — 매수(빨강)/매도(파랑), 전송 전 확인창에서 계좌 종류·금액을 다시 보여줍니다.

### 한국 시장 규칙 반영

| 항목 | 반영 내용 |
| --- | --- |
| 호가단위 | 2023-01-25 개정 구간표 (코스피 7단계 / 코스닥은 5만원 이상 100원 고정) |
| 매매비용 | 매수·매도 수수료 + 매도 시 거래세·농특세 → 플랜의 순손익에 항상 차감 |
| 상·하한가 | ±30% 근접 시 경고 |
| VI | 전일 대비 ±10% 근접 시 정적VI 발동 가능 경고 |
| 장 운영 | 동시호가·시간외에는 신호 점수를 낮추고 자동 진입을 막음 |

초단타 신호는 미국 화면의 지표에 더해 **호가 불균형, 1호가 잔량비, 체결강도, 최근 체결 수급,
스프레드(호가), 순간 거래량 폭증**을 함께 봅니다.

## 🤖 자동매매

**기본값은 꺼져 있고, 모의 실행(dryRun)입니다.** 실제 주문이 나가려면 아래 관문을 전부 통과해야 합니다.

1. `엔진 가동` 체크
2. 킬스위치가 눌리지 않았을 것
3. 정규장 시간일 것 (동시호가·시간외 진입 금지)
4. `모의 실행` 해제
5. **실전 계좌라면 `⚠️ 실전 주문 허용`까지 명시적으로 켤 것**
6. 일일 손실한도 / 일일 주문수 / 동시 보유종목 / 1회 투입액 한도 이내
7. 같은 종목에 진행 중인 주문이 없을 것

하나라도 막히면 주문 대신 **차단 사유가 로그에 남습니다.**

### 안전장치

| 장치 | 기본값 | 설명 |
| --- | --- | --- |
| 킬스위치 | — | 즉시 중단 + 보유분 시장가 청산. **재기동해도 정지 상태가 유지**됩니다 |
| 일일 손실한도 | 30만원 | 도달 시 킬스위치 자동 발동 |
| 1회 투입액 | 100만원 | 초과 주문은 거부 |
| 동시 보유 | 2종목 | |
| 최대 보유시간 | 180초 | 초과 시 무조건 청산 (초단타이므로) |
| 강제청산 시각 | 15:15 | 이후 신규 진입 금지 + 보유분 청산 |
| 재진입 쿨다운 | 30초 | 같은 종목 연속 진입 방지 |
| 스프레드 필터 | 3호가 | 벌어져 있으면 진입하지 않음 |
| 실전 발주 허용 | 재기동 시 **항상 꺼짐** | 사고 방지를 위해 매번 다시 켜야 합니다 |

주문·체결·차단 기록은 `logs/kr-trades-YYYY-MM-DD.jsonl` 에 남습니다.

### 실전에 쓰기 전에

1. **`KIS_PAPER=1` 모의투자로 며칠 돌려보세요.** 신호 품질과 체결 상황을 먼저 확인해야 합니다.
2. TR_ID와 엔드포인트는 `server/kr/config.js` 한 곳에 모아두었습니다.
   KIS가 규격을 개정하면 주문이 `EGW00xxx` 오류로 거절되는데, 그때 이 파일만 최신 문서와 대조해 고치면 됩니다.
   (특히 국내주식 현금주문 TR은 개정 이력이 있어 `alt` 값을 함께 적어두었습니다.)
3. 이 서버는 **주문을 낼 수 있으므로 기본적으로 `127.0.0.1`에만 바인딩**합니다.
   외부에서 접속하려면 `KIS_UI_TOKEN`을 설정해야 하며, 없으면 주문 계열 요청이 모두 거부됩니다.
4. 유량 제한(실전 초당 20건 / 모의 초당 2건)과 실시간 등록 41건 제한을 클라이언트가 스스로 지킵니다.

> ⚠️ **자동매매는 코드가 사용자 돈으로 주문을 냅니다.** 신호 로직의 버그, 시세 지연, 체결 실패,
> 급변동은 모두 실제 손실로 이어지고 되돌릴 수 없습니다. 한도를 반드시 감당 가능한 금액으로 두고,
> 가동 중에는 화면을 지켜보세요.

## 🇺🇸 미국 단타 (`/`)

미국 주식 단타(스캘핑)를 위한 웹 대시보드입니다.
캔들차트 위에 **이동평균선 · 볼린저밴드 · VWAP · 추세선 · 지지/저항 · 피보나치**를 겹쳐 보고,
**RSI · MACD · 스토캐스틱 · 거래량**을 함께 확인하면서, 이 지표들을 종합한 **매매 신호와 ATR 기반 매매 플랜**을 받아볼 수 있습니다.

> ⚠️ 이 앱이 보여주는 점수·신호·플랜은 공개 시세를 이용한 **기술적 계산 결과**이며 투자 자문이나 권유가 아닙니다.
> 실제 매매 판단과 그 결과에 대한 책임은 전적으로 사용자 본인에게 있습니다.

## 실행

```bash
node server/server.js          # http://127.0.0.1:5173
```

| 명령 | 설명 |
| --- | --- |
| `npm start` | 실시간 시세(Yahoo Finance) 사용, 실패 시 데모 데이터로 자동 전환 |
| `npm run demo` | 항상 데모 데이터 (오프라인·사내망 등 외부 접속이 막힌 환경) |
| `npm test` | 지표·신호·초단타·AI 엔진 단위 테스트 |
| `PORT=8080 node server/server.js` | 포트 변경 |

Node.js 18 이상이면 되고, 차트·초단타 기능은 **의존성 없이** 그대로 돕니다.
AI 추천(`/ai.html`)만 `@anthropic-ai/sdk` 가 필요해 `npm install` 을 한 번 실행하면 됩니다.
시세는 API 키가 필요 없는 Yahoo Finance 공개 차트 엔드포인트를 서버가 대신 호출합니다(브라우저 CORS 우회 + 짧은 캐시).
외부 접속이 막혀 있으면 상단 배지가 `데모 데이터`로 바뀌고, 화면 구성과 모든 기능은 동일하게 동작합니다.

## 화면 구성

**왼쪽 — 관심종목 / 시장 지표**
- 관심종목 추가·삭제, 클릭 시 즉시 차트 전환 (브라우저에 저장)
- SPY·QQQ·DIA·IWM·VIX 시세를 곁들여 장 분위기 확인

**가운데 — 차트**
- 캔들 + 거래량 + RSI + MACD + 스토캐스틱 패널
- 겹쳐 그리기: 이동평균선(4개, 기간·SMA/EMA 개별 설정) · 볼린저밴드 · VWAP · 자동 추세선 · 지지/저항 · 피보나치 되돌림 · 회귀 추세선
- 봉 주기 1분 / 2분 / 5분 / 15분 / 30분 / 1시간 / 일봉, 기간은 주기에 맞는 값만 선택 가능
- 마우스 휠 = 확대·축소, 드래그 = 이동, 더블클릭 = 초기화, 십자선으로 봉별 OHLC·거래량·RSI 확인
- ✏️ 버튼으로 **추세선 직접 그리기** (종목·주기별로 저장), CSV 내보내기

**오른쪽 — 신호와 플랜**
- 종합 점수(-100 ~ +100)와 판정: 적극 매수 / 매수 우위 / 관망 / 매도 우위 / 적극 매도
- 점수에 기여한 근거를 가중치와 함께 나열 (예: `이동평균 정배열 (+18)`)
- ATR 기반 진입가·손절가·1·2차 목표·손익비(R:R)
- 포지션 계산기: 계좌 규모와 허용 리스크(%)로 수량·투입금액·최대손실 계산 (매수 여력 초과 시 자동 제한)
- 가격/RSI 도달 알림 (브라우저 알림 + 화면 토스트)

**단축키** — `R` 새로고침 · `/` 검색 · `D` 추세선 그리기

## 신호 엔진이 보는 것

점수는 아래 판정들의 가중 합이며, 각 근거는 화면에 그대로 표시됩니다.

| 구분 | 판정 내용 | 가중치 |
| --- | --- | --- |
| 이동평균 | 정배열/역배열, 단기-중기 골든·데드크로스 | 8 ~ 18 |
| VWAP | 당일 평단 위/아래 (단타의 기준선) | 12 |
| 볼린저밴드 | %B 위치, 밴드 이탈 후 회복, 스퀴즈(밴드폭 백분위) | 6 ~ 12 |
| RSI | 과매수/과매도, 50선 돌파 | 6 ~ 10 |
| MACD | 히스토그램 0선 전환(골든·데드크로스), 부호 | 7 ~ 14 |
| 스토캐스틱 | 과매도/과매수권에서의 %K-%D 교차 | 10 |
| 거래량 | 20봉 평균 대비 배율(급증/부족)과 캔들 방향 | 7 ~ 14 |
| 추세선 | 자동 추세선(스윙 고·저점 연결) 돌파·이탈 | 16 |
| 지지/저항 | 스윙 가격대 군집화 후 근접 여부 | 8 |
| 캔들 패턴 | 장대양·음봉, 망치형, 유성형, 장악형, 도지 | 9 |

**매매 플랜**은 손절을 `1.2 × ATR(14)`로 잡고, 1차 목표는 `1.5R`(가까운 지지/저항이 있으면 그 레벨), 2차 목표는 `2.5R`로 제시합니다.
손익비가 1.5 미만이면 빨갛게 표시되니, 진입 전 손익비부터 확인하세요.

## 알아두면 좋은 점

- **지연 시세입니다.** Yahoo Finance 공개 데이터는 실시간 체결가가 아니라 보통 15분가량 지연됩니다. 실제 초단타 체결에는 증권사 실시간 시세를 쓰세요.
- 자동 새로고침은 봉 주기에 맞춰 20초~5분 간격이며, 백그라운드 탭에서는 멈춥니다.
- 야후 API 제약으로 1분봉은 최근 5일까지만 조회됩니다(주기별로 선택 가능한 기간이 자동 제한됩니다).
- VWAP은 당일 세션 기준이라 일봉에서는 자동으로 비활성화됩니다.
- 관심종목·지표 설정·직접 그린 추세선·알림은 브라우저 localStorage에 저장됩니다.
