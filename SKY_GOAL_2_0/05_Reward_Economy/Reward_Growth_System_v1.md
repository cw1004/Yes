# 보상/성장 시스템 v1.0

구현 위치: `07_MVP_Code/src/engine.js`

## 점수
```
통과 1회: Score += 10 + 2*Combo + PerfectBonus
PerfectBonus = clamp(10 * (1 - |error| / (gap/2)), 0, 10)
```
`error` 는 골문 중앙과 공 중심의 세로 거리. 중앙에 가까울수록 최대 10점.
`|error| <= gap * perfectWindow(기본 0.12)` 이면 **퍼펙트**로 집계되고 골드 파티클이 터진다.

## 코인
```
CoinReward = round(10 + 25 * ln(score + 1)) × 공 보너스 × 모드 배율
모드 배율: 아마추어 1.0 / 프로 1.6
```
0점이어도 10코인은 지급해 실패한 판도 완전한 손실이 되지 않게 한다.

## XP / 레벨
```
XPReward   = (20 + score*1.5 + perfectCount*5) * (1 + difficulty/200) * 모드 배율
XP_required(L) = 100 * L^1.5
```
난이도가 높을수록 XP 가 최대 1.475배까지 늘어난다(고난도 플레이 보상).

## 조각과 장비

한 판을 끝낼 때마다 **등급 조각 1개**를 받는다.

| 등급 | 기본 확률 |
|---|---|
| Common | 60% |
| Rare | 25% |
| Epic | 10% |
| Legendary | 5% |

```
Legendary = clamp(5 + (D-50)/100*10 + (LUCK-50)/50, 5, 12)   // 최대 12%
Common    = 100 - Legendary - Epic - Rare                     // 나머지에서 차감
```

조각은 그 자체로는 쓸모가 없다. **모아서 원하는 장비를 직접 만든다.**

| 등급 | 제작 비용 | 분해 시 코인 |
|---|---|---|
| Common | 5조각 | 20 |
| Rare | 8조각 | 60 |
| Epic | 12조각 | 150 |
| Legendary | 15조각 | 400 |

랜덤 뽑기가 아니라 **지정 해금**이다. 확률형 아이템 규제를 피하려는 이유도 있지만,
그보다 "모으면 반드시 그것을 받는다"가 더 강한 동기이기 때문이다.
확률이 어린이에게 주는 것은 기대가 아니라 불신이다.

### 소모품 — 경기 전 하나

원버튼 게임에 "사용 버튼"을 만들지 않는다. 두 번째 버튼이 생기는 순간
이 게임의 조작이 무너진다. 그래서 소모품은 **경기 시작 시 자동으로 소비**되고
조건이 되면 알아서 발동한다.

| 소모품 | 가격 | 효과 |
|---|---|---|
| 워밍업 드링크 | 80코인 | 첫 5골문 간격 +12% |
| 테이핑 | 150코인 | 첫 사망 시 되감기 1회 (COMBO 유지) |
| 스카우팅 리포트 | 300코인 | 골문 흔들림 -30% |
| 홈 어드밴티지 | 600코인 | 코인 · XP +40% |

### 밸런스 상한

| 대상 | 상한 | 이유 |
|---|---|---|
| 장비 코인·XP 배율 | **+30%** | 스탯·공 보정과 겹쳐도 점수 인플레가 나지 않게 |
| 장비 물리 보정 | **±15%** | 장비로 게임이 쉬워지는 것을 막는다 |
| 충돌 무효 | 판당 1회 | 골키퍼 장갑 |
| 부활 | 판당 1회 | 골든 휘슬(장비) > 테이핑(소모품) 우선순위 |
| **PRO 모드 부활** | **전면 비활성** | 기록 공정성 |

소모품 배율은 장비 상한 **위에** 곱해진다. 한 판 쓰고 사라지는 값에
장비와 같은 상한을 걸면 살 이유가 없어지기 때문이다.

> 보정 집계는 `engine.js` 의 `runMods()` **한 곳에서만** 한다.
> 여러 곳에 흩어지면 상한을 지키는지 아무도 확인할 수 없게 된다.

### AI 난이도와의 관계

AI 난이도 엔진은 **장비 보정이 적용된 뒤의 실제 성공률**을 읽는다.
장비로 쉬워진 만큼 난이도가 따라 올라가므로 밸런스가 스스로 맞춰진다.
조작 설정 슬라이더와 같은 원리다.

## 헤딩 보너스
```
HeaderBonus = 40 + 4 × Combo        (콤보 30에서 상한)
```
낮게 나는 위험을 감수했을 때만 발동하므로 콤보 유지 중일수록 크게 돌려준다.
콤보도 +1 되어 이후 통과 점수까지 함께 올라간다.

마지막 스테이지(WORLD FINAL) 도달 시 1회 지급.

| 조건 | 지급 |
|---|---|
| 골든볼 미보유 | 2030 골든볼 (정가 3000코인) 무료 + 즉시 장착 |

이후 수급이 빨라지는 완만한 복리 구조다.

## 성장 스탯
레벨업 1회당 **스탯 포인트 1점**(스탯 +2)을 지급하고, 결과 화면에서 직접 배분한다.

| 스탯 | 효과 |
|---|---|
| CONTROL | 골문 간격 체감 +, 골문 흔들림 -, 퍼펙트 판정 폭 + |
| POWER | 탭 1회의 상승력 + |
| SPEED | 체감 스크롤 속도 - |
| LUCK | Legendary 확률 + |
| STAMINA | 중력 - (체공 시간 +) |

모든 보정은 ±10~20% 이내로 제한된다.

## 안티 프러스트레이션
- 최근 10게임 성공률 < 65% → 난이도 -5
- 65~80% → 유지
- \> 80% → 난이도 +5
- 조기 사망(3초 미만/통과 0개)에는 추가로 -3
- 한 판당 난이도 변화는 ±5 이내
