# 출원 실무 체크리스트

> 본 문서는 **명세서 본문이 아니다.** 출원서류에 포함시키지 말 것.
> 초안에서는 이 내용이 명세서와 한 파일에 섞여 있었다(결함 G-8).

## 1. 신규사항 추가 금지 원칙 대응 현황

출원 후 보정으로는 새로운 기술사항을 추가할 수 없다(특허법 제47조 제2항).
따라서 아래 항목은 **출원 시점에 명세서에 들어 있어야 한다.**

| 항목 | 초안 상태 | 보정판 상태 |
|---|---|---|
| 인식적 불확실도 산출 알고리즘 | 차원 불일치·상한 초과로 **실질적 부재** | 상호정보량 정의로 기재 완료 |
| 분포외 판정의 독립 지표 계열 | 엔트로피 기준(정보량 0)만 | 입력·잠재 기하 지표 + 상호정보량 기재 완료 |
| 감시부의 재구성 허가 신호 | **전면 부재** | (600)(B) 및 청구항 2·24·25에 기재 완료 |
| 게이팅의 유계 체류·안전정지 상승 | **부재** | (300) 및 청구항 3(d)·13에 기재 완료 |
| 고장 모드 분기 (단일스위치/상 개방 구분) | 혼동 기재 | (400) 및 종속항 14에 기재 완료 |
| ASC 암 선택 | **부재** (하암 고정 기재) | 종속항 17에 기재 완료 |
| B4 3중 제약 | 전압 제약만, 값도 오류 | (400) 및 종속항 19에 기재 완료 |
| 직렬 차단 소자 배치 실시예 | 위치 미정의 | (a)/(b)/(c) 3실시예 기재 완료 |
| 임계치 결정 절차 (FIT·GPD·이중제약) | 절차만, 단위 미정의 | 산출식 및 수치 기재 완료 |
| 캘리브레이션 검증 | 컨포멀 오용 | Venn–Abers로 정정, 순서 규정 완료 |
| 계층적 시간 예산 | 지연만 규정 | 주기·지터·무효화 규칙 기재 완료 |
| **시뮬레이션 결과** | **미기재** | **기재 완료** (`sim/` 재현 가능) |
| 도면 | 13종 미작성 | **15종 전부 작성 완료** (`sim/results/figures/`) |

      (`python3 sim/patent_figs/fig_01_04.py` 등으로 재생성 가능)

      (도 8·10·11의 근거 강화). 소요 1~2주
- [ ] `R_g` 절환에 따른 `t_d(off)` 증가분 실측 (종속항 20의 수치 뒷받침). 소요 1주
- [ ] HIL 검증 — 대학 산학협력단 또는 지역 테크노파크 장비. 소요 1~2개월

### 시뮬레이션 실시예 재현 방법

```bash
cd sim
pip install numpy scipy matplotlib
sudo apt-get install -y fonts-nanum     # 도면의 한글 표기용

python3 check_numerics.py               # 초안 수치 주장의 독립 검증
python3 run_embodiment.py               # 실시예 본체 (약 3~5분)
python3 make_figures.py                 # 도 5, 도 15 (시뮬레이션 결과)
python3 patent_figs/fig_01_04.py        # 도 1 ~ 도 4
python3 patent_figs/fig_06_09.py        # 도 6 ~ 도 9
python3 patent_figs/fig_10.py           # 도 10
python3 patent_figs/fig_11_14.py        # 도 11 ~ 도 14
```

산출물: `sim/results/embodiment_results.json` 및
`sim/results/figures/fig01 … fig15` (도면 15종, 흑백 선화 PNG 220 dpi).

## 4. 주의 — 효과 기재의 진실성

초안 효과란의 "검증셋 오분류 사례의 95 %에서 재구성이 자동 보류된다"는 실측 없는 단정이었다.
보정판에서는 시뮬레이션 실시예의 실제 수치로 대체하였고, 하드웨어 계측이 아님을 명기하였다.
**측정하지 않은 수치를 효과로 단정하는 것은 기재불비 또는 무효사유가 될 수 있다.**
