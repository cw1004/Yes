# 하나의 길 — ONE WAY

> 하나의 믿음 · 하나의 사랑 · 하나의 길

**신앙에 질문이 있는 사람이라면 누구나 들어올 수 있는 공간**을 그대로 코드로 옮긴
홈페이지입니다. 핵심은 배너나 홍보가 아니라 **AI 상담사**입니다.

```
사람의 고민 → 검색 → 짧은 콘텐츠 → AI 상담사(먼저 들음)
           → 50가지 콘텐츠 → 하루 3분 → 기도 지향 → 재방문 → 공동체
```

```bash
python3 -m oneway serve        # 홈페이지 띄우기 → http://127.0.0.1:8000
python3 -m oneway ask          # 터미널에서 상담사와 대화해 보기
python3 -m oneway check        # 환경 점검
```

**외부 API 키가 없어도 전부 동작합니다.** 키가 없으면 규칙 기반 상담 엔진이,
키가 있으면 Claude 가 답합니다. 방문자는 어느 쪽인지 몰라도 됩니다.

## 1. 이 사이트가 다른 교회 홈페이지와 다른 점

| 보통의 교회 홈페이지 | 하나의 길 |
| --- | --- |
| 교회 소개 · 예배 시간 · 오시는 길 | 사람이 실제로 검색하는 **질문**이 첫 화면 |
| 방문자는 읽고 나감 | 상담사가 **말을 걺** → 대화가 시작됨 |
| 한 번 보면 끝 | 하루 3분 · 연속 방문 · 기도 지향 → **다시 올 이유** |
| 처음부터 "우리 교회로 오세요" | 교파 소개는 **5단계**에 배치, 선택은 방문자가 |

## 2. 설치와 실행

```bash
# 1) 파이썬 3.9 이상이면 됩니다. 추가 설치 없이 바로 실행됩니다.
python3 -m oneway check

# 2) 홈페이지 띄우기
python3 -m oneway serve --port 8000
#    → http://127.0.0.1:8000

# 3) (선택) 상담 품질 올리기 — Claude 연결
pip install anthropic
export ANTHROPIC_API_KEY=sk-ant-...
python3 -m oneway serve
```

`make` 를 쓰신다면:

```bash
make serve PORT=8080     # 홈페이지
make ask                 # 터미널 상담
make today               # 오늘의 3분
make site                # 정적 사이트 내보내기
make test                # 테스트
```

## 4. AI 상담사가 답하는 순서

```
입력
 ├─ ① 안전 점검 (safety.py)
 │     위기 신호면 → 신앙 이야기를 멈추고 24시간 상담 전화부터 안내
 ├─ ② 주제 분류 (topics.py) — 단서가 없으면 직전 주제를 이어받음
 ├─ ③ 응답 생성  Claude 가 있으면 Claude, 없거나 실패하면 규칙 엔진
 ├─ ④ 콘텐츠 연결  50가지 2개 + 입구 1개 + 하루 3분
 └─ ⑤ 다시 올 이유  연속 방문 일수 / 내일 예고 / 맡긴 기도 되묻기
```

응답은 언제나 다섯 조각입니다.

| 조각 | 하는 일 |
| --- | --- |
| **공감** | 먼저 듣는다. "그래도"로 시작하지 않는다 |
| **관점** | 왜 그런 마음이 드는지 한 단락 |
| **말씀** | 성경 **주소만**. 번역문은 싣지 않는다 |
| **질문** | 스스로 답해 볼 질문 하나 — 회차가 올라갈수록 깊어진다 |
| **한 걸음** | 오늘 안에 끝낼 수 있는 아주 작은 행동 |

### 안전 원칙 (타협하지 않는 부분)

* 위기 표현이 감지되면 **모델을 호출하지 않고** 규칙 기반 안내문을 먼저 띄웁니다.
  AI 출력에 사람 목숨을 맡기지 않습니다.
* "힘들어 죽겠다" 같은 관용 표현은 위기로 오인하지 않습니다(테스트로 고정).
* 우울이 2주 이상 이어진다는 말에는 진료를 권하되, **믿음과 무관하다**고 분명히 말합니다.
* 모든 페이지 하단에 자살예방 상담전화 **109** 가 항상 노출됩니다.
* 상담사가 AI라는 사실을 숨기지 않습니다.

> 전화번호는 바뀔 수 있습니다. 실제 운영 전에 `oneway/counselor/safety.py` 의
> `HOTLINES_KR` 을 최신 정보로 반드시 확인하십시오.

## 5. 재방문을 만드는 4가지 장치

| 장치 | 주기 | 구현 |
| --- | --- | --- |
| 하루 3분 | 매일 | `content/daily.py` — 날짜만으로 결정되어 서버 저장이 필요 없음 |
| 우리가 함께 믿는 50가지 | 50일 | `content/fifty.py` |
| 30일 사랑의 실천 | 30일 | `daily.LOVE_30` |
| 맡긴 기도 되묻기 | 비정기 | `counselor/session.py` — "그 일은 어떻게 되었습니까?" |

50일과 30일 두 바퀴가 겹쳐 돌기 때문에 **같은 조합은 150일에 한 번**만 돌아옵니다.
(테스트로 고정되어 있습니다.)

## 6. 검색 유입 구조

* 색인 대상 **66개 URL** — 50가지 50개 + 입구 7개 + 고정 페이지 4개 + 핵심 5개
* 각 페이지는 메뉴 이름이 아니라 **사람이 실제로 검색하는 문장**을 제목으로 씁니다.

| 페이지 | 검색 제목 |
| --- | --- |
| 21 | 성경에서 가장 큰 계명은 무엇일까? 사랑에 대한 예수님의 대답 |
| 28 | 용서하기 어려운 사람을 어떻게 용서할 수 있을까? |
| 41 | 가톨릭과 개신교는 왜 다를까? 서로 다른 전통을 이해하는 방법 |
| 45 | 교회를 떠났지만 하느님을 완전히 떠난 것은 아닙니다 |

* 모든 페이지에 `canonical` · Open Graph · JSON-LD 구조화 데이터가 들어갑니다.
* `robots.txt` 는 구글과 네이버(Yeti) 를 모두 허용합니다.
* 소유확인 코드는 설정으로 넣습니다.

```bash
python3 -m oneway sitemap --site-url https://내도메인.kr
```

```json
{
  "site_url": "https://내도메인.kr",
  "naver_verify": "네이버 서치어드바이저 코드",
  "google_verify": "구글 서치콘솔 코드"
}
```

```bash
python3 -m oneway serve --config config.json
```

## 7. 저작권 · IP 위험 관리

이 부분은 코드보다 중요합니다.

### 안전하게 처리한 것

* **성경 번역문을 한 줄도 싣지 않습니다.** 한국어 번역본(성경·공동번역·개역개정·
  새번역 등)은 각 발행처에 권리가 있습니다. 이 사이트는 *어느 대목인지*(주소)만
  알려 주고, 내용은 **우리가 직접 쓴 한 줄 설명**으로 대체합니다.
  → `oneway/content/verses.py` 의 `gist` 필드. 테스트로도 강제합니다.
* 가톨릭 표기와 개신교 표기를 **둘 다** 보여 줍니다 (마태 11,28 / 마태복음 11:28).
* 본문·질문·기도문·실천 항목은 전부 이 저장소에서 새로 쓴 창작물입니다.

### 운영 전에 확인해야 할 것

| 항목 | 해야 할 일 |
| --- | --- |
| 이름 「하나의 길 / ONE WAY」 | 상표 검색 필수. "ONE WAY"는 일반 명사에 가까워 **단독 상표 등록이 어려울 수 있습니다.** 로고를 결합한 도형상표를 함께 검토하십시오 |
| 로고·심볼 | 디자인권 + 상표 출원 (9·16·41·45류 검토) |
| 기도문·본문 | 저작권은 창작과 동시에 발생. 별도 등록은 분쟁 대비용 |
| 상담 흐름·AI 난이도 조절 | 단순 아이디어는 특허 대상이 아닙니다. **기술적 구현 방식**이 있어야 검토 가능 |
| 개인정보 | 이름·연락처를 받지 않는 현재 구조를 유지하십시오. 받는 순간 처리방침·동의·보관기간 의무가 생깁니다 |
| 아동·청소년 | 미성년자 접근을 전제로 설계했습니다. 광고·결제 유도를 넣지 마십시오 |

### 하면 안 되는 것

* 다른 단체의 묵상집·기도문·설교를 그대로 가져오기
* 특정 교단 로고·명칭을 허락 없이 쓰기
* 상담 대화를 동의 없이 수집해 학습에 쓰기

## 8. 개인정보 처리

* 받는 것: 무작위 세션 ID **하나** (쿠키 `ow_sid`, HttpOnly, SameSite=Lax)
* 받지 않는 것: 이름 · 이메일 · 전화번호 · 생년월일
* 기도 지향은 **공개되지 않습니다.** 공개되는 것은 "오늘 N개"라는 숫자뿐입니다.
* 오래된 기록은 지웁니다.

```bash
python3 -m oneway purge --days 180
```

`data/` 폴더는 `.gitignore` 에 있습니다. **절대 커밋하지 마십시오.**

## 9. 배포

### 가장 간단한 방법 — 서버 하나

```bash
python3 -m oneway serve --host 0.0.0.0 --port 8000 --site-url https://내도메인.kr
```

앞에 nginx 를 두고 HTTPS 를 붙이면 됩니다. 표준 라이브러리 서버라 트래픽이 아주
커지면 WSGI/ASGI 로 옮기십시오. 그때 바뀌는 파일은 `web/server.py` 하나입니다.

### 정적 + API 분리 (검색 노출에 유리)

```bash
python3 -m oneway build --clean --site-url https://내도메인.kr
# → out/site/ 66개 페이지 + sitemap.xml + robots.txt + 404.html
```

`out/site` 를 Netlify·Vercel·GitHub Pages 에 올리고, 상담 API(`/api/*`)만
서버로 띄우면 됩니다.
