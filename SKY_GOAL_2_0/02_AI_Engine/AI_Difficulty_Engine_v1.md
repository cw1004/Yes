# SKY GOAL 2.0 — AI 난이도 엔진 v1.0

구현 위치: `07_MVP_Code/src/engine.js`
검증: `07_MVP_Code/tests/engine.test.js`

## 1. 목적
플레이어의 최근 플레이 데이터를 분석하여 목표 성공률을 유지하면서 난이도를 자동 조정한다.
본 버전은 ML 모델이 아닌 **설명 가능한 적응형 규칙 엔진(Adaptive Rule Engine)** 이다.
결과 화면에 "왜 난이도가 이렇게 바뀌었는지" 근거를 그대로 보여준다.

## 2. 입력 데이터
| 필드 | 의미 |
|---|---|
| `survivalTime` | 누적 생존 시간(초) |
| `passCount` | 누적 골문 통과 수 |
| `attemptCount` | 누적 시도 수 |
| `maxCombo` | 최대 콤보 |
| `tapIntervalCV` | 탭 간격 변동계수(표준편차/평균) |
| `recentScores` | 최근 10게임 점수 |
| `recentSuccesses` | 최근 10게임 성공(1)/실패(0) — 성공 기준은 10점 이상 |
| `perfectCount` | 퍼펙트 통과 수 |
| `winStreak` / `loseStreak` | 연속 성공·실패 카운터 |

## 3. 플레이어 숙련도 S
```
A = norm(survivalTime / games,      2 ~ 60)     생존
R = norm(passCount / attemptCount,  0.2 ~ 9)    시도당 통과 골문 수
C = norm(maxCombo,                  1 ~ 20)     콤보
T = norm(1 / (1 + tapIntervalCV),   0.45 ~ 0.9) 탭 안정성
K = norm(mean(recentScores),        0 ~ 120)    최근 성과

S_raw = 0.30A + 0.25R + 0.20C + 0.15T + 0.10K
S_t   = 0.70 * S_prev + 0.30 * S_raw            (0 ~ 100)
```
지수 평활(0.7/0.3)을 쓰기 때문에 한 판의 운으로 숙련도가 튀지 않는다.

## 4. 난이도 D
```
D_target = clamp(0.85 * S + 8 + F, 10, 95)
D_next   = D_prev + clamp(D_target - D_prev, -5, +5)
```
피드백 항 F:

| 조건 | F |
|---|---|
| 3연속 성공 | +5 |
| 3연속 실패 | -5 |
| 조기 사망(3초 미만 또는 통과 0개) | -3 |
| 콤보 10 이상 | +4 |
| 최근 10게임 성공률 > 0.80 | +5 |
| 최근 10게임 성공률 0.65 ~ 0.80 | 유지 |
| 최근 10게임 성공률 < 0.65 | -5 |

성공률 판정은 표본이 3게임 이상 쌓인 뒤부터 적용한다.
**한 게임당 난이도 변화량은 최대 ±5** 로 제한되어 실패 연쇄 후 난이도가 급변하지 않는다.

## 5. 경기장 파라미터
```
gap      = max(145, 220 - 0.9D)      골문 간격
speed    = 210 + 2.8D                스크롤 속도(px/s)
movement = 0.05D * 스테이지 계수     골문 상하 이동
wind     = max(0, (D-35)/60) * 스테이지 계수
rain     = 스테이지가 RAIN 이상일 때 활성
gravity  = 950, flap = -340          (성장 스탯으로 ±10% 내 보정)
```
성장 스탯 보정은 전부 소폭(±10~20%)으로 제한해 "스탯만 올리면 쉬워지는" 붕괴를 막는다.
최종 값은 `gap 130~260`, `speed 180~560` 으로 다시 clamp 된다.

## 6. 목표와 검증
- 플레이어별 체감 성공률 **65~80%** 구간을 우선한다.
- 난이도는 점진적으로 변하며 급격한 실패 연쇄를 방지한다.
- `tests/engine.test.js` 의 시뮬레이션 테스트가 다음을 자동 검증한다.
  - 숙련 플레이어의 D 상승 / 초보 플레이어의 D 하강
  - 120게임 동안 한 판당 변화량이 ±5 를 넘지 않음
  - D 가 10~95 범위를 벗어나지 않음
