# 배경음악(BGM) 넣는 곳

이 폴더에 mp3 / wav / m4a 파일을 넣고 아래처럼 실행하면 자동으로 깔립니다.

```bash
python3 -m india2030 make --range 1-100 --bgm assets/bgm
```

- 파일이 여러 개면 회차 순서대로 돌아가며 사용됩니다(`(회차-1) % 트랙수`).
- 특정 곡 하나만 쓰려면 파일 경로를 직접 지정하세요: `--bgm assets/bgm/theme.mp3`
- 볼륨은 `--bgm-gain -18` 처럼 dB 로 조절합니다(기본 -20dB).
- **저작권**: 상업적 업로드 시 라이선스가 확인된 음원만 사용하세요.
