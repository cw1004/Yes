# KIS 대시보드 안드로이드 앱

집 PC 에서 돌아가는 자동매매 시스템(`python -m kis web`)에 붙어 계좌를 확인하고
급할 때 매매를 멈추는 네이티브 앱입니다.

## 왜 이런 구조인가

```
[집 PC / 서버]                              [안드로이드 폰]
 kis 엔진 (24시간 매매)                       앱: 조회 · 비상정지 · (선택) 주문
 KIS Open API 앱키·시크릿 보관                 서버 주소 + 접속 토큰만 보관
 kis web  ──── REST /api/* ────────────────▶
```

**앱키와 시크릿은 앱에 넣지 않습니다.** APK 는 디컴파일이 쉬워서 키를 심으면 그대로
노출되고, 그 키로 남이 계좌에 주문을 낼 수 있습니다. 매매와 인증은 전부 서버가 하고,
앱은 서버가 발급한 접속 토큰만 들고 있습니다. 토큰이 새더라도 피해 범위는 그 서버가
허용한 동작(기본값: 조회 + 매매 중단)으로 제한됩니다.

## 모듈

| 모듈 | 내용 | 검증 |
|------|------|------|
| `core` | 모델 · JSON 파싱 · HTTP 클라이언트 · 표시 포맷 · 사설망 판별 | JVM 유닛 테스트 30개 + 실서버 통합 테스트 5개 |
| `app` | Compose UI, ViewModel, 암호화 토큰 저장 | 기기/에뮬레이터에서 실행 확인 필요 |

`core` 는 안드로이드에 의존하지 않는 순수 Kotlin 입니다. 덕분에 통신 계층 전체를
PC 에서 `./gradlew :core:test` 만으로 검증할 수 있고, 안드로이드 모듈은 화면 그리는
일만 맡습니다.

## 빌드

1. **Android Studio** (Ladybug 이상 권장) 에서 `android/` 폴더를 엽니다.
2. Gradle 동기화가 끝나면 `app` 을 실행합니다. 최초 동기화 때 SDK 를 내려받습니다.
3. 명령줄로 빌드하려면:

```bash
cd android
./gradlew :core:test          # 순수 Kotlin 테스트 (에뮬레이터 불필요)
./gradlew :app:assembleDebug  # APK 생성 → app/build/outputs/apk/debug/
```

요구 사항: JDK 17 이상(Android Studio 번들 JBR 로 충분), compileSdk 35, minSdk 26.

## 앱 사용법

1. PC 에서 서버를 띄웁니다.

   ```bash
   python -m kis web --host 0.0.0.0 --watch 005930,000660
   # 주문까지 하려면
   python -m kis web --host 0.0.0.0 --allow-control --watch 005930,000660
   ```

2. 터미널에 출력된 **주소와 토큰**을 앱 첫 화면에 입력합니다.
   주소는 `192.168.0.5` 처럼 IP 만 넣어도 됩니다(`http://` 와 `:8000` 은 자동으로 붙습니다).
3. 연결되면 대시보드가 뜨고, 화면이 켜져 있는 동안 서버가 정한 주기(기본 10초)로 갱신됩니다.

## 화면에서 할 수 있는 일

| 동작 | 서버 기본값 | `--allow-control` |
|------|-------------|-------------------|
| 순자산 · 당일손익 · 보유 종목 · 미체결 · 시세 · 주문 기록 조회 | ✅ | ✅ |
| **매매 즉시 중단** | ✅ | ✅ |
| 매매 재개 | ❌ | ✅ |
| 미체결 주문 취소 | ❌ | ✅ |
| 수동 주문 | ❌ (카드 자체가 숨겨짐) | ✅ |

매매를 **멈추는** 방향은 언제나 허용됩니다. 폰을 잃어버려도 기본 설정에서는 남이
주문을 낼 수 없습니다.

## 앱이 지키는 안전장치

- **토큰은 암호화해 저장**합니다(`EncryptedSharedPreferences`). 클라우드 백업과 기기
  이전에서 앱 데이터를 통째로 제외해 토큰이 밖으로 나가지 않게 했습니다.
- **공인 IP 경고**: 대시보드는 평문 HTTP 입니다. 사설 대역(192.168.x.x, 10.x.x.x,
  172.16~31.x.x, 100.64.x.x)이나 HTTPS 가 아닌 주소를 입력하면 연결 전에 경고합니다.
- **주문 전 확인 창**: 주문·취소·매매재개는 모두 확인 창을 거칩니다.
- **연타 방지**: 처리 중에는 다음 동작을 받지 않아 주문이 두 번 나가지 않습니다.
- **수량은 서버가 정합니다**: 서버가 리스크 한도로 수량을 줄이면 앱은 접수된 수량을
  그대로 보여줍니다("100주 → 13주로 줄였습니다").
- **가격은 호가 단위로만**: 주문 화면의 가격은 ± 버튼으로 한 틱씩 움직여, 서버가
  거부할 값을 만들지 않습니다.
- **토큰 만료 처리**: 서버를 재시작해 토큰이 바뀌면 401 을 받고 저장된 토큰을 지운 뒤
  설정 화면으로 돌아갑니다.

## 서버와의 계약

앱이 쓰는 엔드포인트입니다. 서버 쪽 구현은 `kis/web/app.py` 에 있습니다.

| 메서드 | 경로 | 인증 | 용도 |
|--------|------|------|------|
| GET | `/api/health` | 없음 | 주소가 맞는지 확인(계좌 정보 없음) |
| GET | `/api/config` | 필요 | 토큰 확인 + 제어 허용 여부·갱신 주기 |
| GET | `/api/snapshot` | 필요 | 요약·보유·미체결·시세·기록 한 번에 |
| POST | `/api/halt` | 필요 | `{"on": true/false}` 매매 중단/재개 |
| POST | `/api/cancel` | 제어 | `{"order_no", "org_no"}` |
| POST | `/api/cancel-all` | 제어 | 미체결 전량 취소 |
| POST | `/api/order` | 제어 | `{"symbol","side","quantity","price","market"}` |

인증은 `X-Auth-Token` 헤더로만 보냅니다. 쿠키를 쓰지 않으므로 CSRF 가 성립하지 않고,
토큰이 URL 이나 접근 로그에 남지 않습니다.

### 계약이 깨지지 않았는지 확인하기

서버 JSON 의 필드 이름이 바뀌면 앱이 조용히 0 을 표시하게 됩니다. 가짜 응답으로 하는
단위 테스트는 이런 버그를 못 잡으므로, 실제 서버에 붙는 통합 테스트를 함께 둡니다.

```bash
# 1) 서버를 띄우고
python -m kis web --allow-control --token TESTTOKEN --watch 005930

# 2) 실제 서버에 붙여 테스트
cd android
KIS_TEST_SERVER=http://127.0.0.1:8000 KIS_TEST_TOKEN=TESTTOKEN ./gradlew :core:test
```

`KIS_TEST_SERVER` 가 없으면 이 테스트들은 자동으로 건너뜁니다.

## 알아둘 점

- 백그라운드에서는 갱신하지 않습니다. 화면이 켜져 있을 때만 폴링해 배터리를 아낍니다.
  푸시 알림은 없습니다 — 필요하면 서버 쪽에 알림 발송을 붙이는 편이 맞습니다.
- 집 밖에서는 서버에 닿지 않습니다. 포트포워딩으로 여는 대신 Tailscale 같은 VPN 을
  쓰세요. VPN 을 쓰면 100.64.x.x 대역이라 앱도 안전한 주소로 인식합니다.
- 앱은 조회·제어만 합니다. 전략 수정이나 엔진 실행은 PC 에서 합니다.
