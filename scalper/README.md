# ⚡ 3분할 실시간 스캘핑 트래커

SLOT 1 / 2 / 3 이 **각각 독립적으로** 한 종목씩 실시간 추적하면서 매수·매도 타이밍
신호를 보내고, 원하면 자동으로 진입·청산까지 합니다.
여기에 **미 증시 뉴스 팩트 수집**과 **세계 정세·거시경제 판독**을 붙여, 기술적 신호
하나만 보고 들어가지 않도록 만들었습니다.

```bash
python3 -m scalper run                      # 시뮬레이션 (키 없이 바로 실행)
python3 -m scalper run --live --auto        # 실 시세 + 신호 기록
python3 -m scalper run --live --auto --broker alpaca   # Alpaca 페이퍼 계좌로 실제 주문
```

실행하면 http://127.0.0.1:8787 에 대시보드가 뜹니다.

## 2. 매수 신호 — 8가지 로직 (합 100점)

| 로직 | 배점 | 조건 |
|---|--:|---|
| VWAP 안착 | 18 | 종가가 VWAP 위. 단타의 기준선 |
| 정배열 | 16 | MA5 > MA20, MA20 우상향이면 만점 |
| 골든크로스 직후 | 12 | 최근 6봉 내 MA5의 MA20 상향 돌파, 최근일수록 높게 |
| 거래량 급증 | 16 | 20봉 평균 대비 1.6배 이상 |
| RSI 모멘텀 | 14 | 55~72 만점, 45~55 부분점, 72 초과는 추격 금지 |
| 볼린저 스퀴즈 | 8 | 밴드폭이 최근 60봉 하위 30% + 중심선 위 |
| MACD 상승전환 | 10 | 히스토그램 음→양 전환 |
| 음봉 후 반전 | 6 | 직전 음봉 다음 양봉이 전 시가 회복 |

여기에 보정이 더해집니다.

```
최종점수 = 기술점수(0~100)  +  뉴스 보정(±12)  +  매크로 보정(±8)
```

배경 정보가 기술 신호를 통째로 뒤엎지 못하되, **경계선에 걸친 판단은 확실히 갈리는** 폭입니다.

### 매도 신호 (합 100점, 50점 이상에서 발동)

RSI 과매수 30 · MA5 이탈 25 · 고점 꺾임 20 · 음봉+거래량 15 · MACD 하락전환 10

## 3. 뉴스: "사실"을 점수로 바꾸는 방법

단어 감성만 보면 "Nvidia stock **falls** after **record** earnings" 같은 헤드라인에서
방향을 잘못 잡습니다. 그래서 2단 구조로 갑니다.

1. **이벤트 분류가 먼저** — 실적 서프라이즈, 가이던스 상·하향, 목표주가 조정, 리콜,
   규제·소송, M&A, 파산, 수출규제·관세 등 20종을 정규식으로 잡고 방향×강도로 ±70점을 만듭니다.
2. **어휘 감성은 보정만** — ±25점 안에서만 움직이고, 앞 3단어 안에 부정어가 있으면 뒤집습니다.

그리고 종합할 때:

- **최신성 반감기 2시간** — 장중 단타에서 어제 뉴스가 지금 틱을 지배하면 안 됩니다.
- **표본 신뢰도** — 5건이 모여야 100% 반영. 1건짜리 뉴스로 베팅하지 않습니다.
- **신선도 계수** — 가장 최근 기사조차 오래됐다면 절대 영향력 자체를 낮춥니다.
- **중복 제거** — 같은 기사가 여러 매체에 실려도 1건으로 셉니다.

```bash
python3 -m scalper news NVDA TSLA
```

수집원: Finnhub(키 있으면) → Marketaux(키 있으면) → Yahoo Finance RSS → Nasdaq RSS.
**키가 없어도 RSS로 동작합니다.**

## 4. 세계 정세 · 거시경제

"오늘 시장이 위험을 사는 날인가, 파는 날인가"를 숫자 하나로 만듭니다.

| 재료 | 출처 | 읽는 법 |
|---|---|---|
| VIX | FRED `VIXCLS` | 14 미만 안정 / 24 초과 공포 |
| 하이일드 스프레드 | FRED `BAMLH0A0HYM2` | 확대 = 신용 경색 신호 |
| 장단기 금리차 | FRED `T10Y2Y` | 역전 = 경기 경계 |
| 10년물 금리 변화 | FRED `DGS10` | 급등 = 성장주 부담 |
| 달러지수 | FRED `DTWEXBGS` | 강세 = 위험자산 부담 |
| WTI 유가 | FRED `DCOILWTICO` | 급등 = 인플레·수요 충격 |
| 시장 폭 | Stooq SPY 5일 | 실제 돈이 어디로 가는지 |
| 지정학 | 시장 헤드라인 스캔 | 전쟁·관세·제재·셧다운·뱅크런 등 |

→ **RISK_ON / NEUTRAL / RISK_OFF** 판정과 함께 두 개의 손잡이가 나옵니다.

- `size_multiplier` (0.3~1.3) — 포지션 크기를 곱합니다.
- `entry_bias` (-8~+15점) — 진입 문턱을 올리거나 내립니다.

RISK_OFF 면 **덜 사고 작게 삽니다.** 지정학 리스크 75 이상이면 신규 진입이 아예 막힙니다.

```bash
python3 -m scalper macro
```

FRED·Stooq 모두 **API 키가 필요 없습니다.** 네트워크가 막혀 있으면 해당 항목만 빠지고
기술적 신호만으로 판단합니다.

## 5. 리스크 관리 — 수익 극대화의 전제

수익을 늘리는 가장 확실한 방법은 **크게 잃지 않는 것**입니다. 기본값은 전부 방어적입니다.

| 항목 | 기본값 | 이유 |
|---|---|---|
| 1회 매매 리스크 | 계좌의 0.5% | 손절까지 가도 잃는 돈이 고정됩니다 |
| 한 종목 최대 비중 | 25% | 한 종목 사고로 계좌가 흔들리지 않게 |
| 동시 보유 | 3포지션 | 슬롯 수와 동일 |
| 손절 | -1.7% (ATR 기준으로 더 타이트해질 수 있음) | 변동성 큰 종목엔 넓게, 작은 종목엔 좁게 |
| 긴급 손절 | -2.0% | 갭·급락 대비 |
| 목표 | +0.8 ~ +3.2% | 점수·변동성·환경이 좋을수록 위쪽 |
| 시간청산 | 30분 | **단, 이익 중이면 유예** (최대 60분) |
| 트레일링 | +0.5%부터 | 고점 대비 되돌림 허용폭 안에서 손절선을 끌어올림 |
| 재진입 쿨다운 | 180초 | 같은 자리 반복 매매(과매매) 차단 |
| 최소 보유 | 60초 | 진입 직후 흔들림에 수수료만 내고 털리지 않게 |
| 일일 손실 한도 | -3% | 도달하면 그날 신규 진입 중단 |
| 왕복 비용 | 1.0bp | 기대수익이 비용의 3배 미만이면 진입하지 않음 |

포지션 크기는 이렇게 나옵니다.

```
수량 = (계좌 × 0.5%) ÷ (진입가 − 손절가) × 매크로배수     (최대 비중 한도 내)
```

## 8. 실제 돈으로 연결하기 — `scalper/live/`

`run` 명령은 시뮬레이션입니다. **실제 주문은 `live` 명령과 `scalper/live/` 패키지가 냅니다.**

```bash
python3 -m scalper live                            # Alpaca 페이퍼 계좌
python3 -m scalper live NVDA AMD SPY --serve 8790  # 모니터 화면까지
```

### 8-1. 시뮬레이션과 무엇이 다른가

시뮬레이션의 치명적 가정은 **"내가 산 줄 알면 산 것"** 이었습니다. 실전은 다릅니다.

| 항목 | 시뮬레이션 (`run`) | 실전 (`live`) |
|---|---|---|
| 포지션의 진실 | 프로그램 메모리 | **브로커** (매 틱 대조) |
| 진입가 | 5분봉 종가 | **실제 체결 평균가** |
| 손절 판단 가격 | 5분봉 종가 | **실시간 체결가** |
| 브래킷 손절이 거래소에서 체결되면 | 모름 (좀비 포지션) | 다음 틱에 청산으로 확정 |
| 재시작하면 | 포지션·일일손익 소실 | 상태 파일 복원 + 보유분 인수 |
| 장 마감 / PDT | 무시 | 진입 차단 |
| API 오류·레이트리밋 | 없음 | 재시도 + 백오프 |

구성:

| 파일 | 역할 |
|---|---|
| `live/client.py` | Alpaca REST — 재시도·레이트리밋·실시간가·주문상태 |
| `live/guards.py` | 시장시간 / PDT / 일일손실 / 킬 스위치 |
| `live/state.py` | 재시작해도 유지되는 하루 상태 (원자적 저장) |
| `live/executor.py` | 주문 실행 + **브로커 대조** (핵심) |
| `live/runner.py` | 신호 × 안전장치 × 주문을 묶은 루프 |
| `live/monitor.py` | 읽기 전용 모니터 화면 |

### 8-2. 주문이 나가기 전에 통과해야 하는 관문

하나라도 걸리면 **신규 진입은 막히고, 청산은 계속 허용**됩니다. 손절을 막는 조건은 없습니다.

- 장 마감 / 프리·애프터장 (`--extended` 로 해제)
- 개장 후 5분, 마감 전 15분 (`--open-buffer` / `--close-buffer`)
- PDT: 자산 2.5만 달러 미만 + 당일매매 3회 이상 (`--ignore-pdt` 로 해제, 권장하지 않음)
- 일일 손실 한도 도달
- 계좌 거래정지 상태
- 킬 스위치 파일 존재
- 1주 미만 수량 (브래킷 주문은 소수점 매수를 지원하지 않습니다)

### 8-3. 킬 스위치

자리를 비운 사이 뭔가 잘못됐을 때, 파일 하나로 즉시 멈춥니다.

```bash
touch .scalper_halt      # 보유 포지션 전량 청산 후 정지
rm .scalper_halt         # 해제
```

### 8-4. 단계별로 올라가기

```bash
export ALPACA_API_KEY="..."      # https://alpaca.markets (미국주식 수수료 무료)
export ALPACA_API_SECRET="..."
export FINNHUB_API_KEY="..."     # 선택 — 종목 뉴스 커버리지 향상

python3 -m scalper check                        # 1. 키·네트워크 점검
python3 -m scalper backtest NVDA --live         # 2. 실 데이터로 검증
python3 -m scalper run --live                   # 3. 실 시세, 주문 없음 (신호만)
python3 -m scalper live --serve 8790            # 4. 페이퍼 계좌 실제 주문
```

**4번을 최소 2주** 돌려 승률·손익비·MDD를 확인한 뒤에 실계좌를 얘기하세요.

### 8-5. 실계좌 (2중 잠금)

```bash
export SCALPER_ALLOW_LIVE=1
python3 -m scalper live --real
```

`--real` 만으로는 열리지 않습니다. 환경변수까지 있어야 실계좌 엔드포인트로 요청이 나갑니다.
CI 가 이 잠금이 살아 있는지 매번 검사합니다.

주문은 항상 **브래킷 주문**(진입 + 손절 + 익절 동시)입니다. 프로그램이 죽거나 인터넷이
끊겨도 손절은 거래소에 남아 있습니다. 그리고 그 손절이 체결되면 다음 틱에 우리 장부에
자동으로 반영됩니다.

### 8-6. 모니터 화면

`--serve 8790` 을 붙이면 http://127.0.0.1:8790 에 상태 화면이 뜹니다.
**읽기 전용입니다** — 실계좌가 도는 중에 브라우저 버튼 하나로 사고가 나지 않도록
POST 요청 자체를 405 로 막았습니다. 정지는 콘솔 Ctrl+C 또는 킬 스위치 파일로만 합니다.

### 8-7. API 호출 예산

Alpaca 는 분당 200콜입니다. 기본 5초 주기에서 틱당 호출은 8회 이하로 유지됩니다
(포지션 1 + 실시간가 3 + 여유). 계좌·시장시간은 30초, 봉은 60초, 뉴스·매크로는 5분
캐시입니다. `--interval` 을 3초 미만으로 내리면 예산을 넘길 수 있습니다.

## 10. 알아두실 것

- 이 프로그램은 **매매 도구이지 수익 보장이 아닙니다.** 단타는 대부분의 참가자가 잃는
  게임이고, 자동화는 잃는 속도까지 자동화합니다.
- 미국주식 **패턴 데이트레이더 규정(PDT)** — 계좌 자산 25,000달러 미만이면 5영업일 중
  당일매매 4회로 제한됩니다. Alpaca가 주문을 거부할 수 있습니다.
- 세금·환전 비용은 이 코드에 반영돼 있지 않습니다.
- 뉴스·거시 데이터 소스는 무료 티어라 쿼터·지연이 있습니다. TTL 캐시(뉴스 3분, 거시 15분)로
  아끼지만, 초단타 재료 매매에 쓰기엔 지연이 큽니다.
- 반드시 페이퍼로 먼저, 잃어도 되는 돈으로만.
