## 1단계 · 서버에 올리기 (15분)

여러 서비스가 있지만 **Render** 가 가장 단순합니다. GitHub만 연결하면 끝입니다.
(다른 곳을 쓰셔도 됩니다 — Railway, Fly.io, 국내는 Cloudtype 등)

### 순서

1. [render.com](https://render.com) 접속 → **Get Started** → **GitHub로 로그인**
2. 상단 **New +** → **Blueprint** 선택
3. 저장소 목록에서 **`cw1004/Yes`** 선택 → **Connect**
4. 브랜치를 `claude/face-analysis-skin-diagnosis-6q89ed` 로 지정
5. Render 가 저장소의 `render.yaml` 을 읽고 설정을 자동으로 채웁니다 → **Apply**

`render.yaml` 이 이미 저장소에 있어서, **서버 사양·디스크·헬스체크·자동 배포가 미리 설정돼 있습니다.**
직접 입력할 건 다음 단계의 비밀값 몇 개뿐입니다.

### 왜 무료 플랜이 아닌가

무료 플랜은 **15분간 접속이 없으면 서버가 잠들고**, 다음 방문자는 1분쯤 기다려야 합니다.
그리고 **디스크(영구 저장소)를 붙일 수 없어 재배포할 때마다 회원 기록이 지워집니다.**
`render.yaml` 을 유료(starter, 약 $7/월)로 잡아둔 이유입니다.
디스크는 1GB에 월 $0.25 수준입니다. 가입 화면에서 현재 가격을 확인하세요.

> 처음엔 무료로 감을 잡아도 됩니다. 다만 **회원 기록이 사라진다**는 것만 알고 쓰세요.

## 2단계 · 필수 설정값 채우기 (5분)

Render 대시보드 → 내 서비스 → 왼쪽 **Environment** 메뉴.
`sync: false` 로 표시된 항목들이 비어 있습니다. 아래를 채웁니다.

| 이름 | 무엇을 넣나 | 안 넣으면 |
|---|---|---|
| `SKINLAB_SECRET` | **자동 생성됨** (건드리지 마세요) | — |
| `ADMIN_TOKEN` | **자동 생성됨** — 값을 복사해 두세요. `/admin.html` 로그인용입니다 | 매출 지표가 공개됨 |
| `SKINLAB_PAYMENTS` | 아래 **3단계** 참고 | 서버가 뜨지 않음 |

**중요**: `SKINLAB_PAYMENTS` 가 비어 있거나 `mock` 이면 **서버가 일부러 기동을 거부합니다.**
데모 설정 그대로 배포되면 누구나 결제 없이 유료 리포트를 가져갈 수 있어서, 막아둔 안전장치입니다.

## 3단계 · 결제를 받을지 정하기 ← **여기가 갈림길입니다**

### A. 사업자등록이 없다 → `SKINLAB_PAYMENTS=none`

국내에서 **유료 결제를 받으려면 사업자등록이 필요합니다.** 토스페이먼츠·나이스페이 같은
결제대행사는 개인과 계약하지 않습니다. 그러니 개인은 이렇게 시작하는 게 현실적입니다.

```
SKINLAB_PAYMENTS=none
```

이렇게 두면:
- 전문 리포트와 상담이 **전부 무료로 열립니다** (결제 화면 자체가 사라집니다)
- 수익은 **제휴 커머스 수수료**로만 발생합니다 (4단계)
- 나중에 사업자등록을 마치면 이 값만 `toss` 로 바꾸면 됩니다. 코드는 그대로입니다.

### B. 사업자등록이 있다 → `SKINLAB_PAYMENTS=toss`

[토스페이먼츠](https://www.tosspayments.com/) 가입 → 심사 → 키 발급 후
`TOSS_CLIENT_KEY` / `TOSS_SECRET_KEY` 를 넣습니다.
유료 판매를 하면 **통신판매업 신고**도 필요합니다 (관할 구청 또는 정부24).

### C. 해외 결제도 받고 싶다 → `SKINLAB_PAYMENTS=stripe`

`STRIPE_SECRET_KEY` 를 넣습니다.

## 4단계 · 수익 연결하기 (제휴 ID)

**이걸 안 하면 아무리 많이 팔려도 수익이 0원입니다.**
구매 버튼이 그냥 검색 결과로 나가서, 판매처가 "우리가 보낸 손님"인 줄 모릅니다.

가장 빠른 것부터:

| 순서 | 어디 | 걸리는 시간 |
|---|---|---|

| 2 | 링크프라이스 등 제휴 네트워크 (올리브영 등) → `OLIVEYOUNG_PARTNER_ID` | 며칠 |
| 3 | [네이버 개발자센터](https://developers.naver.com/) → 상품 데이터용 | 즉시 |

상품 가격을 실제 값으로 바꾸는 방법은 **[파트너-API-연동.md](파트너-API-연동.md)** 에 따로 정리했습니다.
(키 없이 엑셀만으로 오늘 시작하는 방법부터 있습니다.)

## 5단계 · 내 도메인 붙이기 (10분)

1. 도메인을 삽니다 — [가비아](https://www.gabia.com/), [후이즈](https://www.whois.co.kr/),
   해외는 [Cloudflare](https://www.cloudflare.com/products/registrar/). `.co.kr` 은 연 1~2만원 수준입니다.
2. Render → 내 서비스 → **Settings → Custom Domains → Add Custom Domain** → 산 도메인 입력
3. Render 가 알려주는 값을 도메인 산 곳의 **DNS 설정**에 그대로 붙여넣습니다
   (보통 `CNAME` 한 줄, 또는 루트 도메인이면 `A` 레코드)
4. 10분~1시간 기다리면 연결됩니다. **HTTPS(자물쇠)는 Render 가 무료로 자동 설정**합니다

> 카메라는 **HTTPS 에서만** 열립니다. 그래서 도메인 연결 전 임시 주소(`~.onrender.com`)에서도
> 카메라가 정상 동작합니다 — 그 주소도 HTTPS 이기 때문입니다.

## 6단계 · 사용자를 받기 전 마지막 3가지

### ① 약관·개인정보처리방침 채우기
`public/legal.html` 이 이미 작성돼 있습니다. **`[[대괄호]]` 다섯 칸만 채우면 됩니다** —
시행일, 이름/상호, 연락 이메일 등. 연락처 없이 공개하면 열람·삭제 요청을 받을 방법이 없습니다.

### ② 백업 예약
회원 기록은 파일 하나(`/data/db.json`)입니다. Render → **Cron Jobs** 에서 하루 한 번:
```
npm run backup
```
백업 없이 운영하다 디스크가 상하면 사용자가 4주간 쌓은 기록이 전부 사라집니다.

### ③ 관리자 토큰 보관
`ADMIN_TOKEN` 값을 안전한 곳에 적어 두세요. `내도메인/admin.html` 에서 매출·퍼널을 봅니다.

> **이용자에게 꼭 안내하세요**: 앱은 회원가입이 없어 브라우저 기록을 지우면 진단 기록이 사라집니다.
> 기록 화면의 **복구 코드**를 발급받아 보관하도록 안내하면 문의가 크게 줄어듭니다.

## 7단계 · 한국에서 법적으로 챙길 것

저는 법률 전문가가 아니므로, 아래는 **확인해야 할 목록**으로 봐주세요.
실제 적용은 관할 기관이나 전문가에게 확인하시길 권합니다.

| 항목 | 왜 | 상태 |
|---|---|---|
| **개인정보처리방침** | 얼굴 사진은 서버로 보내지 않지만, 진단 수치와 익명 ID는 저장됩니다 | ✅ `public/legal.html` 작성됨 — `[[대괄호]]` 만 채우세요 |
| **이용약관** | 서비스 성격·한계·책임 범위 | ✅ 같은 파일에 포함 |
| **데이터 삭제 요청 대응** | 파기 요구권에 응할 수 있어야 합니다 | ✅ 앱에서 직접 삭제 가능 |
| **의료기기·의료행위 아님 고지** | 진단·처방을 표방하면 의료기기 인허가 대상이 됩니다 | ✅ 앱에 이미 상시 노출 |
| **제휴 수수료 고지** | 구매 링크로 수수료를 받는다는 사실을 알려야 합니다 | ✅ 추천 화면·상품 카드에 노출 |
| **통신판매업 신고** | 유료 리포트를 직접 판매할 때 필요합니다. 제휴 링크만 운영하는 경우는 상황에 따라 다릅니다 | ⬜ 확인 필요 |
| **소득 신고** | 제휴 수수료도 소득입니다 | ⬜ 확인 필요 |
| **광고 문구** | "전문의보다 정확" 같은 비교 표현은 표시광고법 위반이고 앱 심사 리젝 사유입니다 | ⚠️ 코드는 막아뒀지만 **홍보 문구는 직접 조심하세요** |

## 올리기 전 마지막 점검

내 컴퓨터에서 코드를 받아둔 상태라면, 한 줄로 확인할 수 있습니다.

```bash
npm run check:deploy
```

무엇이 비었고 그래서 무슨 일이 생기는지 알려줍니다. 예:

```
✗ 결제 방식              mock (데모용)
     → 결제를 받으려면 toss/stripe, 무료로 공개하려면 none 으로 설정하세요.
△ 제휴 추적 ID           하나도 없음
     → 없으면 구매 링크가 검색 결과로 나가고 수수료가 잡히지 않습니다. 즉 수익이 0입니다.
```

## 자주 나는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 배포했는데 서버가 안 뜸 | 로그에 `서버를 시작할 수 없습니다 (운영 안전 점검)` 이 있는지 보세요. 무엇이 빠졌는지 그 아래에 적혀 있습니다 |
| 카메라가 안 열림 | HTTPS 인지 확인. 그리고 브라우저 주소창의 자물쇠 → 카메라 허용 |
| 재배포하니 회원 기록이 사라짐 | 디스크를 안 붙였거나 `SKINLAB_DB=/data/db.json` 설정 누락 |
| 첫 접속이 느림 | 무료 플랜이라 서버가 잠들어 있었던 것입니다. 유료 플랜으로 바꾸면 사라집니다 |
| 상품 가격이 실제와 다름 | 아직 샘플 카탈로그입니다 → [파트너-API-연동.md](파트너-API-연동.md) |
| 구매해도 수수료가 안 잡힘 | 제휴 추적 ID 미설정 (4단계) |
