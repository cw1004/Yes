# 수익화 설계

## 1. 지금 구현되어 있는 것

| 광고 | 위치 | 빈도 | 코드 |
|---|---|---|---|
| 배너 | 화면 하단 고정 슬롯 | 상시 | `AdsManager.loadBanner()` |
| 전면 | **게임 오버 이후에만** | 3판마다 + 최소 90초 간격 | `maybeShowInterstitial()` |
| 보상형 | 사용자가 "이어하기"를 누를 때만 | 한 판에 1회 | `showRewarded()` + 게임의 이어하기 |

**플레이 중에는 어떤 광고도 화면을 덮지 않습니다.** 구글 정책 위반을 피하고
이탈률을 낮추기 위한 설계입니다. 배너는 게임 캔버스 위가 아니라 별도 레이아웃 슬롯에 있습니다.

보상형 이어하기는 이 구조에서 **가장 수익성이 높은 지점**입니다.
사용자가 자기 최고 점수를 눈앞에서 잃는 순간에만 뜨고, 스스로 누르기 때문에
전면광고보다 eCPM 이 보통 3~10배 높습니다.

## 2. 수익 계산 (직접 대입해서 쓰세요)

```
일 수익 ≈ DAU × 1인당 광고 노출 수 × (eCPM / 1000)
```

이 게임의 1인당 하루 노출 추정:
- 배너: 세션당 1~2회 노출 (체류 시간에 비례)
- 전면: 3판마다 1회 → 하루 9판 플레이 시 3회
- 보상형: 시청률 20~30% 가정 시 하루 0.5~1회

**eCPM 은 국가별 편차가 매우 큽니다.** 인도 트래픽은 미국의 1/10 수준인 경우가 흔합니다.
아래는 **가정치**이며 실제 값은 AdMob 대시보드에서 확인해야 합니다.

| 지표 | 보수적 | 보통 |
|---|---|---|
| eCPM (배너) | $0.1 | $0.3 |
| eCPM (전면) | $1.0 | $3.0 |
| eCPM (보상형) | $3.0 | $10.0 |

DAU 1,000명 기준 예시 계산(보통 값):
```
배너   1,000 × 1.5회 × 0.3/1000  ≈ $0.45
전면   1,000 × 3회   × 3.0/1000  ≈ $9.00
보상형 1,000 × 0.7회 × 10.0/1000 ≈ $7.00
                                  ─────────
                            하루 약 $16 (월 약 $480)
```
> DAU 1,000명은 저절로 오지 않습니다. **수익 공식의 진짜 변수는 eCPM 이 아니라 DAU 와 유지율**입니다.
> 광고 배치를 다듬는 것보다 재방문율을 1%p 올리는 편이 수익에 훨씬 큽니다.

## 3. 경기장 광고판 (직접 판매 지면)

게임 화면 안에 두 종류의 지면이 있다. (경기장이 광고로 뒤덮이지 않도록 의도적으로 줄였다)

| 지면 | 위치 | 노출 |
|---|---|---|
| 기둥 배너 | 골대 기둥 (골문 틈에서 46px 이상 떨어뜨림) | 골문마다 순환, 통과할 때마다 노출 |
| **대형 세로 광고판 (타워)** | 강 건너 둑, 배경 레이어 | 약 10초에 하나씩 — 가장 눈에 띄는 지면. 세로로 길어 화면에 머무는 시간이 길다 |

**AdMob 과 혼동하면 안 된다.** AdMob 광고는 반드시 공식 광고뷰로만 표시해야 하고,
캔버스에 그린 이미지는 AdMob 노출로 집계되지 않는다.
따라서 이 지면은 **직접 판매(직거래)** 자산이며, 팔리기 전까지는 자체 홍보로 채운다.

### 지금 상태 — 13종
`07_MVP_Code/src/sponsor.js` 의 `BOARDS` 배열에 세 종류가 들어 있다.

| 종류 | 수 | 내용 |
|---|---|---|
| `house` 자체 홍보 | 3 | INDIA 2030 / 공 상점 / FOLLOW THE DREAM |
| `sponsor` 광고 | 5 | **가상 브랜드 4종** + 판매용 빈 지면 1종 |
| `campaign` 공익 | 5 | 자연을 지켜요 / 생태를 지키자 / 창조 질서 보전 / 물을 아껴요 / 나무 한 그루 |

**가상 브랜드**(`fictional: true`)는 실존 상표를 쓰지 않고 이 프로젝트의 자체 IP와
일반 명사를 조합해 만들었다 — GAJU SPORTS, GABE ENERGY, SKY GOAL ACADEMY, DREAM BOOTS.
경기장이 비어 보이지 않게 채우는 용도이자, 스폰서에게 보여줄 지면 샘플이다.
실제 계약이 되면 해당 항목의 `text` · `sub` · `mark` · 색만 바꾸면 끝이다.

**노출 순서는 종류를 섞는다.** `광고 → 캠페인 → 광고 → 자체 → 캠페인 …` 패턴으로
돌아가며, 광고가 3연속으로 나오지 않는 것을 테스트로 고정했다.
화면이 상업적으로만 보이지 않게 하고, 캠페인 메시지가 브랜드 톤을 지켜 준다.

각 보드에는 자체 제작 로고 마크(공·축구화·잎·물방울·별·방패·트로피)가 들어간다.

### 반드시 지킨 원칙
- **클릭 영역 없음** (`CLICKABLE = false`). 원버튼 게임에서 광고 클릭 영역은
  오조작을 부르고, 실수 클릭은 광고 정책 위반 소지도 있다.
  탭은 오직 공을 띄우는 조작이며, 이 사실을 테스트로 고정했다
  (광고판 위를 탭해도 공이 반응하는지 매번 검사)
- 골문 틈 근처에는 절대 그리지 않는다 (시야 방해 방지)
- 하우스 광고는 게임 내 기능(공 상점)이나 브랜드 메시지만 담는다

### 판매 시 참고
- 지면 등급을 나눠 파는 것이 유리하다: **대형 세로 광고판 > 기둥 배너**
- 게임 내 브랜드 노출은 CPM 이 아니라 **기간 단가(월 정액)**로 파는 것이 일반적이다
- 협상 근거가 되는 숫자: DAU, 하루 평균 골문 통과 수(= 배너 노출 수), 평균 세션 길이
- 실측 노출 수를 세려면 통과 시점에 보드 id 를 집계하면 된다 (현재 미구현)
- 광고 심의: 주류·도박·의약품 등은 전체이용가 게임에 부적합하다

## 4. 다음 단계 (효과 큰 순서)

1. **광고 제거 인앱결제 (₩1,100~3,300)**
   - `com.android.billingclient:billing` 추가 → 구매 시 `AdsManager` 비활성화
   - 광고를 싫어하는 상위 1~3% 사용자가 광고 수익의 절반을 대체하기도 합니다
2. **리텐션 장치** — 일일 보상, 연속 출석, 주간 리더보드
   (게임에 이미 코인·XP·스탯이 있으므로 소비처만 붙이면 됩니다)
3. **AdMob 매개변수 최적화** — 광고 형식별 eCPM 하한(플로어) 설정, 매개 네트워크 추가
4. **ASO** — 스토어 제목·짧은 설명의 키워드가 설치율을 좌우합니다
5. **스킨/캐릭터 판매** — 코인으로 사는 무료 스킨 + 현금 프리미엄 스킨

## 5. 반드시 지킬 것

- 자기 광고를 클릭하지 않는다 (계정 영구 정지 사유)
- 광고 클릭을 유도하는 문구·배치를 쓰지 않는다
- 광고를 실수로 누르게 만드는 위치(버튼 바로 옆)에 두지 않는다
- 실제 광고 ID 로 개발 테스트를 하지 않는다 (테스트 ID 또는 테스트 기기 등록 사용)
- 아동 대상 앱으로 설정하면 광고 제약이 커진다 — 이 앱은 13세 이상 대상
