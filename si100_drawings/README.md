# SI-100 시제품 제작 도면 (Rev A, AI 보조 초안)

태양열 흡착식 제빙기 SI-100 시제품(집열판 1 m², 활성탄 Maxsorb III + 메탄올)의 A3 도면 6장을 코드로 만듭니다.
도면의 모든 숫자는 `design.py` 한 곳에서 계산되므로, 설계값을 바꾸고 다시 실행하면 도면 전체가 함께 바뀝니다.

## 실행

```bash
pip install numpy matplotlib
python -m si100_drawings.make     # → output/si100/SI-100_drawingset_RevA.pdf
python -m si100_drawings.design   # 설계값 요약만 출력
```

## 도면 구성

| 장 | 도번 | 내용 |
| --- | --- | --- |
| 1 | SI-100-000 | 전체 배치(측면), 부품표, 설계 성능, 운전 순서 |
| 2 | SI-100-100 | 집열 흡착기 평면·단면, 야간 냉각 댐퍼 |
| 3 | SI-100-110 | 흡착관 종·횡단면, 흡착제 링 사양 |
| 4 | SI-100-200/210 | 응축기(연속 판핀), 수액기(눈금 액면계) |
| 5 | SI-100-300/310 | 증발기(지지봉 보강), 얼음 몰드, 제빙함 |
| 6 | SI-100-400 | 필수 공정 14단계, 충전 파라미터, 합격 시험, 금지 사항 |

## 주의

- AI 보조 초안입니다. 진공 용기·용접·안전밸브는 자격 있는 설계자의 검토와 승인을 받은 뒤 제작하세요.
- 성능 수치는 `si100_sim` 평형 모델의 상한값이고, 설계 목표(10 kg/일)는 상한의 약 78 %로 잡았습니다.
- 흡착제 링 압축 압력, 실제 흡착 등온선은 시험으로 확정해야 합니다.
