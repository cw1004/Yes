| 변동계수 | 표본 부족 시 기본값 |

| 경기장 파라미터 | 난이도↑ → gap↓ / speed↑, 하한·상한 유지 |

| 레벨업 | 스탯 포인트 지급과 소비 |
| commitRun | 지표·연속 기록·최근 10게임 갱신 |

## 2. 브라우저 스모크 테스트 (`tests/browser.smoke.mjs`, 15개)
실제 Chromium 에서 빌드된 단일 HTML 을 띄워 확인한다.
- 시작 화면 표시 / 엔진 로드
- 경기 시작 → `ready` 상태 → HUD 표시
- 자동 조종 봇이 골문을 연속 통과해 점수를 낸다(최대 3판 시도)
- 결과 화면과 보상 표시
- 프로필 저장, 새로고침 후 복구
- 결과 화면에서 재시작
- 리사이즈 후 렌더 유지, 가로 스크롤 없음
- **콘솔 에러 0건**

## 3. 수동 확인 체크리스트
1. 신규 플레이어가 10판 내에 난이도 10~40 구간으로 수렴하는가
2. 숙련 플레이어의 난이도가 60~90 까지 점진 상승하는가
3. 3연속 실패 후 난이도가 급증하지 않는가 (한 판 ±5)
4. 최근 10게임 성공률이 65~80% 근처를 유지하는가
5. 모바일 터치 / PC 스페이스 / 클릭 모두 동작하는가
6. 탭 전환 후 돌아왔을 때 공이 갑자기 죽지 않는가 (자동 일시정지)
7. 장시간 플레이 시 골문 배열이 끊기지 않는가

## 4. 목표 KPI
- 첫 3분 내 재시작률 > 60%
- 평균 연속 플레이 시간 > 2분
- 실패 직전 체감 난이도 급상승 최소화
