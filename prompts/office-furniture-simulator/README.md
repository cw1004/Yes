# Workspace Simulator — 수익 극대화 프롬프트 팩

미국(영어권) 시장을 겨냥한 **모던 오피스 가구 구매 시뮬레이터**를 설계·구축하기 위한 프롬프트 모음입니다.
고객이 자기 작업 공간을 시뮬레이션해 보게 만들고, 그 과정에서 구매 동기를 최대로 끌어올려
**세션당 매출(Revenue Per Session)** 을 극대화하는 것이 목표입니다.

## 파일

| 파일 | 용도 |
|---|---|
| `01-master-prompt.md` | **메인.** 통째로 복사해 붙여넣으면 전략·화면설계·산식·카피·B2B·계측·빌드플랜까지 10종 산출물이 나옵니다 |
| `02-module-prompts.md` | 점수 산식 / 번들가격 / 카피덱 / B2B / 3D·AR / A-B테스트 / 컴플라이언스 / 1주 v0 — 8개 모듈 프롬프트 |
| `03-guardrails-checklist.md` | 같은 전환 장치를 미국 규제 안에서 (더 잘 먹히게) 구현하는 대조표 |

## 쓰는 순서

1. `01-master-prompt.md` 의 코드블록을 복사 → `{{ }}` 값을 자기 브랜드 숫자로 교체 → 실행
2. 나온 결과에서 가장 약한 파트를 골라 `02-module-prompts.md` 의 해당 모듈을 **같은 대화창에** 이어 붙여 심화
3. 출시 전 `M7 컴플라이언스 감사` 모듈 실행 + `03-guardrails-checklist.md` 로 교차 확인
4. 실제 착수는 `M8 1주 v0` 부터 — 3D 없이 핵심 가설(격차 → ROI)만 먼저 검증

## 이 프롬프트의 핵심 아이디어

예쁜 3D 방은 **미끼**이고, 파는 것은 **정량화된 격차**입니다.

```
7문항 진단  →  Workspace Score 0-100 (5개 세부항목)
            →  가장 약한 항목이 붉게 새는 시각화
            →  "주당 4.2시간 손실" → "월 $X" (사용자가 가정값 수정 가능)
            →  3D/AR로 개선안 배치, 점수와 가격을 같은 화면에
            →  "6.4주면 본전" → "$75/mo" → "하루 $2.47"
            →  빌드 저장(이메일 확보) → 리마케팅 자산
```

미국 시장에 특화된 수익 레버 4가지가 특히 큽니다.

- **고용주 재택 스티펜드 청구 도우미** — 청구용 이메일 초안과 항목별 영수증 PDF 자동 생성.
  "$900은 부담"을 "회사가 $500 내줌"으로 바꿔 줍니다.
- **Section 179 사업비 공제 계산기** — LLC/S-corp 소상공인 세그먼트에 대단히 강력합니다.
- **BNPL(Affirm/Klarna) 월납 표기** — $300 이상 모든 가격 옆에 상시 노출. 객단가를 직접 올립니다.
- **B2B 즉시 견적 + Net-30 + 면세 처리** — 40석 구매자를 소비자 장바구니에 가두지 않는 것만으로
  세션당 매출 자릿수가 달라집니다.

## 주의

`03-guardrails-checklist.md` 를 반드시 읽으세요. 가짜 재고·가짜 카운트다운·가짜 리뷰는 미국에서
FTC 제재와 집단소송 대상이며, 이 설계에서는 실익도 없습니다. 모든 긴급성·희소성 장치는
실제 데이터에 연동된 형태로만 구현하도록 프롬프트에 강제해 두었습니다.
