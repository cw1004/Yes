# 특허출원 준비 자료 — Inverter Control System for Optimization and Fault Prevention

업로드된 Patsnap 선행기술조사 보고서(Ref. 04445, 18 rounds / 100 references)를 기반으로 작성한
특허출원 일체 초안이다.

## ⚠️ 가장 먼저 알아야 할 것

**조사보고서의 원안 청구항은 그대로 출원하면 거절된다.** 구성요소 a~g 전부가 X 문헌 3건
(IN202541054528A, IN574334B, IN202441097209A) 안에서 개시 또는 "Obvious"로 판정되었다.
따라서 본 자료는 조사보고서 문언을 정서한 것이 아니라, **6개 축으로 회피설계된 새로운 청구항**을
중심으로 재구축한 출원 초안이다. 상세 근거는 `00_PRIOR_ART_ANALYSIS.md` 참조.

## 발명의 핵심 (한 문단)

인버터의 각 스위칭 소자마다 ① 손실모델 + Foster 열망 + **온-상태 전압강하(TSEP) 보정**으로 접합온도를
개별 추정하고, ② **레인플로우 계수 + 코핀-맨슨 수명모델**로 소모수명지수를 누적하며, ③ AI 자문루프가
`J = 손실비용 + λ(수명예산)·수명소모비용` 을 최소화하는 변조 파라미터(스위칭 주파수·데드타임·변조방식)를
제안하되 — 즉 **필요하면 효율을 일부러 희생해 수명을 산다** — ④ 결정론적 안전 감시기가 그 후보를
해석적 허용집합에 **투영**한 뒤에야 변조기에 인가하고 연속 위반 시 AI 비의존 **폴백으로 래치**한다.
AI는 자문자일 뿐 전력단에 대한 권한이 없으므로 ISO 26262 / IEC 61508 논증이 성립한다.
