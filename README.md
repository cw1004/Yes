# 📈 ScalpDesk — 미국 주식 단타 차트 대시보드

미국 주식 단타(스캘핑)를 위한 웹 대시보드입니다.
캔들차트 위에 **이동평균선 · 볼린저밴드 · VWAP · 추세선 · 지지/저항 · 피보나치**를 겹쳐 보고,
**RSI · MACD · 스토캐스틱 · 거래량**을 함께 확인하면서, 이 지표들을 종합한 **매매 신호와 ATR 기반 매매 플랜**을 받아볼 수 있습니다.

> ⚠️ 이 앱이 보여주는 점수·신호·플랜은 공개 시세를 이용한 **기술적 계산 결과**이며 투자 자문이나 권유가 아닙니다.
> 실제 매매 판단과 그 결과에 대한 책임은 전적으로 사용자 본인에게 있습니다.

---

## 실행

```bash
node server/server.js          # http://127.0.0.1:5173
```

| 명령 | 설명 |
| --- | --- |
| `npm start` | 실시간 시세(Yahoo Finance) 사용, 실패 시 데모 데이터로 자동 전환 |
| `npm run demo` | 항상 데모 데이터 (오프라인·사내망 등 외부 접속이 막힌 환경) |
| `npm test` | 지표·신호 엔진 단위 테스트 |
| `PORT=8080 node server/server.js` | 포트 변경 |

Node.js 18 이상만 있으면 되고 **설치할 의존성이 없습니다** (`npm install` 불필요).
시세는 API 키가 필요 없는 Yahoo Finance 공개 차트 엔드포인트를 서버가 대신 호출합니다(브라우저 CORS 우회 + 짧은 캐시).
외부 접속이 막혀 있으면 상단 배지가 `데모 데이터`로 바뀌고, 화면 구성과 모든 기능은 동일하게 동작합니다.

## 화면 구성

**왼쪽 — 관심종목 / 시장 지표**
- 관심종목 추가·삭제, 클릭 시 즉시 차트 전환 (브라우저에 저장)
- SPY·QQQ·DIA·IWM·VIX 시세를 곁들여 장 분위기 확인

**가운데 — 차트**
- 캔들 + 거래량 + RSI + MACD + 스토캐스틱 패널
- 겹쳐 그리기: 이동평균선(4개, 기간·SMA/EMA 개별 설정) · 볼린저밴드 · VWAP · 자동 추세선 · 지지/저항 · 피보나치 되돌림 · 회귀 추세선
- 봉 주기 1분 / 2분 / 5분 / 15분 / 30분 / 1시간 / 일봉, 기간은 주기에 맞는 값만 선택 가능
- 마우스 휠 = 확대·축소, 드래그 = 이동, 더블클릭 = 초기화, 십자선으로 봉별 OHLC·거래량·RSI 확인
- ✏️ 버튼으로 **추세선 직접 그리기** (종목·주기별로 저장), CSV 내보내기

**오른쪽 — 신호와 플랜**
- 종합 점수(-100 ~ +100)와 판정: 적극 매수 / 매수 우위 / 관망 / 매도 우위 / 적극 매도
- 점수에 기여한 근거를 가중치와 함께 나열 (예: `이동평균 정배열 (+18)`)
- ATR 기반 진입가·손절가·1·2차 목표·손익비(R:R)
- 포지션 계산기: 계좌 규모와 허용 리스크(%)로 수량·투입금액·최대손실 계산 (매수 여력 초과 시 자동 제한)
- 가격/RSI 도달 알림 (브라우저 알림 + 화면 토스트)

**단축키** — `R` 새로고침 · `/` 검색 · `D` 추세선 그리기

## 신호 엔진이 보는 것

점수는 아래 판정들의 가중 합이며, 각 근거는 화면에 그대로 표시됩니다.

| 구분 | 판정 내용 | 가중치 |
| --- | --- | --- |
| 이동평균 | 정배열/역배열, 단기-중기 골든·데드크로스 | 8 ~ 18 |
| VWAP | 당일 평단 위/아래 (단타의 기준선) | 12 |
| 볼린저밴드 | %B 위치, 밴드 이탈 후 회복, 스퀴즈(밴드폭 백분위) | 6 ~ 12 |
| RSI | 과매수/과매도, 50선 돌파 | 6 ~ 10 |
| MACD | 히스토그램 0선 전환(골든·데드크로스), 부호 | 7 ~ 14 |
| 스토캐스틱 | 과매도/과매수권에서의 %K-%D 교차 | 10 |
| 거래량 | 20봉 평균 대비 배율(급증/부족)과 캔들 방향 | 7 ~ 14 |
| 추세선 | 자동 추세선(스윙 고·저점 연결) 돌파·이탈 | 16 |
| 지지/저항 | 스윙 가격대 군집화 후 근접 여부 | 8 |
| 캔들 패턴 | 장대양·음봉, 망치형, 유성형, 장악형, 도지 | 9 |

**매매 플랜**은 손절을 `1.2 × ATR(14)`로 잡고, 1차 목표는 `1.5R`(가까운 지지/저항이 있으면 그 레벨), 2차 목표는 `2.5R`로 제시합니다.
손익비가 1.5 미만이면 빨갛게 표시되니, 진입 전 손익비부터 확인하세요.

## 프로젝트 구조

```
server/
  server.js            의존성 없는 정적 서버 + 시세 프록시 (캐시·입력 검증 포함)
  providers/yahoo.js   Yahoo Finance 차트/검색 래퍼 (API 키 불필요)
  providers/mock.js    오프라인 데모 시세 생성기 (시각 기반이라 기간·주기와 무관하게 일관)
public/
  index.html           화면 구조
  styles.css           다크 트레이딩 테마 (반응형)
  js/indicators.js     지표 계산 (SMA/EMA/BB/RSI/MACD/스토캐스틱/ATR/VWAP/OBV/피봇/추세선/피보나치)
  js/signals.js        신호 엔진 + 매매 플랜 + 포지션 계산
  js/chart.js          캔버스 차트 렌더러 (확대·이동·십자선·직접 그리기)
  js/app.js            상태 관리와 UI 바인딩
test/
  indicators.test.js   지표·신호·데이터 정합성 테스트 (node test/indicators.test.js)
```

### API

| 엔드포인트 | 설명 |
| --- | --- |
| `GET /api/candles?symbol=AAPL&interval=5m&range=5d` | 캔들 + 메타(현재가·전일종가·고저) |
| `GET /api/quotes?symbols=AAPL,TSLA` | 관심종목용 시세 묶음 |

| `GET /api/health` | 서버 상태와 동작 모드 |

## 알아두면 좋은 점

- **지연 시세입니다.** Yahoo Finance 공개 데이터는 실시간 체결가가 아니라 보통 15분가량 지연됩니다. 실제 초단타 체결에는 증권사 실시간 시세를 쓰세요.
- 자동 새로고침은 봉 주기에 맞춰 20초~5분 간격이며, 백그라운드 탭에서는 멈춥니다.
- 야후 API 제약으로 1분봉은 최근 5일까지만 조회됩니다(주기별로 선택 가능한 기간이 자동 제한됩니다).
- VWAP은 당일 세션 기준이라 일봉에서는 자동으로 비활성화됩니다.
- 관심종목·지표 설정·직접 그린 추세선·알림은 브라우저 localStorage에 저장됩니다.
