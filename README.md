# 구형 발광 응원 장치 — 전자 분야 특허출원 문서

제공된 제품 시안(디자인/상표 시안 및 기능 설명 시안)을 근거로, **전자 분야 특허출원용 명세서**를 작성한 저장소입니다.

## 작성 방침

- **특정 대회·연맹·국가대표팀 관련 내용(FIFA 및 그 산하 대회 포함)은 일체 기재하지 않았습니다.** 대신 "스포츠 경기장, 공연장, 전시장 등"의 중립적 표현을 사용하여 종목·대회·지역에 구애받지 않는 권리범위를 지향했습니다.
- 시안의 **브랜드 로고·워드마크·슬로건**은 상표의 영역이므로 특허 명세서에서 제외했습니다.
- 시안의 **외관 디자인·6면도**는 디자인등록의 영역이므로 특허 명세서에서 제외했습니다.
- 특허의 대상이 되는 **기술적 사상(전자 회로·구조·제어 알고리즘)** 만을 추출하여 명세서로 구성했습니다.

## 발명의 명칭

**분리형 손잡이를 구비한 구형(球形) 발광 응원 장치 및 다수 장치의 무선 군집 동기 제어 시스템**

## 핵심 기술 포인트 (특허성 주장 근거)

| # | 기술 요소 | 종래 대비 차별점 |
|---|---|---|
| 1 | **도광·차광 겸용 방사상 리브** | 단일 평면 기판의 양면 실장만으로 구면 전 방향 균일 발광 + 셀 단위 독립 표시를 동시 달성. 구면에 복수 연성기판을 배치하는 종래 방식 대비 조립 공수·원가 절감 |
| 2 | **음향 + 관성 결합 온디바이스 이벤트 판별** | 서버 왕복 없이 장치 내부에서 판별 → 통신 혼잡·단절 환경에서도 즉응. 두 신호를 결합해 확성기·주변 발화에 의한 오판별 저감 |
| 3 | **비접속형 브로드캐스트 + 기준 시각 정렬** | 개별 접속 수립 없이 수만 대 동시 제어. 클럭 주파수 편차까지 보정하여 패킷 사이 구간의 시각 오차 누적 억제 |
| 4 | **좌표 식별자 + 산출 규칙 전송** | 좌표별 값을 개별 전송하지 않고 규칙만 전송 → 송신 데이터량이 장치 대수와 무관 |
| 5 | **홀센서 기반 손잡이 분리 검출** | 자기 결합 + 포고 접점 구조에서 분리를 자동 검출해 저전력 표시 모드 전환. 배터리를 손잡이에 두어 무게중심 하향·발열 경로 분리 |
| 6 | **충격/온도/잔량 연동 출력 제한** | 낙하 시 과출력 방지, 소자 과열 방지, 잔량 2단 제한으로 급정지 방지 |

## 도면 미리보기

도면은 SVG 벡터 파일입니다. GitHub에서 직접 클릭하여 확인할 수 있으며, 전자출원 시에는 흑백 선화 PDF/TIFF로 변환해 제출합니다.

```bash
# 예시: SVG → PDF 변환
for f in 특허출원/도면/*.svg; do rsvg-convert -f pdf -o "${f%.svg}.pdf" "$f"; done
```
