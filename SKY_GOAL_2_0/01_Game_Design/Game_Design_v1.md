# SKY GOAL 2.0 — 게임 디자인 v1.0

## 한 줄 정의
탭 한 번으로 공을 띄워 움직이는 골문을 통과하는 원버튼 아케이드.
**플레이할수록 게임이 나에게 맞춰진다.**

## 핵심 루프
```
탭 → 골문 통과 → 콤보/퍼펙트 → 점수 → 스테이지 변화 → 사망
  → 코인·XP·아이템 → 레벨업/스탯 → AI 난이도 재계산 → 다음 판
```
한 판은 짧게(수십 초), 판 사이의 성장과 난이도 조정이 재시작 동기를 만든다.

## 킥오프 — 경기의 시작
"경기 시작"을 누르면 바로 조작이 시작되지 않고 **킥오프 연출**이 먼저 나온다.

| 시간 | 장면 |
|---|---|
| 0.00s | 심판 휘슬, 공은 잔디 위에 정지 |
| 0.00~0.55s | 선수가 왼쪽에서 달려온다 |
| 0.55~0.85s | 플랜트 · 백스윙 |
| **0.85s** | **임팩트** — 킥 사운드, 잔디 파편, 공 발사 |
| 0.85~1.47s | 공이 포물선을 그리며 플레이 위치로 |
| 1.47s | 플레이 시작 |

- 임팩트 순간의 초기 속도는 **플레이 시작 지점에 정확히 도착하도록 역산**한다.
  연출이 끝나면 공이 그 자리에 자연스럽게 놓이므로 위화감이 없다.
- 화면을 탭하면 언제든 **연출을 건너뛰고** 바로 시작한다.
- 시작 버튼 클릭이 사용자 제스처이므로 이 시점에 오디오가 열린다 (첫 탭 전에도 소리가 난다).

**선수는 이름·얼굴·등번호가 없는 실루엣이다.** 실존 선수를 묘사하지 않는다
(초상권·퍼블리시티권 문제 및 스토어 심사 회피).

## 조작
- 탭 / 클릭 / 스페이스 / ↑ : 공 띄우기 (원버튼)
- 시작 직후에는 **TAP TO START** 준비 상태로 대기한다. 화면을 보기도 전에 죽지 않는다.
- 탭으로 게임이 시작된 뒤부터 시간·물리가 흐른다.

## 공 5종 (시작 화면 → ⚽ 공 선택 · 상점)
| 공 | 무게 | 점프 높이 | 체공 | 가격 | 특성 |
|---|---|---|---|---|---|
| 거리의 낡은 공 | 1.00 | 60.8px | 0.72s | 기본 제공 | 기준값 |
| 고무공 | 0.78 | 71.9px | 0.89s | 300코인 | 높이 뜨고 천천히 떨어진다 |
| 훈련용 중량구 | 1.30 | 58.7px | 0.62s | 800코인 | 낮게 뜨고 빠르게 떨어져 민첩 |
| 공식 경기구 | 0.94 | 67.3px | 0.79s | 1500코인 | 균형형 · 퍼펙트 판정 +0.02 |
| 2030 골든볼 | 0.88 | 77.7px | 0.87s | 3000코인 | 코인 획득 +15% |

(난이도 50 · 조작 설정 기본값 기준. 점프 높이 = flap² / 2g)

무게는 중력에 곱해지고 킥 배율은 탭 상승력에 곱해진다.
그래서 **공을 바꾸면 상하 운동이 실제로 달라진다** — 가벼운 공은 붕 뜨고,
무거운 공은 짧고 빠르게 튄다. 취향과 조작 스타일에 맞춰 고르는 요소다.

코인으로 해금하며, 이것이 코인의 주 사용처다.

## 조작 설정 (시작 화면 → ⚙ 조작 설정)
| 항목 | 범위 | 기본 | 설명 |
|---|---|---|---|
| 공 상하 미세 조정 | 20 ~ 100 | 50 | 탭 반응 속도. 점프 높이는 그대로 |
| 스피드 | 30 ~ 100 | 50 | 골문이 다가오는 속도 |

값은 프로필에 저장되고 즉시 반영된다. 난이도를 낮추는 치트가 아니라
**손에 맞추는 값**이다 — 쉬워진 만큼 AI 가 난이도를 올려 균형을 잡는다.

## 실패 조건
- 골문 기둥과 충돌
- 천장 또는 잔디에 닿음

## 화면 구성
- 상단 좌: SCORE / COIN·LV
- 상단 우: DIFFICULTY / STAGE·COMBO
- 결과 화면: 점수·콤보·퍼펙트, 코인·XP·아이템, 새 난이도와 **그 근거**, 스탯 배분

## 설계 원칙
1. **난이도는 설명 가능해야 한다.** 결과 화면이 왜 어려워졌는지/쉬워졌는지 문장으로 보여준다.
2. **불가능한 배치를 만들지 않는다.** 골문 높이는 도달 가능한 범위로만 생성한다.
3. **실패해도 손실이 없다.** 최소 코인·XP 를 지급한다.
4. **한 화면, 한 파일.** 설치 없이 브라우저에서 즉시 실행된다.
