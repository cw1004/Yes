# Aside 브라우저 에이전트 프롬프트 (수정판)

> 기존 프롬프트의 문제와 수정 이유는 `../README.md` 「5. Aside 활용 범위」를 참고하세요.
> 이 프롬프트들은 **특정 버튼 색·위치를 가정하지 않습니다.** 사이트 UI가 바뀌어도 동작하도록
> "목표 + 확인 기준 + 멈출 지점"만 지시합니다. 결제는 언제나 사람이 직접 합니다.

## 사용 원칙

1. **하루 20건 이하**일 때만 에이전트 발주를 씁니다. 그 이상은 `python3 -m beauty_seller orders`로
   대량발주 파일을 만들어 공급사의 엑셀 대량주문 기능에 업로드하세요(더 빠르고 오류가 적음).
2. 고객 이름·주소·연락처는 에이전트가 읽는 순간 AI 서비스로 전송될 수 있습니다.
   개인정보처리방침에 '처리위탁(및 국외이전 여부)'을 적어두고, Aside의 데이터 정책을 먼저 확인하세요.
3. 결제·예치금 차감·주문 확정 버튼은 **절대** 에이전트가 누르지 않게 합니다.
4. 한 번에 한 주문. 주문마다 사람이 확인 → 결제 → 시트에 "발주완료" 표시.

---

## ① 단건 발주 (공급사 사이트 공통)

```
너는 내 위탁 발주 보조야. 아래 규칙을 반드시 지켜.
- 결제, 주문 확정, 예치금 사용 버튼은 절대 누르지 마.
- 상품이 정확히 일치하지 않거나, 품절이거나, 옵션이 다르면 즉시 멈추고 이유를 말해.
- 입력한 값은 마지막에 표로 다시 보여줘.

[작업]
1. "발주관리" 시트에서 상태가 "발주대기"인 첫 번째 행을 찾아 다음 값을 읽어:
   주문번호, 공급사상품코드, 수량, 수령인, 연락처, 우편번호, 주소, 배송메시지
2. [공급사 사이트] 탭으로 이동해. 로그인이 안 되어 있으면 멈추고 나에게 로그인을 요청해.
3. 검색창에 '공급사상품코드'로 검색해. 결과가 정확히 1개이고 코드가 일치할 때만 상세 페이지로 들어가.
4. 수량을 시트 값으로 맞추고 주문서 작성 단계로 이동해.
5. 배송지 입력:
   - '주문자(회원) 정보와 동일' 같은 자동 채움 옵션은 끄고 새 배송지로 입력해.
   - 우편번호는 주소검색 결과에서 시트의 우편번호와 같은 항목을 고르고, 나머지 주소를 상세주소에 입력해.
   - 배송메시지가 비어 있으면 "안전배송 부탁드립니다."
6. 결제수단 선택 화면이 보이면 멈추고 아래 표를 보여줘:
   | 항목 | 시트 값 | 화면에 입력된 값 | 일치 |
   (상품코드, 상품명, 수량, 수령인, 연락처, 우편번호, 주소, 배송메시지, 최종 결제 예정 금액)
```

## ② 송장번호 회수 (공급사 → 시트)

```
결제나 주문 변경 버튼은 누르지 마.
1. [공급사 사이트]의 주문/배송 조회 메뉴로 가서 최근 7일 주문 목록을 열어.
2. 각 주문의 '참조주문번호(또는 배송메시지·수령인)', 택배사, 송장번호를 읽어.
3. "발주관리" 시트에서 같은 주문번호 행의 택배사·송장번호 칸을 채우고 상태를 "송장확보"로 바꿔.
4. 수령인 이름이 시트와 다르거나 송장번호가 없는 건은 채우지 말고 목록으로 보고해.
```

## ③ 마켓에 송장 입력 (소량일 때만)

```
1. "발주관리" 시트에서 상태가 "송장확보"인 행을 읽어.
2. [스마트스토어 판매자센터] 발송처리 화면에서 상품주문번호로 각 주문을 찾아 택배사·송장번호를 입력해.
3. '발송처리' 최종 버튼을 누르기 직전에 멈추고, 입력 목록을 표로 보여줘. 내가 확인 후 누를게.
```

> 주문이 늘면 ②·③은 마켓의 **엑셀 일괄발송** 기능이나 공식 API(네이버 커머스API, 쿠팡 Open API)
> 기반 통합관리 솔루션으로 넘기세요. 브라우저 자동 조작은 사이트 약관상 제한될 수 있습니다.

## ④ 상품 소싱 조사 (개인정보 없음 — 에이전트가 가장 잘하는 일)

```
[공급사 사이트]에서 아래 조건으로 상품을 찾아 표로 정리해 줘. 장바구니·주문은 하지 마.
- 카테고리: [세럼]
- 조건: 위탁배송 가능, 온라인 판매 허용, 상세페이지 이미지 사용 허용 표시가 있는 상품
- 표 열: 상품명, 공급사상품코드, 공급가, 권장소비자가, 공급가/권장가 비율, 묶음배송 가능 여부,
  배송비, 전성분 표기 여부, 온라인 최저가(네이버 쇼핑 검색 1페이지 기준)
- 온라인 최저가가 (공급가 × 1.3)보다 낮은 상품은 '가격경쟁 불리'로 표시
```
