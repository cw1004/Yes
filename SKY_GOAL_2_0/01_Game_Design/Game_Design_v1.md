# SKY GOAL 2.0 — 게임 디자인 v1.0

## 한 줄 정의
탭 한 번으로 공을 띄워 움직이는 골문을 통과하는 원버튼 아케이드.
**플레이할수록 게임이 나에게 맞춰진다.**

## 핵심 루프
```
탭 → 골문 통과 → 콤보/퍼펙트 → 점수 → 스테이지 변화 → 사망
  → 코인·XP·아이템 → 레벨업/스탯 → AI 난이도 재계산 → 다음 판
```
한 판은 짧게(수십 초), 판 사이의 성장과 난이도 조정이 재시작 동기를 만든다.

## 킥오프 — 경기의 시작
"경기 시작"을 누르면 바로 조작이 시작되지 않고 **킥오프 연출**이 먼저 나온다.

| 시간 | 장면 |
|---|---|
| 0.00s | 심판 휘슬, 공은 잔디 위에 정지 |
| 0.00~0.55s | 선수가 왼쪽에서 달려온다 |
| 0.55~0.85s | 플랜트 · 백스윙 |
| **0.85s** | **임팩트** — 킥 사운드, 잔디 파편, 공 발사 |
| 0.85~1.47s | 공이 포물선을 그리며 플레이 위치로 |
| 1.47s | 플레이 시작 |

- 임팩트 순간의 초기 속도는 **플레이 시작 지점에 정확히 도착하도록 역산**한다.
  연출이 끝나면 공이 그 자리에 자연스럽게 놓이므로 위화감이 없다.
- 화면을 탭하면 언제든 **연출을 건너뛰고** 바로 시작한다.
- 시작 버튼 클릭이 사용자 제스처이므로 이 시점에 오디오가 열린다 (첫 탭 전에도 소리가 난다).

**선수는 이름·얼굴·등번호가 없는 실루엣이다.** 실존 선수를 묘사하지 않는다
(초상권·퍼블리시티권 문제 및 스토어 심사 회피).

## 조작
- 탭 / 클릭 / 스페이스 / ↑ : 공 띄우기 (원버튼)
- 시작 직후에는 **TAP TO START** 준비 상태로 대기한다. 화면을 보기도 전에 죽지 않는다.
- 탭으로 게임이 시작된 뒤부터 시간·물리가 흐른다.

## 모드 — 아마추어 / 프로
시작 화면에서 고른다. AI 난이도 엔진은 그대로 쓰고 **그 위에 모드 보정**을 곱한다.

| | 아마추어 | 프로 |
|---|---|---|
| 난이도 밴드 | 10 ~ 95 | **35 ~ 99** (+22 오프셋) |
| 골문 간격 | ×1.00 | **×0.88** |
| 스크롤 속도 | ×1.00 | **×1.15** |
| 골문 흔들림 | ×1.00 | **×1.30** |
| 퍼펙트 판정 | ×1.00 | **×0.72** |
| 코인·XP | ×1.00 | **×1.60** |

난이도 50 기준 실측: 골문 175 → 137px, 속도 305 → 412px/s.

**해금 조건**: 아마추어에서 **200점 돌파** 또는 **완주 1회**.
처음부터 프로를 열어두면 대부분 첫 판에 죽고 앱을 지운다. 아마추어에서 실력이
붙었다는 신호가 나온 뒤에 열어야 "이제 진짜를 해볼까"가 된다.

**모드별로 따로 관리되는 것**: 학습된 난이도 D, 숙련도 S, 최고 점수, 최근 10게임 기록.
프로에서 고전한다고 아마추어 난이도가 내려가지 않는다.
코인·레벨·공·완주 횟수는 공용이다.

## 공 5종 (시작 화면 → ⚽ 공 선택 · 상점)
| 공 | 무게 | 점프 높이 | 체공 | 가격 | 특성 |
|---|---|---|---|---|---|
| 거리의 낡은 공 | 1.00 | 60.8px | 0.72s | 기본 제공 | 기준값 |
| 고무공 | 0.78 | 71.9px | 0.89s | 300코인 | 높이 뜨고 천천히 떨어진다 |
| 훈련용 중량구 | 1.30 | 58.7px | 0.62s | 800코인 | 낮게 뜨고 빠르게 떨어져 민첩 |
| 공식 경기구 | 0.94 | 67.3px | 0.79s | 1500코인 | 균형형 · 퍼펙트 판정 +0.02 |
| 2030 골든볼 | 0.88 | 77.7px | 0.87s | 3000코인 | 코인 획득 +15% |

(난이도 50 · 조작 설정 기본값 기준. 점프 높이 = flap² / 2g)

무게는 중력에 곱해지고 킥 배율은 탭 상승력에 곱해진다.
그래서 **공을 바꾸면 상하 운동이 실제로 달라진다** — 가벼운 공은 붕 뜨고,
무거운 공은 짧고 빠르게 튄다. 취향과 조작 스타일에 맞춰 고르는 요소다.

코인으로 해금하며, 이것이 코인의 주 사용처다.

## 장비 · 조각 (시작 화면 → 🎽 장비 · 조각)

한 판마다 등급 조각 1개를 받고, 모아서 **원하는 장비를 직접 만든다**(뽑기 아님).
슬롯은 3개이고 슬롯마다 등급별로 1종씩, 모두 12종이다.

| 슬롯 | 성격 | LEGENDARY |
|---|---|---|
| BOOTS · 부츠 | 물리 · 조작 | 2030 실버 부츠 — 퍼펙트 2연속마다 COMBO +1 |
| BAND · 암밴드 | 보상 · 성장 | 2030 캡틴 완장 — COMBO 10+ 에서 코인·XP +25% |
| CHARM · 부적 | 확률 · 안전 | 2030 골든 휘슬 — 사망 시 1회 부활 |

소모품은 경기 전에 하나만 고르고 **시작하는 순간 소비**된다.
플레이 중에 누를 버튼은 없다 — 이 게임은 원버튼이고, 그 원칙을 깨지 않는다.

장비 보정 상한은 코인·XP +30%, 물리 ±15%. 부활은 판당 1회이고
**PRO 모드에서는 발동하지 않는다**(기록 공정성).

자세한 수치는 `05_Reward_Economy/Reward_Growth_System_v1.md` 참조.

## 조작 설정 (시작 화면 → ⚙ 조작 설정)
| 항목 | 범위 | 기본 | 설명 |
|---|---|---|---|
| 공 상하 미세 조정 | 20 ~ 100 | **20**(하한) | 탭 반응 속도. 점프 높이는 그대로 |
| 스피드 | 30 ~ 100 | **30**(하한) | 골문이 다가오는 속도 |

값은 프로필에 저장되고 즉시 반영된다. 난이도를 낮추는 치트가 아니라
**손에 맞추는 값**이다 — 쉬워진 만큼 AI 가 난이도를 올려 균형을 잡는다.
이 설정은 **아마추어·프로 모드 공용**이다(모드별로 따로 저장되지 않는다).
신규 프로필은 가장 느긋한 값(20/30)으로 시작해 처음 접하는 사람도
편하게 적응하도록 하고, 손에 익으면 직접 올리게 한다.

## 완주 — 헹가래 세리머니
무한 게임이므로 "끝"을 **마지막 스테이지(WORLD FINAL) 도달**로 정의한다.

```
스테이지 = 진행도 구간(통과 골문 수) + floor(난이도 / 25)
→ 난이도 50 이면 골문 약 30개, 난이도 75 이면 약 20개에서 WORLD FINAL 도달
```

도달하는 순간 경기가 잠시 멈추고 **동료 3명이 헹가래**를 친다.

| 시간 | 장면 |
|---|---|
| 0.0s | 팡파르, BGM 정지, 응원단 최고조 |
| 0.4s~ | 3번 띄웠다 받는다 (한 번에 0.62초, 높이 110→154px) |
| 1.1s | 선물 발표 |
| 3.2s | 자동 종료 (1.4초 뒤부터는 탭으로 건너뛰기 가능) |

세리머니가 끝나면 **경기는 계속된다.** 눈앞의 골문을 비우고 공을 플레이 위치에
되돌린 뒤 준비 상태로 넘어가므로, 세리머니 직후에 죽는 일이 없다.

### 완주 선물
| 조건 | 선물 |
|---|---|
| 골든볼 미보유 | **2030 골든볼**(정가 3000코인)을 무료로 주고 바로 장착 |
| 이미 보유 | **1000코인 + 레전더리 아이템** |

완주 횟수는 프로필에 누적되어 시작 화면과 결과 화면에 표시된다.
가장 비싼 공을 첫 완주 보상으로 준 것은, 상점을 구경만 하던 사람에게
"코인을 모을 이유"를 실물로 쥐어 주기 위해서다.

## 사이드라인 응원단
경기장 앞쪽 잔디(**플레이 영역 바깥**)에서 치어리더 3~6명이 응원한다.
충돌·점수·물리에 전혀 관여하지 않는 **순수 배경 연출**이다.

| 순간 | 반응 |
|---|---|
| 킥오프 임팩트 | 환호 +1.2, 색종이 |
| 골문 통과 | 환호 +0.5 |
| 퍼펙트 통과 | 환호 +1.0, 색종이 |
| 스테이지 전환 | 환호 +1.4 (최고조), 색종이 |

환호 수치는 초당 0.85씩 식는다. 뜨거울수록 점프가 커지고 폼폼 흔들림이 빨라진다.

> 이전 버전에는 경기 중 헤딩 보너스 선수가 있었으나, **플레이를 방해해서 제거**했다.
> 화면 중앙에 오브젝트를 두는 대신, 잔디 아래쪽에서 반응하는 연출로 바꿨다.

## 실패 조건
- 골문 기둥과 충돌
- 천장 또는 잔디에 닿음

## 화면 구성
- 상단 좌: SCORE / COIN·LV
- 상단 우: DIFFICULTY / STAGE·COMBO
- 결과 화면: 점수·콤보·퍼펙트, 코인·XP·아이템, 새 난이도와 **그 근거**, 스탯 배분

## 설계 원칙
1. **난이도는 설명 가능해야 한다.** 결과 화면이 왜 어려워졌는지/쉬워졌는지 문장으로 보여준다.
2. **불가능한 배치를 만들지 않는다.** 골문 높이는 도달 가능한 범위로만 생성한다.
3. **실패해도 손실이 없다.** 최소 코인·XP 를 지급한다.
4. **한 화면, 한 파일.** 설치 없이 브라우저에서 즉시 실행된다.
