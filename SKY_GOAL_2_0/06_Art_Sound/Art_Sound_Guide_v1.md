# 아트 / 사운드 가이드 v1.1

구현 위치: `07_MVP_Code/src/scenery.js` (배경), `src/audio.js` (사운드)

## 1. 배경 — 히말라야 능선 + 강 + 경기장

화면은 위에서 아래로 다음 순서로 쌓인다. 각 층이 다른 속도로 흘러 원근감을 만든다.

| 층 | 내용 | 패럴랙스 |
|---|---|---|
| 하늘 | 스테이지별 그라디언트, 별, 해/달, 구름, 새 | 0.02 ~ 0.05 |
| 먼 산 | 만년설이 덮인 높은 능선 | 0.06 |
| 가까운 산 | 어두운 능선 | 0.12 |
| 대기 | 원근 흐림(헤이즈) | 고정 |
| 숲 | 강 건너 나무 실루엣 | 0.22 |
| 강 | 그라디언트 + 물비늘 + 해·달 반사 | 0.35 |
| 강둑 | 앞쪽 둔치 | 고정 |
| 잔디 | 경기장 줄무늬 | 1.00 |

지형은 시드(20300101) 기반으로 **한 번만** 생성한다. 매 프레임 모양이 흔들리지 않고,
리사이즈해도 같은 산이 나온다. 능선의 첫 점과 끝 점 높이를 맞춰 좌우로 무한 반복해도
이음매가 보이지 않는다.

## 2. 스테이지 팔레트

| 스테이지 | 하늘 | 먼 산 | 강 | 특징 |
|---|---|---|---|---|
| DAY | `#3aa5f0` → `#cdeeff` | `#8aa6c2` | `#63bfe6` | 해, 구름, 새 |
| SUNSET | `#ff6a2a` → `#ffd9a0` | `#8a5f72` | `#ffab5e` | 큰 해, 황금빛 물 반사 |
| NIGHT | `#050d22` → `#1b4470` | `#1b2c47` | `#2c5382` | 별 70개, 달 |
| RAIN | `#2a3b4b` → `#8296a6` | `#4d6070` | `#5a7381` | 빗줄기 |
| WIND | `#2f6d92` → `#d5e9f4` | `#71889b` | `#7fb6cc` | 수평 바람선 |
| STORM | `#070f19` → `#33445a` | `#1c2836` | `#233444` | 비 + 바람 + 번개 섬광 |
| WORLD FINAL | `#1a0b2e` → `#ff9933` | `#4a2a56` | `#c07a35` | 인도 국기색 하늘 |

번개는 STORM / WORLD FINAL 에서 2.5~7초 간격으로 친다.

## 3. 오브젝트
- 공: 흰 원 + 어두운 오각형 패치, 반지름 15px, 속도에 따라 회전
- 골문 (인도 국기색 장식)
  - 기둥: 좌→우 그라디언트 + 마름모 네트 격자 + 좌우 프레임 + 뒤쪽 그림자
  - 크로스바: 위 주황(`#ff9933`) / 아래 초록(`#138808`), 양끝 흰색 캡
  - 삼색 트림: 주황·흰색·초록 3줄
  - 상단 배너 3종 (골문마다 랜덤): 삼색 리본 / 원형 엠블럼 / 삼각 깃발 줄
  - 나부끼는 깃발: 위 주황·아래 초록이 서로 반대로 흔들린다
  - 바닥 받침 그림자
- 퍼펙트: 골드 파티클 14개 / 일반 통과: 흰 파티클 6개 / 사망: 주황 파티클 22개

## 4. 사운드 — 전부 WebAudio 합성

외부 음원 파일이 없다. 단일 HTML 배포가 유지되고 로딩도 없다.

### BGM
132 BPM, 16분음표 스케줄러(0.12초 선예약). D 마이너 펜타토닉.
**스테이지가 올라갈수록 파트가 쌓인다.**

| 강도 | 스테이지 | 구성 |
|---|---|---|
| 0 | DAY / SUNSET | 킥 + 스네어 + 하이햇 + 베이스 |
| 1 | NIGHT / RAIN | + 싱코페이션 킥, 타블라 틱 |
| 2 | WIND / STORM | + 옥타브 베이스, 리드 아르페지오 |
| 3 | WORLD FINAL | + 고음 리드 |

### 효과음
| 이벤트 | 소리 |
|---|---|
| 탭 | 680→340Hz 트라이앵글 + 짧은 노이즈 틱 |
| 골문 통과 | 스퀘어 상승음 (콤보가 쌓일수록 음이 높아진다) |
| 퍼펙트 | 3음 상승 차임 |
| 스테이지 전환 | 220→880Hz 스윕 + 관중 함성(밴드패스 노이즈 스윕) |
| 사망 | 320→60Hz 하강음 + 저역 임팩트 |
| 레벨업 | 4음 상승 아르페지오 |

### 정책 대응
- 브라우저는 사용자 입력 전에는 소리를 내지 않는다 → **첫 탭에서 `unlock()`** 후 재생
- 우하단 🔊/🔇 버튼으로 음소거, 설정은 프로필에 저장된다
- `AudioContext` 가 없거나 생성이 막힌 환경에서는 모든 호출이 조용히 무시된다
  (게임은 정상 동작)
