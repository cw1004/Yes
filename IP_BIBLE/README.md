# IP 바이블 — 세 친구의 여행

NUBI · WOBI · SARO 세 캐릭터를 **장기간 일관되게 쓰기 위한 기준 문서**.

| 파일 | 내용 |
|---|---|
| `01_Character_Bible.md` | 세계관 · 성격 · 말투 · 색상 · 실루엣 · 성장단계 · 관계도 · 표현 규정 · IP 보호 로드맵 |
| `characters.json` | **색상과 수치의 유일한 기준.** 사람이 읽는 문서가 아니라 기계가 읽는 원본 |

## 왜 JSON 이 따로 있나

색상값을 문서에만 적어 두면 반드시 어긋난다.
라이선시는 바이블을 보고 굿즈를 만들고, 사용자는 게임 화면을 본다.
둘이 다르면 **같은 캐릭터로 보이지 않는다.**

그래서 `characters.json` 을 기준으로 삼고,
게임 코드와 어긋나면 테스트가 실패하게 해 두었다.

```bash
cd ../THREE_FRIENDS && node --test 07_MVP_Code/tests/bible.test.js
```

이 테스트는 다음을 강제한다.
- 바이블과 게임의 캐릭터 목록·색상값·행동·전담 장애물이 같은가
- 볼터치와 외곽선을 셋이 공유하는가 (한 가족으로 보이는 최소 장치)
- 포인트 색이 셋 다 다른가
- **몸 색이 흑백으로 줄여도 구분되는가**

## 색을 바꾸려면

1. `characters.json` 을 고친다
2. `THREE_FRIENDS/07_MVP_Code/src/engine.js` 의 `CHARACTERS` 를 같이 고친다
3. `01_Character_Bible.md` 3장의 표를 같이 고친다
4. 테스트를 돌려 통과하는지 확인한다

순서를 지키지 않으면 테스트가 막는다. 그게 이 구조의 목적이다.
