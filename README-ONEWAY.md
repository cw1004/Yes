# 하나의 길 — ONE WAY

> 먼저 듣습니다. 조언은 그 다음입니다.

지치고 외로운 사람이 아무 때나 와서 말할 수 있는 자리입니다.
중심에는 **상담사 「곁」**이 있습니다.

```
사람의 고민 → 검색 → 순수한 상담(종교 언어 없음)
           → 한 번에 안 끝나는 고민은 여러 날에 걸친 여정으로
           → 상대가 스스로 열 때만 더 깊은 이야기 → 재방문 → 공동체
```

```bash
python3 -m oneway serve        # 홈페이지 → http://127.0.0.1:8000
python3 -m oneway ask          # 터미널에서 상담사와 대화해 보기
python3 -m oneway book         # 전자책 만들기 (수익은 전액 기부)
python3 -m oneway check        # 환경 점검
```

**외부 API 키가 없어도 전부 동작합니다.** 키가 없으면 규칙 기반 엔진이,
키가 있으면 Claude 가 답합니다. 방문자는 어느 쪽인지 몰라도 됩니다.

## 0. 가장 중요한 두 가지 원칙

### ① 처음에는 색깔을 지운다

처음 온 사람에게는 **교파는 물론이고 신앙 언어조차 쓰지 않습니다.**
사람은 설득당하러 오지 않습니다. 힘들어서 옵니다.

| 깊이 | 언제 | 쓸 수 있는 말 |
| --- | --- | --- |
| **0 · 열림** | 기본값 | 순수한 상담. 하느님·성경·기도·교회라는 말을 **한 단어도** 쓰지 않음 |
| **1 · 이야기** | '왜 사는가' 같은 큰 질문에 닿았을 때 | 출처를 밝히지 않은 오래된 이야기 한 토막 |
| **2 · 신앙** | 상대가 신앙 언어를 **먼저** 썼을 때 | 성경의 '주소', 기도 한 줄 |
| **3 · 전통** | 상대가 교파를 **직접 물었을 때만** | 가톨릭·개신교를 공정하게 |

깊이는 **상대가 엽니다.** 우리가 끌어올리지 않습니다.
문은 페이지 아래쪽에 정직한 이름으로 조용히 둡니다(「더 깊은 질문이 있으시다면」).

“종교 이야기는 하지 말아 달라”고 한 번이라도 말하면 **영구히 깊이 0**입니다.
한 번 거절한 사람에게 두 번 권하지 않습니다.

같은 페이지가 사람에 따라 다르게 보입니다. 예를 들어 `/today` 는
아직 문을 열지 않은 사람에게 「오늘의 질문」과 「오늘의 한 걸음」만 보여 주고,
문을 연 사람에게만 「오늘의 말씀」과 「오늘의 기도」가 함께 나옵니다.

### ② 기계 티를 내지 않되, 거짓말은 하지 않는다

피하려는 것은 두 가지입니다.

* **기계 티** — "①공감 ②말씀 ③질문" 같은 딱지, 매 답변마다 붙는 고지문,
  이모지 머리표, 늘 똑같은 첫 문장. 전부 없앴습니다.
* **거짓말** — 그렇다고 사람인 척하지는 않습니다.

그래서 택한 자리는 이것입니다.
**먼저 밝히지 않는다. 물으면 정직하게 답한다. 절대 아니라고 하지 않는다.**

| | 예전 | 지금 |
| --- | --- | --- |
| 상담 화면 첫인상 | "이 상담사는 AI입니다" 세 문단 | 조용한 한 줄 + 「이곳에 대하여」 링크 |
| 매 답변 | 고지문이 매번 붙음 | 붙지 않음 (위험 신호가 있을 때만) |
| "사람이세요?" | — | 즉시 "사람이 아닙니다"라고 답함 |
| 위기 상황 | — | **반드시 먼저 밝힘.** 사람에게 연락해야 하니까 |
| 답변 모양 | 항상 5칸 고정 | 1번째는 듣기만, 회차가 쌓이면 깊어짐 |

## 1. 첫 화면

첫 화면에서 결정됩니다. 원칙 세 가지로 만들었습니다.

**① 말을 걸기까지 클릭이 0번**

예전에는 「지금 이야기하기」를 눌러 `/counsel` 로 넘어간 뒤에야 입력할 수
있었습니다. **클릭 한 번이 곧 이탈 지점**입니다. 그래서 입력창을 첫 화면으로
올렸습니다. 들어오자마자 바로 씁니다.

자바스크립트가 없어도 동작합니다. 평범한 `<form action="/counsel" method="get">`
이라서, 제출하면 상담사가 그 문장으로 답을 시작합니다.

**② 지금 상태를 한 번에 고르는 단추**

```
  너무 지쳤어요   혼자인 것 같아요   잠이 안 와요   앞날이 무서워요
```

무슨 말부터 해야 할지 모르는 사람이 대부분입니다. 하나 누르면 문장이 채워집니다.

**③ 묻지 않는다는 사실을 먼저 보여 준다**

```
  · 이름 안 물음  · 연락처 안 물음  · 로그인 없음  · 무료  · 24시간
```

이게 이 사이트의 가장 큰 차별점입니다. 스크롤 없이 보여야 합니다.

### 시간에 따라 말이 바뀝니다

서버는 시간에 좌우되지 않는 문구를 그리고, 방문자의 **자기 시계**를 보고
자바스크립트가 바꿉니다. 서버 시간대와 상관없이 맞고, JS 가 없어도 자연스럽습니다.

| 시각 | 문구 |
| --- | --- |
| 기본 (서버) | 말할 데가 없을 때 / **혼자 두지 않겠습니다** |
| 새벽 0~5시 | 새벽 세 시에도 / **여기 있습니다** |
| 아침 6~10시 | 오늘도 버텨야 하는 아침에 / **잠깐 앉았다 가세요** |
| 낮 11~17시 | 괜찮은 척하느라 지쳤다면 / **여기서는 안 그러셔도 됩니다** |
| 밤 18~23시 | 하루를 겨우 끝냈다면 / **혼자 삼키지 마세요** |

요란하게 만들지 않았습니다. 힘든 사람이 오는 곳이지 판촉 페이지가 아닙니다.

## 2. 보통의 교회 홈페이지와 다른 점

| 보통의 교회 홈페이지 | 하나의 길 |
| --- | --- |
| 첫 화면이 교회 소개·예배 시간 | 첫 화면에 **입력창이 있음** — 클릭 0번 |
| 메뉴만 봐도 종교 사이트인 게 보임 | 1차 메뉴에 신앙 항목이 없음 |
| 방문자는 읽고 나감 | 상담사가 **말을 걺** |
| 처음부터 "우리 교회로 오세요" | 상대가 열기 전에는 신앙 언어조차 안 씀 |
| 한 번 보면 끝 | 하루 3분 · 연속 방문 · 맡긴 바람 되묻기 |

## 3. 설치와 실행

```bash
# 1) 파이썬 3.9 이상이면 됩니다. 추가 설치 없이 바로 실행됩니다.
python3 -m oneway check

# 2) 홈페이지 띄우기
python3 -m oneway serve --port 8000
#    → http://127.0.0.1:8000

# 3) (선택) 상담 품질 올리기 — Claude 연결
pip install anthropic
export ANTHROPIC_API_KEY=sk-ant-...
python3 -m oneway serve
```

`make` 를 쓰신다면:

```bash
make serve PORT=8080     # 홈페이지
make ask                 # 터미널 상담
make today               # 오늘의 3분
make site                # 정적 사이트 내보내기
make test                # 테스트
```

## 4. 폴더 구조

```
oneway/
├── cli.py              커맨드라인 (serve / ask / today / check / build / sitemap / purge)
├── config.py           설정 (도메인·포트·모델·데이터 폴더)
├── seo.py              sitemap.xml · robots.txt
├── donate.py           판매·기부 장부 (수익 전액 기부 약속의 증거)
│
├── book/               전자책
│   ├── content.py        1부는 새로 쓴 에세이 10편 · 2~3부는 기존 콘텐츠
│   ├── personal.py       그 사람을 위한 책 (주제·깊이만 사용, 원문은 안 씀)
│   ├── epub.py           EPUB 3 생성 (표준 라이브러리만)
│   └── render.py         한 장짜리 HTML(인쇄용 CSS) · 마크다운
│
├── content/            사이트에 실리는 모든 글
│   ├── verses.py         성경 '주소' 64개 + 우리가 풀어 쓴 한 줄  ← 저작권 안전장치
│   ├── fifty.py          우리가 함께 믿는 50가지 (깊이 2 콘텐츠 · 검색 유입 통로)
│   ├── entries.py        7개의 입구 — 겉에 4개(마음·가족·사랑·미래), 안쪽에 3개
│   ├── paths.py          여정 — 여러 날에 걸쳐 가는 길 (불안한 시대를 지나는 9일)
│   ├── daily.py          하루 3분 + 30일 한 걸음
│   └── pages.py          「나는 교회를 떠났습니다」 「이곳에 대하여」 등
│
├── counselor/          상담사 「곁」
│   ├── depth.py          ★ 대화의 깊이 판정 — 이 사이트에서 가장 중요한 파일
│   ├── persona.py        말투, 이름, 정체를 물었을 때의 정직한 답
│   ├── safety.py         위기 감지 + 날짜 예언·통제 집단 경고  ← 가장 먼저 실행
│   ├── topics.py         고민 주제 26개. **깊이별로 칸이 나뉘어 있음**
│   ├── engine.py         대화 조립 (Claude 실패 시 자동 폴백)
│   ├── llm.py            Claude API 연동 + 종교어 누출 차단
│   └── session.py        연속 방문·열린 깊이·맡긴 바람 기억
│
└── web/
    ├── server.py       표준 라이브러리 HTTP 서버
    ├── render.py       HTML (SEO 메타 · Open Graph · JSON-LD)
    └── static/         style.css · app.js
```

`topics.py` 의 주제 하나는 이렇게 생겼습니다.

```python
empathy / insight / questions / steps / closing   # 깊이 0 — 종교어 0개
story                                             # 깊이 1 — 출처 없는 이야기
faith_insight / verses / prayer / faith_steps     # 깊이 2 — 상대가 열었을 때만
```

깊이 0 칸에 종교어가 한 단어라도 들어가면 **테스트가 실패합니다.**

## 5. 상담사가 답하는 순서

```
입력
 ├─ ① 안전 점검 (safety.py)
 │     위기 신호면 → 다른 이야기를 멈추고 24시간 상담 전화부터
 ├─ ② 깊이 판정 (depth.py)
 │     거절한 적이 있으면 무조건 0. 예외 없음
 ├─ ③ 주제 분류 (topics.py) — 단서가 없으면 직전 주제를 이어받음
 ├─ ④ 응답 생성  Claude 가 있으면 Claude, 없거나 실패하면 규칙 엔진
 │     깊이 0~1 응답에 종교어가 섞이면 **버리고 규칙 엔진으로 다시 답함**
 ├─ ⑤ 콘텐츠 연결  깊이 0 에서는 신앙 콘텐츠를 걸지 않음
 └─ ⑥ 다시 올 이유
```

답변은 **한 덩어리의 말**로 나갑니다. 소제목도 이모지 머리표도 없습니다.
그리고 회차에 따라 모양이 달라집니다.

| 회차 | 하는 일 |
| --- | --- |
| 1번째 | 받아 주고, 관점 하나, 되묻기. **처방하지 않음** |
| 2번째 | + 오늘 할 수 있는 아주 작은 행동 하나 |
| 3번째~ | + 들고 갈 한 줄. 질문이 더 깊어짐 |

듣자마자 해결책을 내미는 것이 가장 상담답지 않은 행동이라서 그렇습니다.

### 실제 출력 (깊이 0)

```
많이 지치셨네요. 여기까지 버텨 오신 것만으로도 적지 않습니다.

지침은 게으름의 반대말이 아니라, 오래 애쓴 사람에게 생기는 증상입니다.

하나만 여쭤도 될까요. 요즘 가장 많은 힘을 빼앗아 가는 건 무엇입니까?

  → 마음의 쉼 · 오늘의 하루 3분
  여기는 늘 열려 있습니다. 급할 것 없습니다.
```

### 안전 원칙 (타협하지 않는 부분)

* 위기 표현이 감지되면 **모델을 호출하지 않고** 규칙 기반 안내문을 먼저 띄웁니다.
  AI 출력에 사람 목숨을 맡기지 않습니다.
* 위기 상황에서는 **사람이 아니라는 사실을 반드시 먼저 밝힙니다.**
  그래야 사람에게 연락할 수 있습니다.
* "힘들어 죽겠다" 같은 관용 표현은 위기로 오인하지 않습니다(테스트로 고정).
* 마찬가지로 "사람 만나기도 싫다"의 '기도', "말씀하시길"의 '말씀',
  "결혼식 신부", "영세한 회사"를 신앙 신호로 오인하지 않습니다.
  깊이를 잘못 올리면 원하지 않는 사람에게 종교 이야기를 하게 됩니다.
* 우울이 2주 이상 이어진다는 말에는 진료를 권하되,
  **의지의 문제가 아니라고** 분명히 말합니다.
* 모든 페이지 하단에 자살예방 상담전화 **109** 가 항상 노출됩니다.

> 전화번호는 바뀔 수 있습니다. 운영 전에 `oneway/counselor/safety.py` 의
> `HOTLINES_KR` 을 최신 정보로 반드시 확인하십시오.

## 6. 재방문을 만드는 장치

| 장치 | 주기 | 구현 |
| --- | --- | --- |
| 하루 3분 | 매일 | `content/daily.py` — 날짜만으로 결정되어 서버 저장이 필요 없음 |
| 우리가 함께 믿는 50가지 | 50일 | `content/fifty.py` |
| 30일 한 걸음 | 30일 | `daily.LOVE_30` |
| 맡긴 바람 되묻기 | 비정기 | `counselor/session.py` — "그 뒤로 좀 어떻게 되었습니까?" |
| **불안한 시대를 지나는 9일** | 9일 | `content/paths.py` — 걸음마다 다음 걸음 예고 |
| **당신을 위한 책** | 이야기가 쌓일 때마다 | `book/personal.py` — 다시 만들면 다른 장이 들어온다 |

50일과 30일 두 바퀴가 겹쳐 돌기 때문에 **같은 조합은 150일에 한 번**만 돌아옵니다.
(테스트로 고정되어 있습니다.)

## 7. 여정 — 한 번에 끝나지 않는 고민

전쟁, 지진, 기후 재난. "세상이 끝나는 것 같다"는 불안은 한 번 위로하고
보내면 다음 뉴스에서 다시 무너집니다. 그래서 **여러 날에 걸쳐 한 걸음씩
가는 길**을 따로 만들었습니다.

### 불안한 시대를 지나는 9일 (`/path/anxious-times`)

| 걸음 | 깊이 | 제목 |
| --- | --- | --- |
| 1 | 0 | 무섭다고 느끼는 게 이상한 게 아닙니다 |
| 2 | 0 | 뉴스는 세상을 보여 주지 않습니다 |
| 3 | 0 | 준비는 불안을 줄입니다 (실제 재난 대비) |
| 4 | 0 | 당신이 할 수 있는 것과 없는 것 |
| 5 | 1 | 무너지는 시대를 지나온 사람들 |
| 6 | 1 | 끝을 생각하면 오늘이 선명해집니다 |
| 7 | 2 | 희망은 낙관이 아닙니다 |
| 8 | 2 | **그날은 아무도 모릅니다** |
| 9 | 2 | 그러면 오늘 무엇을 할까요 |

**앞의 여섯 걸음에는 종교 이야기가 한 단어도 나오지 않습니다.**
거기까지만 읽어도 이 여정은 제 몫을 합니다. 무신론자도 끝까지 볼 수 있습니다.
뒤의 세 걸음은 6걸음 끝에서 *"원치 않으시면 여기서 멈추셔도 됩니다"* 라고
분명히 안내한 뒤에 나옵니다.

동작 방식:

* 각 걸음은 **다음 걸음을 예고**하고 끝납니다 — 다시 올 이유
* 걸은 곳까지 기억합니다. 다음에 오면 「이어서 걷기」가 그 자리를 가리킵니다
* **7걸음(신앙)까지 걸어온 것 자체가 동의**이므로, 그때 대화의 깊이가 열립니다.
  실제로 `/today` 화면이 그 순간부터 달라집니다
* 상담사는 **한 번만** 권합니다. 이미 걷고 있으면 다음 걸음을 가리킵니다
* 첫마디부터 권하지 않습니다. 대화가 한 번은 오간 뒤입니다

### 8걸음이 이 여정의 중심입니다

종말 불안은 **날짜를 정하는 집단이 사람을 끌어가는 통로**입니다.
"끝이 가까우니 들어오라"고 하는 사이트는 그 통로를 넓히는 일을 합니다.
그래서 정반대를 넣었습니다.

* 성경 자체가 그날과 그 시간은 아무도 모른다고 못 박습니다(마태 24,36)
* 날짜를 정한 사람들은 역사상 **전부 틀렸고**, 그 과정에서 사람들이
  집을 팔고 학교를 그만두고 가족과 끊겼습니다
* **두려움으로 사람을 모으는 곳은 신앙이 아니라 통제입니다**
* 가톨릭과 개신교가 이 지점에서는 갈리지 않습니다 — 교파 중립도 지켜집니다

이 경고는 **상담사에도 들어가 있습니다**(`counselor/safety.py`).
날짜를 정해 주는 말이나 통제 집단의 신호가 감지되면, 일반 상담 내용을
밀어내고 곧바로 이 이야기를 합니다. 중요한 말이 다섯 문단 뒤에 있으면
읽히지 않기 때문입니다.

```
나 > 어떤 모임에서 2027년에 끝난다고, 재산 다 바치라고 합니다

  (받아 주는 한 문단)
  그런데 한 가지는 분명히 말씀드리고 싶습니다. 끝나는 날짜를 정해서 말한
  사람들은 지금까지 전부 틀렸습니다. 한 번도 맞은 적이 없습니다.
  … 그건 믿음이 아니라 통제에 가깝습니다. 거기서 나오셔도 됩니다.
  그 모임 밖에, 지금 상황을 그대로 말할 수 있는 사람이 한 명이라도 있습니까?
```

**안전 문제라서 깊이 0 에서도 그대로 나갑니다.** 다만 위기 신호(자해·자살)가
같이 있으면 그쪽이 먼저입니다.

## 8. 전자책 — 「혼자 두지 않겠습니다」

```bash
python3 -m oneway book            # EPUB + HTML + 마크다운 생성
python3 -m oneway ledger          # 판매·기부 장부 확인
```

사이트 글을 그대로 옮기면 책이 되지 않습니다. 상담 자료는 조각으로 되어 있고
책은 이어지는 산문이어야 합니다. **1부는 새로 쓴 에세이입니다.**

| 부 | 내용 | 깊이 |
| --- | --- | --- |
| 여는 글 | 이 책을 읽으면 좋을 사람 · 수익 전액 기부 약속 | — |
| 1부 · 지금, 당신의 마음 | 새로 쓴 에세이 10편 | 0 (종교 언어 0개) |
| 2부 · 불안한 시대를 지나는 9일 | 여정 전문 | 0 → 2 |
| 3부 · 30일, 한 걸음씩 | 실천 + 오래 들고 다닐 질문 | 0 |
| 닫는 글 | 이 책을 산 돈이 가는 곳 | — |
| 부록 | 힘들 때 연락할 곳 · 날짜를 말하는 사람 · 성경 표기 안내 | — |

21장, 본문 약 9,400자. 한 장에 3분, 하루 한 장이면 한 달입니다.

**1부에 종교 언어가 한 단어도 없습니다.** 서점에서 집어 든 사람이 첫 장을
넘길 수 있어야 하기 때문입니다. 깊이는 2부에서 여정을 따라 올라갑니다.

### 출력 형식

| 형식 | 용도 |
| --- | --- |
| `.epub` | 전자책 서점 업로드용. 표준 라이브러리만으로 생성(의존성 0) |
| `.html` | 브라우저에서 읽기 + **인쇄 → PDF로 저장** (인쇄용 CSS 포함) |
| `.md` | 편집·다른 도구로 옮길 때 |

PDF 라이브러리를 넣지 않은 이유: 한글 폰트를 따로 챙겨야 하고 설치가 무거워집니다.
인쇄용 CSS 를 갖춘 HTML 을 브라우저에서 저장하면 글꼴 문제 없이 더 좋습니다.

표지는 외부 이미지 없이 SVG 로 그립니다 — 폰트·이미지 저작권 문제가 없습니다.

## 9. 「당신을 위한 책」 — 상담이 끝나면 그 사람의 책을 만든다

상담이 몇 번 오가면, 그 사람이 꺼낸 이야기로 책 한 권을 묶어 줍니다.
27개 주제 중 **실제로 꺼낸 것만** 골라 담고, **그 사람이 열어 둔 깊이까지만**
담습니다. 같은 사이트에서 두 사람이 서로 다른 책을 받습니다.

```bash
python3 -m oneway book --session <세션id>     # 터미널에서
# 또는 사이트에서 /my-book → EPUB / HTML 내려받기
```

| 부 | 내용 |
| --- | --- |
| 1부 · 당신이 꺼낸 이야기 | 많이 이야기한 순서대로 |
| 2부 · 조금 더 걸어 본다면 | 아직 안 꺼냈지만 대체로 같이 오는 주제 + 걷던 여정의 다음 걸음 |
| 3부 · 30일, 한 걸음씩 | 실천 |

### 절대 지키는 두 가지

**① 그 사람이 쓴 문장은 한 글자도 넣지 않습니다.**

이 사이트는 이름도 연락처도 받지 않습니다. 그런데 책에 *"당신은 남편의
폭력에 대해 말씀하셨습니다"* 같은 문장이 들어가면, **그 파일을 가족이 보는
순간 그 자체가 가해가 됩니다.**

그래서 쓰는 것은 **주제 키·깊이·횟수뿐**입니다. `build_profile()` 이 Visitor
에서 가져가는 값을 보면 확인할 수 있습니다 — 원문이 들어올 자리가 아예 없습니다.

테스트가 이걸 검증합니다. 아주 구체적인 문장("박지훈 과장이…", "빚이
삼천만원…", "아이가 왕따를…")을 입력한 뒤 **생성된 EPUB·HTML·마크다운
전체를 뒤져서** 그 단어들이 하나도 없는지 확인합니다. 세션 id 도 마찬가지입니다.

파일은 **내려받을 때마다 메모리에서 만들고 디스크에 남기지 않습니다.**
남기면 그 파일이 곧 개인정보가 됩니다.

**② 값을 받지 않습니다.**

마음을 쏟아낸 직후에 값을 붙이는 것은 상담이 아니라 영업입니다.
맞춤 책은 그 사람 것이고 무료입니다. 파는 책(7장)은 따로 있고,
책 안에 이렇게 적어 두었습니다.

> 이 사이트에는 파는 책이 따로 하나 있고, 그 수익은 전쟁으로 부모를 잃은
> 아이들과 남겨진 가족들에게 전액 전달됩니다. 마음이 생기시면 그때 보시면
> 됩니다. **지금은 아닙니다.**

### 언제 권하는가

* 위기 상황에서는 **권하지 않습니다.** 그때 필요한 건 파일이 아니라 전화번호입니다
* 이야기가 쌓였을 때만 (주제 2개 이상 · 발화 3회 이상)
* **하루에 한 번까지.** 매번 권하면 상담이 아니라 배포가 됩니다
* 상담사는 무료 맞춤 책만 권하고, **파는 책은 절대 꺼내지 않습니다** (테스트로 고정)

## 10. 수익 전액 기부 — 말이 아니라 장부로

### "전액"을 흐리지 않습니다

"수익금 전액 기부"는 확인할 방법이 없으면 아무 의미가 없습니다.
그리고 **무엇의 전액인지**를 밝히지 않으면 지킬 수 없는 약속이 됩니다.

| | 예시 | 설명 |
| --- | --- | --- |
| 표시 매출 | 540,000원 | 정가 × 부수. 실제로 들어오지 않는 돈 |
| **실제 정산금** | **315,000원** | 통장에 들어온 돈 ← **약속의 기준** |
| 전달한 금액 | 315,000원 | 실제로 보낸 돈 |
| 저자가 가져간 돈 | **0원** | |

전자책 플랫폼은 보통 30~40%를 가져갑니다. 정가 기준으로 "전액"이라고 하면
지킬 수 없습니다. 그래서 **정산금 전액**을 약속으로 삼고, 세 숫자를 모두
공개해 차이를 숨기지 않습니다.

`/book/ledger` 페이지가 `data/ledger.json` 을 그대로 읽어 보여 줍니다.
서버를 다시 띄우지 않아도 갱신됩니다.

```bash
# 판매 기록
python3 -m oneway ledger --sale 2026-03-01 교보문고 120 540000 315000
# 전달 기록 (증빙 번호까지)
python3 -m oneway ledger --donate 2026-04-10 "단체이름" 315000 RCP-0001
```

`ledger` 명령은 스스로 점검도 합니다 — 날짜 형식이 틀렸거나, 어디에
전달했는지 안 적혀 있거나, **아직 전달하지 않은 금액이 남아 있으면**
그대로 알려 줍니다.

### 상담사는 책을 팔지 않습니다

힘들다고 온 사람에게 물건을 파는 것은 상담이 아닙니다.
책 링크는 사이트 하단과 `/book` 페이지에만 있고, **상담사 응답에는
절대 들어가지 않습니다.** 테스트로 고정해 두었습니다.

책 페이지에도 이렇게 적혀 있습니다.

> 형편이 여의치 않으시면 사지 마십시오. 같은 내용을 이 사이트에서 무료로
> 읽으실 수 있습니다. 이 책은 여유가 있는 분이 여유가 없는 분을 돕는
> 방식으로 만들어졌습니다.

### 운영 전에 반드시 확인할 것 (법률)

| 항목 | 내용 |
| --- | --- |
| **기부금품법** | 남에게서 기부금을 '모집'하면 일정 금액 이상일 때 등록 의무가 생깁니다. 이 구조는 **내 판매 수입을 내가 기부**하는 것이라 모집에 해당하지 않는 것이 일반적이지만, 판매 문구를 "기부금을 모읍니다"로 쓰면 해석이 달라질 수 있습니다. **문구를 정하기 전에 확인하십시오.** |
| **표시광고법** | "전액 기부"는 광고 문구입니다. 증명하지 못하면 허위·과장 광고가 됩니다. 그래서 장부가 필요합니다. |
| **세금** | 판매 수입은 일단 **내 소득**입니다. 기부해도 소득 신고 의무는 남습니다. 세무사 확인 필요. |
| **받는 단체** | 기부금 영수증이 필요하면 지정기부금단체인지 확인하십시오. `donate.py` 의 `DEFAULT_CAUSES` 와 `config.book_stores` 를 실제 단체·판매처로 채우십시오. |
| **저작권** | 이 책은 성경 번역문을 한 줄도 싣지 않습니다. 그래서 **어떤 발행처의 허락 없이도 판매할 수 있습니다.** (테스트로 고정) |

## 12. 저작권 · IP 위험 관리

이 부분은 코드보다 중요합니다.

### 안전하게 처리한 것

* **성경 번역문을 한 줄도 싣지 않습니다.** 한국어 번역본(성경·공동번역·개역개정·
  새번역 등)은 각 발행처에 권리가 있습니다. 이 사이트는 *어느 대목인지*(주소)만
  알려 주고, 내용은 **우리가 직접 쓴 한 줄 설명**으로 대체합니다.
  → `oneway/content/verses.py` 의 `gist` 필드. 테스트로도 강제합니다.
* 가톨릭 표기와 개신교 표기를 **둘 다** 보여 줍니다 (마태 11,28 / 마태복음 11:28).
* 본문·질문·기도문·실천 항목은 전부 이 저장소에서 새로 쓴 창작물입니다.

### 운영 전에 확인해야 할 것

| 항목 | 해야 할 일 |
| --- | --- |
| 이름 「하나의 길 / ONE WAY」 | 상표 검색 필수. "ONE WAY"는 일반 명사에 가까워 **단독 상표 등록이 어려울 수 있습니다.** 로고를 결합한 도형상표를 함께 검토하십시오 |
| 로고·심볼 | 디자인권 + 상표 출원 (9·16·41·45류 검토) |
| 기도문·본문 | 저작권은 창작과 동시에 발생. 별도 등록은 분쟁 대비용 |
| 상담 흐름·AI 난이도 조절 | 단순 아이디어는 특허 대상이 아닙니다. **기술적 구현 방식**이 있어야 검토 가능 |
| 개인정보 | 이름·연락처를 받지 않는 현재 구조를 유지하십시오. 받는 순간 처리방침·동의·보관기간 의무가 생깁니다 |
| 아동·청소년 | 미성년자 접근을 전제로 설계했습니다. 광고·결제 유도를 넣지 마십시오 |

### 하면 안 되는 것

* 다른 단체의 묵상집·기도문·설교를 그대로 가져오기
* 특정 교단 로고·명칭을 허락 없이 쓰기
* 상담 대화를 동의 없이 수집해 학습에 쓰기

## 13. 개인정보 처리

* 받는 것: 무작위 세션 ID **하나** (쿠키 `ow_sid`, HttpOnly, SameSite=Lax)
* 받지 않는 것: 이름 · 이메일 · 전화번호 · 생년월일
* 기도 지향은 **공개되지 않습니다.** 공개되는 것은 "오늘 N개"라는 숫자뿐입니다.
* 맞춤 책에는 **방문자가 쓴 문장이 한 글자도 들어가지 않습니다.**
  주제 키와 깊이와 횟수만 씁니다. 파일은 내려받을 때 만들고 저장하지 않습니다.
* 오래된 기록은 지웁니다.

```bash
python3 -m oneway purge --days 180
```

`data/` 폴더는 `.gitignore` 에 있습니다. **절대 커밋하지 마십시오.**

## 14. 배포

**[`deploy/README.md`](deploy/README.md) 에 단계별 안내가 있습니다.**
서버를 처음 다뤄 본다는 전제로 썼습니다. 전체 1~2시간, 월 1만 원 안쪽입니다.

```bash
cp deploy/.env.example deploy/.env       # 도메인·키 적기
sed -i 's/example.kr/내도메인.kr/g' deploy/nginx/oneway.conf
cd deploy && docker compose up -d --build
```

들어 있는 것:

| 파일 | 하는 일 |
| --- | --- |
| `Dockerfile` | 의존성 거의 없는 가벼운 이미지. **루트로 돌지 않음**, 헬스체크 포함 |
| `deploy/docker-compose.yml` | 앱 + nginx + 인증서 자동갱신 + 매일 정리·백업 |
| `deploy/nginx/` | HTTPS, HSTS, CSP, 요청 제한, gzip |
| `deploy/systemd/` | 도커 없이 올릴 때 |
| `deploy/scripts/preflight.sh` | **공개 전 점검** — 전화번호·설정·개인정보 |
| `deploy/scripts/maintenance.sh` | 오래된 기록 삭제 + 백업 (매일 자동) |
| `deploy/scripts/restore.sh` | 백업에서 되돌리기 |

설정은 **기본값 → 설정 파일 → 환경변수 → 명령줄** 순으로 덮어씁니다.
컨테이너는 `ONEWAY_*` 환경변수만으로 뜨고, **설정 파일이 없다고 죽지 않습니다.**

### 비용이 새어 나가지 않게

상담 한 번이 Claude API 한 번이고, 그건 돈입니다. 그래서 두 겹으로 막습니다.

* **nginx** — 분당 20회 (`limit_req zone=counsel`)
* **앱** — 시간당 40회 (`oneway/web/ratelimit.py`)

서버 앞단이 바뀌어도 앱이 스스로를 지킬 수 있어야 하기 때문입니다.

**막을 때도 문은 닫지 않습니다.** 429 응답에도 상담 전화번호가 들어갑니다.
그리고 **위기 신호가 있는 요청은 제한하지 않습니다** — 급한 사람을 막으면 안 됩니다.

### 얼마나 버티나

표준 라이브러리 HTTP 서버라 한 대로 동시 접속 수백 명 수준입니다.
더 커지면 바뀌는 파일은 `web/server.py` 하나이고,
`ratelimit.py` 의 `RateLimiter` 를 Redis 로 바꾸면 여러 대로 늘릴 수 있습니다
(인터페이스는 `check()` 하나뿐).
