# 출시 전 체크리스트 — "구매 유혹"을 합법적으로 최대화하기

미국 시장에서 전환율 장치는 대부분 합법입니다. 문제는 **가짜 데이터로 구동할 때**만 생깁니다.
아래는 "쓰면 안 되는 것"이 아니라 **"같은 장치를 진짜 데이터로 돌리는 법"** 표입니다.

| 장치 | 위험한 구현 (미국 내 실제 제재 대상) | 안전하고 대체로 더 잘 먹히는 구현 |
|---|---|---|
| 희소성 | "2개 남음" 하드코딩 | 실제 재고 API 연동. 재고 12개 이하일 때만 노출 |
| 긴급성 | 새로고침하면 리셋되는 카운트다운 | 실제 배송 컷오프 타이머 — "3시간 12분 내 주문 시 화요일 도착" |
| 정가 대비 할인 | 판매한 적 없는 "정가" 취소선 | 구성품 실제 가격 합계 대비 번들 할인, 산식 노출 |
| 사회적 증거 | 지어낸 "412명이 구매" | 실제 쿼리 결과 + 세그먼트 일치 ("최근 30일 원격근무 PM 412명") |
| 리뷰 | 인센티브 리뷰의 미표기, 부정 리뷰 숨김 | 인센티브 표기 의무, 부정 리뷰 삭제 금지(FTC 리뷰 규칙) |
| 생산성 수치 | "생산성 37% 향상" 단정 | "추정치" 라벨 + 가정값 노출 + 사용자가 수정 가능 |
| 건강 효익 | "허리 통증을 없애줍니다" | 인체공학 연구 인용 + 연관 표현, 의학적 단정 금지 |
| 총액 | 결제 마지막 단계에서 배송비·수수료 등장 | 전 단계 총액 공개 (FTC 수수료 규칙) |
| 구독/보증 자동갱신 | 해지 어렵게 설계 | 가입만큼 쉬운 해지(click-to-cancel), CA ARL 준수 |
| 이메일/SMS | 사전동의 없는 발송 | CAN-SPAM 원클릭 해지, SMS는 TCPA 서면동의 |
| 접근성 | 3D/AR 없이는 구매 불가 | 키보드·스크린리더로 완주 가능한 HTML 폴백 (ADA) |
| 개인정보 | 연봉 필드 강제 수집 | 목적 고지 + 스킵 가능 + GPC 존중 (CCPA/CPRA) |

**핵심 원칙 하나만 기억한다면:** 이 시뮬레이터의 설득력은 "점수 격차 → 시간 → 달러 → 회수기간"
이라는 **계산 가능한 논리**에서 나옵니다. 가짜 배지는 여기에 아무것도 보태지 않으면서 소송
리스크만 얹습니다. 정직한 다운그레이드 경고("이걸 바꾸면 -6점, 주당 1.1시간을 다시 잃습니다")가
역설적으로 이 플로우에서 객단가를 가장 크게 올리는 장치입니다.
