# 1인 뷰티 위탁 셀러 — 실제 수익 구조 설계

"AI 얼굴 분석 → 화장품 추천 → 위탁 발주 자동화" 아이디어를 **법적으로 안전하고, 숫자가 맞고,
혼자 운영 가능한** 구조로 다시 설계한 문서와 도구입니다.

```bash
python3 -m beauty_seller quiz                       # 대화형 피부 타입 체크 → 추천 메시지
python3 -m beauty_seller recommend '{"adult":"예","tightness":"많이","shine":"없음","redness":"많이","reaction":"조금","concern":"dryness","budget":"mid","steps":"basic"}'
python3 -m beauty_seller margin --price 59900 --supply 34500 --ad 8000
python3 -m beauty_seller orders 주문.csv --mapping beauty_seller/data/order_mapping.example.json
python3 -m beauty_seller simulate                   # 990개 전략 × 300개 시나리오 최적화 (약 5초)
```

파이썬 3.9+ 표준 라이브러리만 씁니다(설치할 것 없음). 테스트: `python3 -m unittest tests.test_beauty_seller`

## ① 핵심 결론

기존 설계(고객 민낯 사진 → 무료 데모 사이트로 분석 → Aside가 주문 대행)는 **그대로 실행하면 안 됩니다.**
돈이 되는 지점은 'AI 얼굴 분석'이 아니라 **"내 피부 타입에 맞는 루틴 세트를 고민 없이 사는 경험"**입니다.

수정한 구조:

```
숏폼 콘텐츠 → 사진 없는 8문항 피부 타입 체크 → 공유하고 싶은 결과 카드
→ 스마트스토어 '루틴 세트'(단일 공급사 묶음배송) → 엑셀 대량발주 → 6~8주 뒤 재구매 알림
```

- 얼굴 사진은 **MVP에서 받지 않습니다.** (개인정보·약관·책임 리스크 대비 효용이 낮음)
- 상품은 단품이 아니라 **세트**로 팝니다. 단품 위탁은 최저가 경쟁에서 이길 수 없습니다.
- 발주는 Aside 에이전트가 아니라 **대량발주 파일 변환**이 주력, Aside는 소싱 조사·소량 보조용입니다.

## ② 현재 계획의 문제 (기존 답변에서 고쳐야 할 부분)

| 기존 내용 | 문제 | 수정 |
|---|---|---|
| 고객 민낯 사진을 오픈채팅·구글폼으로 받음 | 얼굴 사진은 개인정보이고, 얼굴 특징을 분석·처리하면 민감정보(생체인식정보) 쟁점이 생김. 동의서·보관기간·파기 절차 없이 받으면 위반 소지 | 사진 없는 설문형 체크로 대체 |
| YouCam **온라인 데모 페이지**에 고객 사진 업로드 | 데모는 상업용 대행 분석 용도가 아님(약관 위반 소지) + 고객 사진의 제3자 제공·국외이전 | 사진 분석이 꼭 필요하면 **유료 상용 API 계약** + 별도 동의 후 도입(레이어 4) |
| "홍조 있는 21호 웜톤 → 진정 세럼, 옐로우 파운데이션" | ①"홍조 개선·치료" 같은 표현은 화장품법상 의약품 오인 광고 위험 ②사진만으로 파운데이션 호수 추천 → 반품률 높음 | "붉은 기 고민 피부용 저자극 루틴"처럼 표현, **베이스 메이크업은 초기 상품에서 제외** |
| 알리·타오바오 해외 구매대행 | 해외직구 화장품에서 유해물질 검출 사례가 반복 보도됨. 고객 피부 문제 시 신뢰·분쟁 리스크가 큼 | **국내 위탁(성분표·정식 유통 확인 가능)만** 시작 |
| Aside가 건별로 사이트를 돌며 주문 입력 | 느리고(건당 수 분), UI 변경 시 오작동, 고객 주소가 AI 서비스로 전송됨, 사이트 약관상 자동화 제한 가능 | 공급사 **엑셀 대량주문** 양식으로 변환(`orders` 명령) |
| "파란색 [바로 구매하기]", `Ctrl+E` 등 구체 UI | 실제 확인되지 않은 세부사항. 틀리면 에이전트가 엉뚱한 버튼을 누름 | UI를 가정하지 않는 "목표+확인+멈춤" 프롬프트로 재작성(`prompts/`) |
| "쿠팡 파트너스로 완전 자동 부수입" | 수수료가 낮고(판매가의 수 % 수준) 트래픽이 없으면 0원. 광고 표기 의무 있음 | 퍼널 검증용 보조 수익으로만 사용 |
| 카카오 오픈채팅으로 상담 | 상업 홍보 목적 운영이 제한될 수 있고 고객 관리가 어려움 | **카카오톡 채널**(비즈니스)로 운영 |

맞는 부분도 있습니다: 완제품을 그대로 판매·유통만 하는 경우 화장품책임판매업 등록은 필요 없습니다.
단, **소분·혼합**해서 팔면 맞춤형화장품판매업 신고 대상이 되므로 하지 마세요. 사업자등록과
통신판매업 신고는 필수입니다.

## ③ 원인

"AI 기술을 붙이면 팔린다"에서 출발했기 때문입니다. 1인 셀러의 실제 병목은 **기술이 아니라 유입(트래픽)과
마진**입니다. 분석 정확도를 아무리 높여도 사람이 오지 않으면 매출은 0이고, 같은 상품을 남들보다 비싸게
팔 이유가 없으면 마진도 0에 수렴합니다.

## ④ 가장 좋은 해결책 — 4단 수익 레이어 (우선순위 순)

| 순서 | 레이어 | 시작 시점 | 역할 | 수익원 |
|---|---|---|---|---|
| 1 | **루틴 세트 위탁 판매** (스마트스토어) | 2주차 | 메인 매출 | 세트 마진 (목표 순이익률 25~30%, 광고비 제외) |
| 2 | **재구매 루틴** (카카오톡 채널 알림, 정기 할인) | 2개월차 | 객단가→고객생애가치 | 재구매 시 광고비 0원 → 마진 그대로 이익 |
| 3 | **제휴 링크** (쿠팡 파트너스 등) | 1주차부터 병행 | 세트가 없는 조합·단품 수요 흡수 | 판매 수수료 |
| 4 | **확장**: 사진 분석(상용 API), 자체 PB(OEM), B2B | 월 200세트 이상 안정화 후 | 차별화·마진 확대 | PB 마진, 제휴 |

**왜 세트인가 (차별화 원리)**: 단품은 가격비교 1초 만에 최저가에 집니다. "건성·민감용 4단계 루틴 세트"는
구성이 내 큐레이션이라 직접 가격비교가 어렵고, 객단가가 올라 배송비·수수료 같은 고정비 비율이 내려갑니다.
반드시 **한 공급사 안에서** 구성해 묶음배송 1회로 보내세요(공급사가 다르면 배송비가 구성품 수만큼 붙습니다).
`recommend` 명령은 이 규칙대로 단일 공급사에서만 세트를 구성합니다.

## ⑤ 실행 단계 (30일)

| 주차 | 할 일 | 완료 기준 |
|---|---|---|
| 0주 | 사업자등록, 통신판매업 신고, 스마트스토어·카카오톡 채널 개설, 개인정보처리방침 작성 | 판매 가능 상태 |
| 1주 | 공급사 1곳 입점 → 위탁·온라인판매·이미지 사용 허용 상품 30개 조사(`prompts/` ④) → `data/catalog.example.csv` 형식으로 실제 카탈로그 작성 | 공급가/권장가 비율 60% 이하 상품 위주 |
| 1주 | 피부 타입 4종 × 단계 2종 = **세트 8개**만 등록 | 등록 완료 |
| 2주 | 8문항 설문을 구글폼(또는 카카오 채널 자동응답)으로 구현, 결과 메시지는 `recommend` 출력 그대로 사용 | 지인 20명 테스트 |
| 2~4주 | 숏폼 하루 1편(성분·루틴 순서 정보형) → 프로필 링크 = 설문 | 설문 완료 300건 |
| 4주 | 지표 점검 후 반응 없는 세트 교체, 잘 팔리는 세트에만 광고 소액 테스트 | 아래 KPI 기준 |

**KPI (매주 기록)**: 설문 완료 수 → 결과 링크 클릭률(목표 30%) → 구매 전환율(목표 3%) → 객단가 →
60일 재구매율(목표 20%) → 주문당 광고비(손익분기 이하 유지).

## ⑥ 실제 예시 — 숫자

`python3 -m beauty_seller margin --price 59900 --supply 34500` (수수료 6%, 배송비 3,000원, 기타 300원 가정)

| 시나리오 | 순이익/건 | 순이익률 | 월 300만 원에 필요한 주문 | 필요한 설문 완료(전환 3%) |
|---|---:|---:|---:|---:|
| 콘텐츠 유입(광고 0) | 18,506원 | 30.9% | 163건 (하루 6건) | 5,434건 |
| 광고 CPA 8,000원 | 10,506원 | 17.5% | 286건 (하루 10건) | 9,534건 |
| 쿠팡 채널(수수료 11% 가정) | 15,511원 | 25.9% | 194건 | 6,467건 |

해석:
- 광고로만 팔면 이익이 절반 가까이 줄어듭니다. **콘텐츠 유입 + 재구매**가 수익의 핵심입니다.
- 손익분기 광고비는 건당 18,506원이지만, 실제로는 그 절반 이하에서만 광고를 유지하세요.
- 수수료율·배송비는 가정치입니다. 판매자센터와 공급사 조건을 확인한 뒤 `--fee`, `--shipping`으로 바꿔 넣으세요.

추천 메시지 예시(`recommend` 출력, 카탈로그는 가상 상품):

```
피부 타입 체크 결과: 건성·민감 타입 / 주요 고민: 건조·당김
추천 루틴 (아침·저녁 순서대로)
1. 클렌저 — (예시) 크림 타입 저자극 클렌저 120ml
2. 세럼 — (예시) 판테놀 진정 세럼 50ml
3. 보습크림 — (예시) 세라마이드 장벽 크림 50ml
4. 선크림 — (예시) 무기자차 선크림 SPF50+ 50ml
개별 구매가 77,600원 → 루틴 세트 72,900원 (기본 할인 5%)
※ 설문 기반 피부 타입 참고 정보이며 의학적 진단이 아닙니다. ...
```

발주 자동화(`orders`): 마켓 주문 CSV → 공급사 대량발주 CSV. 세트는 구성품별 행으로 펼치고, 연락처·우편번호
형식 오류나 매핑 없는 상품은 `발주서_오류.csv`로 분리합니다. 열 이름은 `data/order_mapping.example.json`에서
실제 양식에 맞게 바꾸세요. (마켓 엑셀이 암호화돼 있으면 엑셀에서 열어 CSV로 다시 저장)

## ⑥-2 시뮬레이션 최적화 결과 (`simulate`)

불확실한 가정 15개(전환율, 가격 탄력성, 광고 단가, 재구매율 등)를 **범위**로 두고 시나리오 300개를 뽑아,
전략 990개(세트 할인 6단계 × 광고비 6단계 × 광고 시작 시점 × 재구매 정책 5종 × 발주 방식 3종)를 **같은 시나리오**로
12개월씩 돌렸습니다. 고른 전략은 새로 뽑은 시나리오 300개로 다시 검증했습니다(과적합 방지).
비용에는 초기비용 50만 원과 **콘텐츠 제작 월 30시간**(시간당 1.5만 원 환산)을 포함했습니다.

| 항목 | 결과 |
|---|---|
| **최적 전략** | 세트 할인 0~5% · 광고 없음 · 재구매 알림 + 5~10% 할인 · 대량발주 파일 |
| 12개월 기대 순이익 | 현금 기준 **약 1,390만 원**, 내 시간비용 차감 후 **약 840만 원** |
| 범위 | 비관(하위 10%) −240만 원 ~ 낙관(상위 10%) 2,310만 원 (시간비용 차감 기준) |
| 위험 | 현금 손실 확률 1%, 최악 5% 누적 적자 약 51만 원, 흑자 전환 중앙값 3개월차 |
| 검증 | 새 시나리오에서 820만 원 — 최적화 결과와 2% 이내로 일치 |
| 기존 방식(10% 할인·알림 없음·에이전트 발주) 대비 | **+43%** |

**요소별 효과** (최적 전략에서 하나만 바꿨을 때, 시간비용 차감 기준 12개월):

| 바꾼 것 | 순이익 변화 | 이유 |
|---|---:|---|
| 세트 할인 10% | −69만 원 | 마진이 얇아 할인으로 늘어난 주문보다 깎인 이익이 큼 (탄력성이 2.6 이상이어야 이득) |
| 세트 할인 20% | −216만 원 | 〃 |
| 광고 월 60만 원 | −262만 원, 손실확률 14% | 설문 1건 광고단가가 **약 670원 미만**이어야 본전. 가정 범위(400~1,500원) 대부분에서 적자 |
| 광고 월 150만 원 | −985만 원, 손실확률 50% | 광고비가 늘수록 효율 하락 |
| 재구매 알림 끔 | −58만 원 | 재구매는 광고비 0원 주문 |
| Aside 에이전트 발주 | −79만 원 | 오발주율·작업시간이 대량발주 파일보다 큼 |

**결과를 가장 크게 흔드는 가정** = 먼저 실측할 것: ① 콘텐츠 유입 성장률 ② 첫 달 콘텐츠 유입 수
③ 설문→구매 전환율 ④ 공급가 비율. → **수익의 핵심은 할인·광고가 아니라 숏폼 꾸준히 올리기**입니다.

현실 운영 규칙으로 옮기면:
1. 세트 혜택은 가격 할인보다 **0~5% + 샘플 증정**으로 시작합니다. 0%와 5% 차이는 연 3% 수준이라, 두 안을 2주씩 A/B 테스트해서 정합니다.
2. 광고는 끄고 시작합니다. 소액(하루 1만 원 × 1주) 테스트로 **설문 1건당 광고비를 실측**해서 670원 미만일 때만 늘립니다.
3. 재구매 알림은 첫 판매부터 켭니다(수신 동의 필수). 재구매 할인은 5%로 충분합니다(5~15% 차이 미미).
4. 발주는 `orders`(대량발주 파일)로 합니다. Aside는 소싱 조사용입니다.
5. 4주 뒤 실측값으로 `data/sim_config.example.json`의 범위를 좁혀 **다시 돌립니다**. 범위가 좁을수록 추천이 정확해집니다.

> 이 수치는 실측 전 가정에서 나온 **의사결정용 추정**이지 수익 보장이 아닙니다. 모델 구조: `simulate.py` 상단 주석.

### 오류 점검으로 고친 것 (퍼즈 테스트: 무작위 불량 주문 1,000건)

## ⑧ 수익화 확장 — 내 캐릭터 IP와의 연결

이 사업은 캐릭터·게임 IP와 **다른 사업**입니다. 시간을 무한정 쓰지 말고 "현금흐름 + 콘텐츠 퍼널 연습"으로
범위를 정하는 것을 권합니다. 다만 한 지점에서 자연스럽게 연결됩니다.

- **피부 타입 캐릭터 결과 카드**: 건성·지성·복합성·중성(+민감) 결과를 각각 **독창적인 캐릭터 1종**으로
  보여주는 공유용 카드. 성격 유형 테스트처럼 "내 피부 캐릭터"를 SNS에 공유하게 만들면 광고비 없이 유입이 생깁니다.
  - 캐릭터 그림 → 저작권, 캐릭터 이름 → 상표(필요 시) 대상. 기존 뷰티 브랜드 마스코트와 닮지 않게 설계.
  - 잘 되면 같은 캐릭터로 숏폼 시리즈·굿즈(파우치·거울)·자체 PB 패키지까지 확장 → 장기 IP 자산.
- 자체 PB(OEM)는 화장품책임판매업 등록과 책임판매관리자가 필요하므로 **월 200세트 이상 안정화 후** 검토.

## ⑨ 다음 단계

1. 입점할 공급사 1곳을 정하고, 위탁·온라인 판매·이미지 사용 조건을 확인합니다.
2. 실제 상품 30개로 `data/catalog.example.csv`를 복사해 `catalog.csv`를 만들고
   `python3 -m beauty_seller recommend ... --catalog catalog.csv`로 8개 세트를 뽑습니다.
3. 각 세트를 `margin`으로 계산해 **광고 0원 기준 순이익률 25% 미만인 세트는 등록하지 않습니다.**
4. 공급사의 대량주문 엑셀 양식을 받아 `order_mapping.example.json`의 열 이름을 맞춥니다.
5. 피부 타입 캐릭터 4종 콘셉트를 잡고 결과 카드 1장을 시안으로 만듭니다.
6. 4주 뒤 실측값(설문 수, 전환율, 광고단가)으로 `simulate --config`를 다시 돌려 전략을 갱신합니다.
