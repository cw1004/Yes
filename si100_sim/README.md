# SI-100 흡착식 제빙기 시뮬레이션

활성탄(Maxsorb III)과 메탄올을 쓰는 태양열 흡착식 제빙기의 하루 얼음 생산량을 계산하고,
어떤 설계 변수를 바꾸면 얼음이 늘어나는지 찾는 도구입니다.

## 실행

```bash
pip install numpy matplotlib
python -m si100_sim.analyze
```

결과는 `output/si100/` 에 저장됩니다.

| 파일 | 내용 |
| --- | --- |
| `sensitivity.png` / `.csv` | 변수 8개를 하나씩 바꿨을 때 집열판 1 m²당 얼음량 |
| `improvement_path.png` / `.csv` | 개선안을 차례로 누적 적용했을 때 얼음량 |

## 모델

- 하루 1회 사이클: 낮에 태양열로 탈착(냉매를 응축기로 보냄), 밤에 흡착(증발기에서 얼음 생성).
- 흡착 평형은 Dubinin-Astakhov 식. 계수는 도면 VC-400의 흡착 평형 표 3개 점에 맞춤
  (E ≈ 11,600 J/mol, n ≈ 1.57, 포화 흡착량 1.31 kg/kg).
- 가열량 = 등량 가열 + 등압 탈착(현열 + 흡착열). 흡착열 = 증발 잠열 + 흡착 퍼텐셜.
- 집열 효율 = 0.75 − U × (평균 흡착기 온도 − 외기) / 700 W/m².
  집열판이 하루에 받는 열로 가열할 수 있는 만큼 활성탄을 넣는다고 가정합니다.

## 한계

- 평형 모델입니다. 열·물질 전달이 느려 평형에 못 미치는 손실은 들어 있지 않으므로 결과는 상한에 가깝습니다.
- 기준 조건(증발 −5 °C, 응축 30 °C, 흡착 종료 30 °C, 탈착 100 °C, 일사 20 MJ/m²)은 가정값입니다.
- SI-100의 실제 냉매(메탄올 대체 물질)가 정해지면 `psat_kpa`, `h_fg`, DA 계수를 그 물질 값으로 바꿔야 합니다.
- 도면 VC-400 표 자체가 계산값이라 실측 흡착 등온선으로 다시 맞춰야 합니다.
