# 기술 정리 노트 v1.0

> 이 문서는 변리사 상담 전 **기술 내용을 정리한 메모**이며 법률 자문이 아니다.
> 출원 가능성 판단과 선행기술 조사는 전문가 검토가 필요하다.

## 시스템이 실제로 하는 일
1. 한 판이 끝날 때 7개 지표(생존시간, 통과 수, 시도 수, 최대 콤보, 탭 간격 변동계수,
   최근 점수, 최근 성공률)를 수집한다.
2. 가중합으로 숙련도 S 를 계산하고 지수 평활(0.7/0.3)로 갱신한다.
3. S 와 연속 성공/실패·조기 사망·콤보 피드백 항 F 로 목표 난이도를 구하고,
   **한 판당 ±5 로 변화량을 제한**해 다음 판에 적용한다.
4. 난이도는 골문 간격·스크롤 속도·골문 이동폭·바람으로 환산된다.
5. 다음 골문 높이는 현재 물리 파라미터에서 **도달 가능한 범위**로 제한 생성된다.
6. 조정 근거를 플레이어에게 문장으로 제시한다.

## 정리해 둘 만한 포인트
- 지표 → 숙련도 → 난이도 → 물리 파라미터로 이어지는 변환 체계
- 변화량 상한(±5)과 성공률 목표 구간(65~80%)을 함께 쓰는 안티 프러스트레이션 구조
- 물리 파라미터로부터 역산한 "도달 가능성 제약" 기반 장애물 생성
- 난이도 조정 근거를 사용자에게 노출하는 설명 가능 구조

## 확인이 필요한 사항
- DDA(Dynamic Difficulty Adjustment) 관련 선행기술 범위
- 규칙 기반 조정 로직의 신규성 인정 여부
- 소프트웨어 발명 성립 요건
